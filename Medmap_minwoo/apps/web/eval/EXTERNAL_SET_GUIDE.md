# 외부 평가 문장 모으기 안내문

규칙을 모르는 사람(팀원·지인)에게 보내는 안내문이다. 받은 문장은 `intake_eval_set.jsonl`과 같은 형식으로 정답을 달아
외부 세트로 따로 채점한다. 정답은 문장을 받은 뒤 달고, 문장을 정규식에 맞춰 고치지 않는다.

---

안녕하세요! 캡스톤 프로젝트 **MedMap**(병원 가기 전에 증상을 말로 남기면 자동으로 정리해 주는 앱) 시험용 문장을 모으고 있어요.
10~15분이면 됩니다. 🙏

**어떻게 쓰나요?**
병원 접수처에서 "어디가 불편해서 오셨어요?"라는 질문을 받았다고 상상하고, **입으로 말하듯이** 적어 주세요.

- 아래 상황 중에서 골라서 상황 하나에 1~3문장씩, **모두 20~30문장** 정도 써 주세요.
- 평소 말투 그대로 써 주세요. 반말, 사투리, 말 줄임, 맞춤법 틀림, 띄어쓰기 안 함, "음… 그러니까" 같은 말 다 좋아요.
- 할 수 있으면 이런 것도 섞어 주세요.
  - 언제부터인지
  - 얼마나 심한지
  - 몇 번 그랬는지
  - 좋아지는지, 나빠지는지
  - **없는 증상**("○○은 없어요")
  - 헷갈리는 것("○○인지 잘 모르겠어요")
  - 먹는 약, 알레르기, 앓았던 병
  - 가족 증상
- 정답이 있는 시험이 아니에요. 서로 다른 말투가 많을수록 도움이 돼요.

**꼭 지켜 주세요**
- ChatGPT 같은 AI로 만들지 말고 직접 써 주세요.
- 실제 내 병력이 아니어도 돼요. **상상해서 써 주세요.**
- 이름, 전화번호, 주민번호, 병원 이름 같은 개인정보는 넣지 말아 주세요.
- 다른 사람이 쓴 문장은 보지 말고 써 주세요.

**상황 예시** (번호만 적고 골라 쓰면 돼요)
1. 며칠째 감기 기운이 있다
2. 배 쪽이 불편하고 화장실을 자주 간다
3. 머리가 아프다
4. 아이(또는 부모님)가 아파서 보호자로 대신 말한다
5. 가슴 쪽이 불편하다
6. 허리나 무릎·어깨 같은 관절이 아프다
7. 피부에 뭐가 났다
8. 소변볼 때 이상하다
9. 어지럽거나 기운이 없다
10. 잠을 잘 못 자거나 기분이 처진다
11. 눈·귀·코 중 하나가 불편하다
12. 목이 아프거나 기침이 난다
13. 뭘 잘못 먹고 탈이 났다
14. 혈압약 같은 약을 원래 먹는데 새로운 증상이 생겼다
15. 지난번보다 좋아졌거나 나빠져서 다시 왔다
16. 증상이 있는 건지 없는 건지 헷갈린다
17. 갑자기 심해져서 급하게 왔다
18. 자유 주제 (흔히 겪는 아무 증상이나)

**보내는 형식**
```
이름(별명 가능):
1) 상황 3 / 문장
2) 상황 3 / 문장
3) 상황 12 / 문장
...
```

감사합니다! 모은 문장은 이 앱의 증상 정리 정확도를 재는 데만 쓰고, 보내 준 사람 이름은 기록하지 않아요.
