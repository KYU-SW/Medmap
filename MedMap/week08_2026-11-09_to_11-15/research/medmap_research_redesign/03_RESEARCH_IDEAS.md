## 아이디어 1. 진단 조건부 증거 놀람도 (DxShift)

**쉬운 예시**: ED에서 "폐렴"으로 입원. 6시간 뒤 D-dimer 매우 높음, 흉부 CT에 폐렴 소견 없음. 과거에 폐렴으로 입원해 끝까지 폐렴이었던 환자들에게는 드문 조합. 드문 정도를 점수로 쌓아 "이 진단, 다시 볼 만함"을 알림. 폐렴 규칙을 사람이 쓰지 않음. 과거 자료가 "폐렴답다"의 기준.

1. 해결할 문제: 의사가 붙인 진단과 이후 도착한 결과가 어긋나는 시점을 질병별 규칙 없이 탐지.
2. 기존 한계: e-trigger는 쌍별 수작업(R01). EVLU는 모델 자기 판단 + 수작업 방향 규칙(R03). 조건부 이상치는 처방 행위 대상(R47). Hautz는 고정 특성으로 예측 불가 보고(R12).
3. 차이: 조건 변수가 **의사의 ED 진단**. 입력은 **가용 시각 순서**의 결과. 정답은 **실제 진단 변경**.
4. 제안 방법: 진단군별 조건부 우도비를 시간순 누적하는 순차 검정.
5. 작동 원리
   - 진단군 g(ED 주진단의 CCSR 범주). 증거 사건 e = (항목 k, 값 구간 v, 가용 시각 a, 출처, 판본).
   - 학습: 유지군(y=0)·변경군(y=1)에서 P(v | g, k, y) 추정. 표본 적은 g는 상위 계통→전체로 수축(Dirichlet 평활).
   - 추론: Λ_t = Σ log[P(v|g,k,1) / P(v|g,k,0)], 합산 대상은 a ≤ t, 최신 판본, 중복군당 1건.
   - 알림: Λ_t ≥ τ_g. 보류: g 표본 < N_min 또는 사용 증거 수 < m.
   - 설명: 항별 기여 상위 3건을 출처와 함께 제시.
6. 입력: ED 진단 코드, 검사 결과(storetime), 영상 판독 범주(storetime, 정정 연결), 활력징후.
7. 출력: 시점별 재검토 점수, 알림/보류/무알림, 기여 증거 목록.
8. 의사코드
```
for stay in test:
    g = ccsr(ed_primary_dx(stay))
    if n_train[g] < N_MIN: emit(ABSTAIN, "진단군 표본 부족"); continue
    L = 0; used = {}
    for e in sort_by_available_time(evidence(stay)):
        if e.superseded_by is not None and e.superseded_by.available <= now: retract(L, e)
        if e.dedup_group in used: continue          # 같은 검사 재서술은 1회만
        L += log(p1[g][e.k][e.v] / p0[g][e.k][e.v]); used.add(e.dedup_group)
        if len(used) >= M_MIN and L >= tau[g]: emit(ALERT, top_contributors(e))
```
9. 필요한 의학 지식: 없음(자료 유도). ICD→CCSR 매핑표, 증상 코드→질병 "구체화" 관계표만 필요.
10. 데이터 확보: 로컬 MIMIC-IV + ED로 즉시 가능. 영상 범주는 일반화 필요(초기엔 검사·활력만).
11. 비교 대상: 이상 결과 개수 규칙, 조기경보 점수(중증도만), 진단을 뺀 부스팅, 진단을 특징으로 넣은 부스팅, 로컬 LLM 제로샷.
12. 지표: 시점별 AUROC·AUPRC, 고정 알림률에서 PPV·민감도, 보류율, 알림 선행 시간, 진단군별 최저 성능.
13. 독창성 위험: 수식은 나이브 베이즈 + 순차 확률비 검정(기존). 새로움은 과제·조건화·평가에 한정. "진단 넣은 부스팅"이 더 높으면 방법 기여 소멸.
14. 구현 위험: ED 진단 코딩 시점 미상(퇴실 후 코딩이면 "의사 가설" 해석 약화). 증상 코드(R코드) 비율 높으면 라벨 잡음.
15. 실패 원인 예상: 변경 라벨이 청구 관행 차이를 반영. 검사 주문 자체가 의사의 재검토를 반영(정보가 이미 반영됨).
16. 논문 가능성: 중~상. 과제 + 라벨 + 프로토콜 + 음성 결과 포함 보고로 정보학 학술지 수준.

## 아이디어 2. 가능성 갱신의 우도비 분해 (SCT 방향 일치)

**쉬운 예시**: 가설 "대동맥 박리", 새 정보 "흉부 X선 종격동 정상". 의사 패널 정답 −1(조금 덜 의심). 모델이 "많이 올림(+2)"이라 하면 방향 오류. 같은 X선 결과가 간호기록·의사기록·판독문 세 곳에 적혀 있어도 한 번만 반영해야 함.

1. 문제: 새 정보 1건이 가설을 어느 방향·크기로 바꾸는지 의사 패널과 일치시키기.
2. 기존 한계: LLM 직접 응답은 전문의보다 낮음(R31). 이전 판단에 끌림(R03). 중복·정정 미취급.
3. 차이: 갱신을 "증거 1건의 우도비 등급" 단위로 분해하고, 증거 위생 규칙을 갱신 앞단에 고정.
4. 방법: 로컬 LLM이 우도비 등급(≪1, <1, ≈1, >1, ≫1)만 답함. 누적·중복 제거·정정 철회는 결정적 코드가 수행.
5. 원리: 로그 오즈 = 사전 + Σ 등급 가중치. 동일 중복군은 가중 1회. 정정 도착 시 이전 판본 기여 철회 후 새 판본 적용. 바꿔쓰기 5회 응답 불일치 시 보류.
6. 입력: 가설, 사례 맥락, 새 정보(시각·출처 포함).
7. 출력: −2~+2 등급, 보류 표시, 사용 증거 목록.
8. 알고리즘: 위 5번. 등급→가중치는 개발 분할에서 1회 보정 후 동결.
9. 의학 지식: LLM 내재 지식. 수작업 규칙 없음.
10. 데이터: ER-REASON SCT 194 내원(심사 필요, 불확실). 대체: 공개 SCT 174문항(소규모).
11. 비교: LLM 직접 등급, LLM + 사슬 추론, 최빈값, 소견 유무 규칙(기존 EXP-04 0.607).
12. 지표: 방향 일치율, SCT 표준 집계 점수, 보류 포함 위험-적용범위 곡선, 반대 방향 오류율.
13. 독창성 위험: SCT 벤치마크 포화(R31, R05 자체 평가). 우도비 분해는 고전 베이즈.
14. 구현 위험: 8 GB 모델의 의학 지식 한계. 접근 심사 탈락.
15. 실패 원인: 분해가 직접 응답보다 낮을 수 있음. SCT 문항에 중복·정정이 드물면 위생 계층 효과 0.
16. 논문 가능성: 중. 접근 성공 시 워크숍~학술지.

## 아이디어 3. 증거 위생 섭동 감사 (가용 시각·정정·중복)

**쉬운 예시**: CT 최초 판독 "색전 없음", 3시간 뒤 정정 "우하엽 분절 색전". 기록 시각 순으로만 읽는 파이프라인은 두 문서를 "음성 1건, 양성 1건"으로 셈. 정정 관계를 알면 "양성 1건, 음성은 폐기".

1. 문제: 흔한 EHR 전처리(기록 시각 정렬, 판본 무시, 중복 계수)가 하류 판단을 얼마나 바꾸는지 정량화.
2. 기존 한계: 가용 시각만 다룸(R13, R20, R08). 정정·중복 미취급.
3. 차이: 실제 타임라인에 세 가지 섭동을 통제 적용하고 판단 뒤집힘을 사건 단위로 측정.
4. 방법: 섭동 연산자 3종 + 뒤집힘 감사.
5. 원리
   - T(가용 시각): charttime 기준 입력 vs storetime 기준 입력.
   - S(정정): 정정 연결 반영 vs 원본·정정을 독립 문서로 취급 vs 정정 누락.
   - D(중복): 중복군 1회 vs 원문 그대로.
   - 하류 모델(부스팅, 로컬 LLM, 기존 규칙 엔진)의 출력 변화율과, 라벨 대비 해로운 변화율 측정.
6. 입력: MIMIC-IV 검사·영상(정정 25,735건 연결).
7. 출력: 섭동별 뒤집힘률, 영향 받는 내원 비율, 시점별 분포.
8. 알고리즘: 재생 엔진(기존 구현) + 섭동 스위치.
9. 의학 지식: 불필요.
10. 데이터: 로컬 보유. 중복 서술은 MIMIC에 경과기록이 없어 합성 주입으로만 가능.
11. 비교: 섭동 없음(위생 완비) 대 각 단순 처리.
12. 지표: 뒤집힘률, 해로운 뒤집힘률, 정정 포함 내원 한정 성능 차.
13. 독창성 위험: 가용 시각 부분은 재현 연구. 정정 부분만 신규 가능.
14. 구현 위험: 낮음. 기존 엔진 재사용.
15. 실패 원인: 정정이 의미를 바꾸는 비율이 낮으면 효과 미미.
16. 논문 가능성: 중하~중. 자원·방법 논문.

## 아이디어 4. 퇴원요약 서술 기반 진단 전환점 추출

**쉬운 예시**: 퇴원요약에 "처음엔 폐렴으로 항생제 시작, 입원 2일째 CT에서 폐색전 확인되어 항응고제로 전환". 치료 의사가 직접 쓴 전환 기록. 여기서 (이전 진단, 새 진단, 계기 증거)를 뽑아 CT 판독문 시각과 연결하면 "전환 시각"이 생김.

1. 문제: 변경 사건의 시각과 계기 증거를 확보.
2. 기존 한계: 코드 비교는 시각이 없음. 서술 추출 자료 미발견(폐렴 1질환 R51).
3. 차이: 치료 의사 본인의 서술이 정답. 주석자는 독해 정확성만 확인(의학 판단 불필요).
4. 방법: 단서 문구 정규식 선별 → 로컬 LLM 구조화 추출 → 계기 증거를 구조화 사건에 시각 연결.
5. 원리: 추출 필드 = 이전 진단, 이후 진단, 계기(검사·영상·경과), 서술 인용 구간. 인용 구간 문자열 일치 검증으로 환각 차단.
6. 입력: MIMIC-IV-Note 퇴원요약(다운로드 필요).
7. 출력: 전환 사건 표(내원, 이전→이후, 계기 사건 id, 가용 시각).
8. 알고리즘: 2단 추출 + 인용 검증 + 사건 연결(같은 내원의 판독문·검사 중 계기와 일치하는 가장 이른 것).
9. 의학 지식: 불필요(독해).
10. 데이터: credentialed 권한 보유 추정, 파일 미보유. 약 33만 요약 중 단서 문구 포함분만 처리.
11. 비교: 정규식 단독, 코드 불일치 라벨과의 일치도.
12. 지표: 표본 200건 2인 독해 검증 정밀도, 코드 라벨과 κ, 계기 연결 성공률.
13. 독창성 위험: 유사 추출 연구 존재 가능(검색 2회 한정).
14. 구현 위험: 8 GB 모델 추출 품질. 처리 시간.
15. 실패 원인: 사후 서술의 후견 편향, 기록된 전환만 포착(선택 편향), 계기 미기재.
16. 논문 가능성: 중~상(자료 기여). 아이디어 1의 2단계 정답으로 결합 시 상승.

## 아이디어 5. 양성 결과 후 조치 폐루프 감시 (PE)

**쉬운 예시**: CTPA 판독 "급성 폐색전" 저장. 이후 12시간 동안 항응고제 투여 기록 없음. "양성 결과에 조치 없음" 후보.

1. 문제: 중요한 양성 결과 뒤 기대 조치 누락 탐지.
2. 기존 한계: e-trigger로 이미 수행(R01 PPV 52.4%).
3. 차이: Ext-PE 의사 라벨로 양성 정의의 정확도 확보.
4. 방법: 결과 가용 시각 + 기대 조치 창 + 조치 기록 조회.
5. 원리: 판독 storetime 이후 창 내 `emar`·`prescriptions` 항응고제 유무.
6. 입력: 판독문, 투약 기록.  7. 출력: 미조치 후보 목록.
8. 알고리즘: 규칙.  9. 의학 지식: 기대 조치 정의(금기 예외 포함) 필요 → 전문의 필요.
10. 데이터: 로컬 가능.  11. 비교: 단순 규칙.  12. 지표: 후보율(정답 없음).
13. 독창성 위험: 높음(기존 트리거와 동일).  14. 구현 위험: 낮음.
15. 실패 원인: 미조치의 정당 사유(출혈, 임종 돌봄) 판정 불가.
16. 논문 가능성: 낮음.

## 아이디어 6. 기존 진단이 설명하지 못하는 소견 잔차

**쉬운 예시**: 진단 "요로감염". 소견 중 "발열·농뇨"는 설명됨. "새로 생긴 저나트륨혈증"은 설명 안 됨 → 잔차.

1. 문제: 설명되지 않은 소견 식별.  2. 기존 한계: 간결 덮개 이론(R48)은 지식베이스 필요.
3. 차이: LLM을 "설명 가능 여부" 판정기로 사용.  4. 방법: 소견별 설명 여부 판정 → 잔차 집합 크기·중요도.
5~8. 소견 추출 → (진단, 소견) 쌍 판정 → 잔차 누적 → 임계 알림.
9. 의학 지식: LLM 의존.  10. 데이터: MIMIC 가능, **정답 없음**.
11. 비교: 이상 결과 개수.  12. 지표: 변경 사건과의 연관(대리).
13. 독창성 위험: 중.  14. 구현 위험: 8 GB 모델 판정 신뢰도 낮음.
15. 실패 원인: 정답 부재로 타당성 입증 불가.  16. 논문 가능성: 낮음(현 환경). 아이디어 1의 비교군으로만 가치.
