# 07. 최종 연구 방향 (2026-11-10)

## 판정: 일부 유지 + 연구 질문 전환

- 유지: "의사 진단 + 이후 증거 → 재검토 신호"라는 목표, 증거 위생 재생 엔진.
- 전환: 질병별 수작업 규칙의 임상 검증 → **자료에서 유도한 진단 조건부 신호를 실제 진단 변경 사건으로 검증**.
- 중단 권고: 그래프·4값 논리를 기여로 내세우는 서술, PE·ACS·심낭염 규칙 추가 확장.
- 전환 이유
  - 전문의 없음 → 규칙의 의학 타당성·재검토 필요성 정답 확보 불가.
  - 자체 결과: 그래프 = 평면 규칙표, 활성 규칙 0, 공개 SCT 연결 0.
  - 문헌: 가용 시각 누출·LLM 갱신 불안정성은 2026년에 이미 발표(R13, R20, R03).
  - 남은 공백: 의사 진단 조건부 + 공개 정답 + 정정 처리 영향.

## 1순위. DxShift — 의사 진단 조건부 증거 누적으로 진단 변경 사건 탐지

- 선택 이유: 로컬 자료만으로 즉시 착수. 정답이 전문의 없이 구성 가능. 유사 공개 연구 미발견. 진단 변경은 사망·재원과 연관 보고(R12).
- 경쟁 연구: R03(EVLU), R01·R09(e-trigger), R12(Hautz), R47(조건부 이상치), R13(EarlyDx).
- 기술적 차별점: 조건 변수 = 의사의 ED 진단. 입력 = 가용 시각·정정·중복 처리된 증거 흐름. 정답 = 코드 불일치 + 의사 서술 전환점 이중 라벨.
- 개발 알고리즘: 진단군별 조건부 우도비의 수축 추정 + 순차 누적 + 보류(03 문서 아이디어 1). 서술 전환점 추출기(아이디어 4).
- 재사용: 재생 엔진, 정정·중복 처리, MIMIC 어댑터, 봉인 규칙, 검사 틀.
- 신규: CCSR 범주화, 변경 라벨, 분포 추정기, 기준선 4종, 추출기.
- 데이터: MIMIC-IV 3.1, ED 2.2, Note 2.2(퇴원요약 추가 다운로드).
- 우월성 검증: "진단 입력 부스팅" 포함 5개 기준선 대비 AUROC·고정 알림률 PPV, 제거 실험 6종, 서술 계기 일치율(05 문서 설계 1).
- 실패 가능성 높은 이유: 변경 라벨이 청구 관행을 반영할 수 있음. Hautz가 예측 난이도 시사. 부스팅이 제안법을 이길 수 있음.
- 실패 시 전환: 라벨 실패 → 서술 라벨 단독 또는 3순위. 방법 실패 → 과제·라벨·음성 결과 논문으로 축소.

## 2순위. 의사 패널 SCT 기준 가능성 갱신의 우도비 분해

- 선택 이유: "근거에 따른 가능성 변화"의 의사 정답을 가진 유일 공개 자료(ER-REASON v1.1.0, 2026-11-02 공개).
- 경쟁: R05 자체 평가, R31(SCT-Bench), R03.
- 차별점: 갱신을 증거 단위 우도비 등급으로 분해, 누적·중복·정정은 결정적 코드.
- 알고리즘: 03 문서 아이디어 2.
- 재사용: 중복·정정 처리, 출처 추적.
- 신규: 로컬 LLM 추론 틀, 등급 보정.
- 데이터: ER-REASON(기여자 심사). 대체: 공개 SCT 174문항.
- 검증: 직접 응답 대비 방향 일치·반대 방향 오류율.
- 실패 이유: 심사 탈락, 8 GB 모델 한계, SCT 연구 포화.
- 전환: 1순위 논문의 외부 보조 분석으로 흡수.

## 3순위(안전). 증거 위생 섭동 감사

- 선택 이유: 자료·코드 모두 보유. 정답 불필요. 완주 가능성 최고.
- 경쟁: R13, R20, R08, R50, R39~R41.
- 차별점: 판독 정정(연결 25,735건)의 하류 영향 정량화. 가용 시각 부분은 재현.
- 알고리즘: 섭동 연산자 3종 + 사건 단위 귀속.
- 재사용: 기존 엔진 거의 전부.
- 신규: 섭동 스위치, 하류 모델 2~3종.
- 데이터: 로컬 MIMIC, Ext-PE.
- 검증: 뒤집힘률, 정정 포함 판독의 PE 상태 오판률.
- 실패 이유: 의미를 바꾸는 정정이 드물 가능성.
- 전환: 기술 통계 중심 자원 논문으로 축소.

## 예상 비판

- "나이브 베이즈와 무엇이 다른가" → 수식 신규성 주장 안 함. 과제·라벨·프로토콜 기여로 한정.
- "진단 변경은 정상 진료 과정" → 맞음. 오류 주장 안 함. 변경 조기 인지의 가치는 R12 연관 근거까지만 인용.
- "ED 진단 코드는 의사의 실시간 가설이 아니다" → 민감도 분석(주호소 기반)으로 범위 확인.
- "단일 기관" → 한계 명시. ER-REASON 접근 시 외부 확인.

## 방향 확정 전 해결할 불확실성 (우선순위순)

1. ED 경유 입원에서 ED 주진단 범주와 퇴원 주진단 범주의 불일치 비율. 5~40% 범위 밖이면 1순위 재검토.
2. ED 진단 중 증상 코드 비율. 과다하면 "구체화" 분류가 대부분이 됨.
3. Ext-PE 판독 중 정정 연결 건수와 정정 지연. 3순위 생사 결정.
4. 퇴원요약 다운로드 가능 여부, 단서 문구 포함 비율.
5. ER-REASON 심사 신청 여부(사용자 결정).
6. MIMIC-IV-ED `diagnosis` 코딩 시점에 대한 공식 문서 기술.

## 실제 다음 행동 (가장 중요한 하나)

- **불확실성 1·2·3을 한 번에 재는 집계 전용 스크립트 1개 작성 → 사용자 검토 → 실행**(예상 수 분, CPU, 집계만 출력).
- 결과에 따라 1순위 확정 또는 3순위 전환.
- 그 뒤 `/rg-plan`으로 사전등록 → `/rg-gate`.
