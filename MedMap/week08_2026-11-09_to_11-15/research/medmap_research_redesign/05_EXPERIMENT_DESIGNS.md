# 05. 상위 3개 방향 실험 설계 (2026-11-10)

공통 규칙
- 실행 전 `/rg-plan` → `/rg-gate` RUN 필요(이 프로젝트는 Research Guardian 활성).
- 환자 행은 봉인 폴더에만. 공개 산출물은 집계, 10 미만 칸 가림.
- 분할은 환자(subject) 단위. 시험 분할은 1회 사용.
- 모든 입력은 가용 시각(storetime) 이하만. ICD 퇴원 코드는 라벨 전용.

---

## 설계 1. DxShift + 전환점 추출 (아이디어 1 + 4)

1. 가설
   - H1: ED 진단 조건부 점수가, 진단을 모르는 같은 입력의 모델보다 변경 사건을 잘 가려냄.
   - H2: 가용 시각·정정 처리를 끄면 성능이 과대 또는 왜곡됨.
   - H3: 알림의 최상위 기여 증거가 의사 서술의 계기 증거와 우연 이상으로 일치함.
2. 데이터: MIMIC-IV 3.1 + ED 2.2 + Note 2.2(영상 보유, 퇴원요약 추가 필요). ED 경유 입원 성인.
3. 접근: credentialed(보유). 퇴원요약 다운로드는 사용자 수행.
4. 입력: ED 주진단(CCSR 범주), ED 퇴실 후 t = 6·12·24·48시간까지 가용한 검사·활력·영상 범주.
5. 정답
   - L1(전체): ED 주진단 범주 vs 퇴원 주진단 범주. 3분류 = 동일 / 구체화(증상→질병, 같은 계통) / 불일치. 양성 = 불일치.
   - L2(부분): 퇴원요약 서술 전환 사건(아이디어 4). 계기 증거 시각 포함.
   - 라벨 타당성 선행 점검: L1·L2 일치도, 표본 200건 2인 독해.
6. 비교 대상
   - B0 이상 결과 개수.
   - B1 중증도 점수(활력 기반).
   - B2 부스팅, 진단 미입력.
   - B3 부스팅, 진단 입력(가장 강한 기준선).
   - B4 로컬 LLM 제로샷(8 GB 한도 모델).
7. 제안: 진단군 조건부 우도비 누적 + 수축 추정 + 보류.
8. 제거 실험
   - 진단 조건 제거(전체 평균 분포 사용).
   - storetime → charttime.
   - 정정 연결 제거(원본·정정 독립 계수).
   - 수축 제거.
   - 결과만 vs 결과 + 주문 사건(의사의 기존 의심 반영분 분리).
   - 보류 규칙 제거.
9. 핵심 지표: t별 AUROC·AUPRC(환자 부트스트랩 CI), 알림률 5%·10% 고정 PPV·민감도, 보류율, 판단 가능 비율, 진단군별 최저 AUROC, L2 계기 일치율(상위 3 기여 내 포함), 알림~계기 시각 차.
10. 실패 판정(사전 고정)
    - L1의 불일치 비율이 5% 미만 또는 40% 초과 → 라벨 정의 재검토.
    - L1·L2 일치 κ < 0.2 → 코드 라벨 폐기, L2 단독.
    - 제안법 AUROC가 B2 대비 +0.02 미만 → "진단 조건화 효과 없음" 보고, 방법 기여 철회.
    - 전 방법 AUROC < 0.65 → "가용 증거로 변경 예측 불가" 음성 결과 보고 후 설계 3으로 전환.
11. 누수 방지: 퇴원 ICD·퇴원요약 입력 금지. ED 진단 코드의 사후 코딩 가능성은 민감도 분석(주호소 기반 진단군으로 대체 실행).
12. 의료적 검증 범위: 없음. 변경 사건 예측력만.
13. 재현성: 코드·분할 해시·사전등록 JSON 동결. MIMIC 공개 자료.
14. 주장 가능: "의사의 ED 진단을 조건으로 한 가용 시각 기준 증거 누적이 진단 변경 사건과 연관됨/되지 않음", "정정·가용 시각 처리의 영향 크기".
15. 주장 불가: 오진 탐지, 임상 정확도, 환자 결과 개선, 알림의 임상 유용성.

예상 소요: 라벨 구축 1~2주, 기준선 1주, 제안법·제거 1~2주. 학습은 CPU 중심.

## 설계 2. SCT 방향 갱신 (아이디어 2)

1. 가설: 우도비 분해 + 위생 계층이 로컬 LLM 직접 응답보다 의사 패널 방향과 더 일치.
2. 데이터: ER-REASON v1.1.0 `sct_test.csv`·`sct_reasoning.csv`(194 내원 × 감별 5).
3. 접근: credentialed + CITI + 기여자 심사. 승인 전 실행 금지. 외부 API 전송 금지 전제.
4. 입력: 사례 맥락, 가설, 단계별 새 정보.
5. 정답: DxUpdate(−2~+2), DxTrajectory(전문의 2명 + 조정).
6. 비교: 최빈 등급, 소견 유무 규칙, LLM 직접, LLM 사슬 추론, 이전 판단 넘겨주기(R03 방식).
7. 제안: 등급 우도비 추출 → 결정적 누적.
8. 제거: 바꿔쓰기 합의 제거, 중복 제거 끔, 사전값 제공 끔.
9. 지표: 방향 일치율, 정확 등급 일치, 반대 방향 오류율, 위험-적용범위 곡선.
10. 실패 판정: 직접 응답 대비 방향 일치 +3%p 미만 또는 반대 방향 오류 증가 → 기여 철회.
11. 누수: 개발·시험을 내원 단위 분할. 가중치 보정은 개발분만.
12. 검증 범위: 패널 일치. 임상 결과 아님.
13. 재현성: 로컬 모델 버전·시드 고정.
14. 주장 가능: "소형 로컬 모델에서 분해 갱신의 방향 일치 효과".
15. 주장 불가: 대형 모델 일반화, 실제 진료 개선.

위험: 심사 탈락 시 설계 무효. 표본 약 970 판단(194×5, 확인 필요)로 검정력 제한.

## 설계 3. 증거 위생 섭동 감사 (아이디어 3) — 안전 대안

1. 가설: 판독 정정을 무시한 파이프라인은 정정 포함 내원에서 하류 판단을 유의하게 뒤집음. 가용 시각 무시는 조기 시점일수록 영향 큼.
2. 데이터: 로컬 MIMIC-IV 영상(정정 25,735건), 검사, Ext-PE 라벨.
3. 접근: 보유.
4. 입력: 내원별 사건 타임라인.
5. 정답
   - 1차: 뒤집힘 자체(정답 불필요).
   - 2차: Ext-PE 급성 PE 라벨(정정이 PE 상태를 바꾼 판독의 올바른 최종 상태).
6. 비교: 위생 완비 대 T·S·D 각 단순 처리.
7. 제안: 섭동 연산자 + 사건 단위 귀속(기존 v5-2A.2 구현).
8. 제거: 연산자 하나씩, 시점 6·12·24시간.
9. 지표: 영향 내원 비율, 뒤집힘률, PE 상태 오판률(정정 포함 판독 한정), 정정 지연 분포.
10. 실패 판정: 정정으로 PE 상태가 바뀌는 판독이 30건 미만 → PE 한정 분석 포기, 전체 영상 뒤집힘 기술 통계로 축소.
11. 누수: 해당 적음.
12. 검증 범위: 입력 무결성. 진단 타당성 아님.
13. 재현성: 상.
14. 주장 가능: "정정·가용 시각 처리 누락의 빈도와 하류 영향 크기".
15. 주장 불가: 진단 성능 개선.

선행 1일 측정(30초~수분): Ext-PE 판독 중 정정 연결 건수, 정정 지연 분포. 이 값이 설계 3의 생사를 결정.
