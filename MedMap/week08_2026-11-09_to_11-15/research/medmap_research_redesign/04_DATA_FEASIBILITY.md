# 04. 데이터 실현 가능성 (2026-11-10)

## 1. 세 가지 정답의 구분

| 정답 종류 | 뜻 | 확보 가능한 자료 |
|---|---|---|
| ① 최종 진단 | 퇴원 시 확정 진단 | MIMIC-IV, eICU, ER-REASON, SDBench, DiReCT |
| ② 근거에 따른 가능성 변화 | 새 정보로 가설이 강해졌는지 약해졌는지 | ER-REASON SCT 194 내원(의사 2명 + 조정) |
| ③ 재검토 필요 여부 | 그 시점에 다시 봐야 했는지 | **공개 자료 없음**. Safer Dx 검토(R01·R09)는 비공개 |
| ③의 대리 지표 | 실제로 진단이 바뀌었는지 | MIMIC-IV에서 구성 가능(ED 진단 vs 퇴원 진단, 퇴원요약 서술) |

- ③ 자체는 전문의 검토 없이는 불가. 현재 환경에서 주장 불가.
- 대리 지표는 "변경 사건"일 뿐 "오진"이 아님. 문서 전체에서 구분 유지.

## 2. 데이터별 정리

### MIMIC-IV 3.1 (로컬 보유)
- 규모: 입원 약 43만 건 수준(R02는 v2.2에서 422,534 입원·180,640 환자 보고).
- 진단: 퇴원 후 확정 ICD(`diagnoses_icd`). 시각 없음. 입력 사용 시 누출(R02).
- 검사: `labevents` charttime(채취)·storetime(결과 저장). 로컬 감사에서 대상 항목 storetime 결측 0.05%, 지연 중앙 76분.
- 주문 시각: `poe.ordertime` 존재(M, 문서 재확인 필요).
- 미생물: 최종 보고 지연 큼(중앙 53.2시간, 2차 요약).
- 결과 열람 여부: 없음.
- 검사 정정 이력: 없음(최종값만).

### MIMIC-IV-ED 2.2 (로컬 보유)
- 규모: ED 내원 40만 건 이상(S).
- ED 진단: `diagnosis` 표, ED 체류 전용 청구 진단. **코딩 시점 미상**(퇴실 후 부여 가능성, 확인 필요).
- triage 주호소·활력징후 있음. triage 시각 열 없음(로컬 감사 메모).
- 의사 최초 가설: 없음. ED 경과기록 없음.

### MIMIC-IV-Note 2.2 (영상 판독문만 로컬 보유)
- 로컬 확인: `radiology.csv.gz`, `radiology_detail.csv.gz`만 존재. **`discharge.csv.gz` 없음** → 다운로드 필요.
- 판독문: charttime·storetime. 로컬 감사 259,099행 중 storetime 결측 0, 역전 68건, 지연 중앙 120분.
- **정정 이력: `note_type='AR'`(addendum) + `radiology_detail`의 `parent_note_id` 25,735건**(로컬 집계). 원 판독과 연결 가능.
- ED 구간 내 영상 24,339건 중 1,779건(약 7%)이 퇴실 후에야 가용, 검사 27,617건 중 1,280건(약 5%) 동일(기존 4질환+비교군 코호트 기준).
- 퇴원요약: 사후 작성. "Brief Hospital Course"에 진단 경과 서술. 입력으로 쓰면 누출, **정답 추출원으로는 사용 가능**.
- 경과기록·ED 의사 기록: 없음 → 문서 간 중복 서술 연구에 부적합.

### MIMIC-IV-Ext-PE (로컬 보유, 사용 완료)
- CTPA 판독문 19,942, 급성 PE 1,591, 의사 2명 κ 0.82.
- 가능 평가: 판독문 → PE 상태 추출 정확도(이미 수행). 재검토 정답 아님.

### eICU-CRD (미보유)
- 2014~2015, 208개 병원 ICU 약 20만 건(M).
- `lab.labresultrevisedoffset`(검사값 수정 시각) 존재(M, 확인 필요) → 검사 정정 시각의 유일한 공개 후보.
- 기록문 빈약, 영상 판독문 없음. ED 진단 없음.
- 가능 평가: 검사 수정 지연 분포 정도.

### ER-REASON v1.1.0 (미보유)
- 공식 페이지 직접 확인(2026-11-10).
- 공개일: v1.0.0 2025-10-23, **v1.1.0 2026-11-02**.
- 규모: 환자 3,437, 내원 3,984, 기록 25,174, 기간 2022-03-01~2024-03-31, UCSF 성인 18~85세.
- 파일: `er_reason.csv`, `sct_test.csv`, `sct_reasoning.csv`, `icd10_codes.csv`.
- 기록 종류: ED 의사 기록, 퇴원요약, 경과기록, H&P, 협진, 영상·심초음파·ECG 판독.
- 정답: 전문의 근거 서술 72건, SCT 194 내원(감별 5개, DxUpdate −2~+2, DxTrajectory).
- 최초 가설: `Rule_Out`은 내원 전 감별(72건 한정). `primaryeddiagnosisname`은 ED 종료 시 진단.
- 검사 시각·정정 이력: 페이지에 언급 없음.
- 접근: credentialed + CITI + DUA + **기여자의 연구 계획 심사**(Contributor Review Health Data License 1.5.0). 승인 여부 가정 금지.
- 기존 조사와 불일치: arXiv v2 본문은 SCT를 기술하지 않음. SCT는 v1.1.0에서 추가된 것으로 보임(확인 필요).
- 이용 제약: 외부 상용 LLM API 전송 가능 여부 미기재 → 로컬 모델 전제.

## 3. 병원 실제 수집 방식 (질문 12개 요약)

| 질문 | 실제 병원 | 공개 연구 자료 |
|---|---|---|
| 최초 진단 가설 저장 | 자유기록(ED 기록 impression)에만. 구조화 드묾 | MIMIC 없음, ER-REASON 기록문 내 |
| 확진/의심 구분 | 문장 표현(hedge)으로만. FHIR Condition.verificationStatus 있으나 입력 품질 미상(M) | R42가 표현 보존 평가 |
| 진단 기록 시각 | 기록 서명 시각. 청구 코드는 사후 | MIMIC ICD 시각 없음 |
| 검사 주문 시각 | 처방전달시스템 보유 | MIMIC `poe`(M) |
| 채취·수행 시각 | 검사정보시스템 보유 | charttime |
| 결과 공개 시각 | 보유(HL7 v2 ORU, FHIR `issued`, M) | storetime(대리 지표) |
| 의료진 열람 여부 | 감사 로그에만(R52). 열람 ≠ 조치 | 공개 자료 없음 |
| 판독 정정 이전본 | 영상정보시스템 addendum, FHIR status `amended`/`corrected`(R55) | MIMIC `AR` 25,735건 |
| 검사 사건 식별번호 공유 | accession 번호. 기록문에는 미기재 | MIMIC note_id 연결만 |
| 새 결과 자동 알림 | HL7 v2 피드, FHIR Subscriptions, CDS Hooks(M). 병원 승인 필요 | 재생(replay) 모사만 |
| 연구들의 연결 방식 | 기관 데이터웨어하우스 직접 질의(R01 VA CDW) | — |
| 병원 간 구조 차이 | OMOP·FHIR 매핑(M). 시각 의미는 기관별 상이 | R20 지적 |

- 외부 연구자가 결과 열람 여부·실시간 피드에 접근하는 경로 없음.
- 따라서 "의사가 결과를 보았는지"는 전 실험에서 **모름**으로 표기.

## 4. 현재 환경에서 가능한 평가 결론

| 평가 목표 | 가능 여부 | 조건 |
|---|---|---|
| 판독문 추출 정확도 | 가능(수행 완료) | Ext-PE |
| 가용 시각·정정 영향 측정 | 가능 | 로컬 MIMIC |
| 진단 변경 사건 조기 탐지 | 조건부 가능 | 변경 라벨 정의 타당성 검증, 퇴원요약 다운로드 |
| 가능성 변화 방향 일치 | 조건부 가능 | ER-REASON 심사 통과 |
| 재검토 필요성(전문의 기준) | 불가능 | 전문의 없음 |
| 임상 정확도·오진 탐지율 | 불가능 | 정답 없음 |
