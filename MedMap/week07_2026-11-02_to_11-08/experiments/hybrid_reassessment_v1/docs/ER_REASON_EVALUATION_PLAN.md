# ER-Reason 평가 계획 (승인 대기, 실데이터 실행 없음)

상태: 연구별 접근 신청 제출(사용자 보고). 로컬에서 승인 확인 불가 → **미승인으로 취급**. 승인 기록 파일 없으면 코드가 데이터 파일을 열지 않음.

## 공개 문서로 확인한 것(실제 파일 미확인)
- v1.1.0: `er_reason.csv`, `sct_test.csv`(194 encounter), `sct_reasoning.csv`, `icd10_codes.csv`.
- `sct_test`: encounterkey, One_Sentence_Extracted, differential_1~5, evidence_1~5. `sct_reasoning`: encounterkey, differential, evidence, dxupdate(-2~+2), rationale, dxtrajectory.
- 논문: 194사례, 787문항, 전문의 2명 + 조정 1명. 단계 수 T1·T2 194, T3 193, T4 128, T5 78. 전문의 등급 정확 일치 52.6%. 논문 모델 zero-shot DxUpdate κ 0.538~0.691(조건 다름, 비교 기준 아님).
- 분할은 논문에 없음.

## UNKNOWN(승인 후 확인)
실제 헤더·값 형식 · 행 단위(문항 수와 일치 여부) · dxupdate 단일값이 문항당 몇 가설에 대응하는지 · 증거 문자열 일치율 · 질환 분포 · 노트별 시각 · 근거 문장 위치.

## 라이선스 제약(공개 본문 확인)
- 라이선스 3조: 제3자에게 접근 공유 금지. 1조: 재식별 시도 금지. 8조: 출판 시 코드 공개.
- PhysioNet 2025-09-24 공지(MIMIC 대상): API 전송을 제3자 공유로 보며 로컬 LLM 강력 권고. ER-Reason 적용 여부는 DUA 전문 확인 필요.
- **결정: 원문은 로컬 스크립트만 처리. Claude Code 세션도 외부 LLM 이므로 원문·행 단위 결과를 읽지 않음. 세션에는 집계만.** 공식 저장소의 OpenRouter 경로는 사용하지 않음.

## 연구 질문 → 지표
| RQ | 지표 |
|---|---|
| RQ1 지지·약화 구분 | 전체 문항 방향 일치, 약화 재현율, 반대 방향 오류 |
| RQ2 DxUpdate 일치 | 선형 가중 카파(논문과 같은 가중치) + 적용 범위 |
| RQ3 적절한 기권 | 기권률, 기권 문항의 전문가 등급 분포 |
| RQ4 구성요소 기여 | 짝 부트스트랩 차이, 조건 충족 시 제거 실험 |
| RQ5 순서 안정성 | 이전 단계 판단 변경률(증거 불변 시 0 이어야 함), 순서 뒤바꾼 입력 비교 |
| RQ6 근거·출처 | 인용이 입력 문구와 일치하는 비율, 표본 감사(방법 별도) |
- DxTrajectory: 엔진이 순위를 내지 않으므로 현재 NOT_EVALUABLE. 순위 출력이 설계된 팔만 별도.
- 전문가 일치 ≠ 임상 재검토 경고 정확도. 단계 증거는 실제 열람 EMR 과 같다고 가정 안 함. 단계 증거는 전문의가 작성한 자료임.

## 분할
사례 단위 해시(`MEDMAP_ER_REASON_SPLIT_V1`): DEVELOPMENT 40% · VALIDATION 20% · HELD_OUT_TEST 40%. 실제 크기로 재확인 후 동결. E0 측정은 전체 가능(개발 전 고정).
세션이 원문을 볼 수 없어 오류 분석은 범주별 집계만 가능 — 규칙 개발 속도·품질의 주요 제약.

## 실행 전 조건
승인 확인 → DUA 전문 확인 → 로컬 다운로드·SHA → 스키마·라벨 의미 확인 → 프로토콜 동결 → 사용 이력 기록 → 모델별 동일 조건 점검 → 외부 전송 차단 확인 → 사용자 승인. 연구 관리 절차(RG) 적용 여부는 그때 사용자 결정.

## 실행 순서
1. E0 무수정 평가 2. 적용 범위·기권률 3. 방향 일치 등 4. DEVELOPMENT 에서 A·B·C·D 비교 5. 오류 유형 집계 6. 검증된 부족 요소만 개선 7. 고정 모델로 HELD_OUT_TEST 1회 8. 논문 정리.

## 준비된 코드
`hybrid/er_reason.py`(승인 확인·스키마 검사·입력/정답 분리·사례 분할), `hybrid/metrics.py`. 실제 파일로 시험한 적 없음.
