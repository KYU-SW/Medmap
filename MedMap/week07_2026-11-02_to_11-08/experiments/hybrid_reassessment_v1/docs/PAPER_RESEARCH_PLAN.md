# 논문 계획 (결과 없음 — 결론 미정)

**가제:** Evidence-Provenance-Aware Diagnostic Reassessment Using a Hybrid Knowledge Graph and Clinical Reasoning Framework

**중심 질문:** 의사 가설 중심의 하이브리드 구조가 단순 규칙·단독 그래프·단독 LLM 보다 새로운 증거의 진단적 의미를 더 정확하고 일관되게 평가하는가? 답이 '아니오'여도 논문 가치가 있도록 설계.

## 구분해서 보고
| 수준 | 현재 근거 | 쓸 수 있는 표현 |
|---|---|---|
| 구현 정합성 | 합성 테스트, 변이 시험 | 구조가 규칙대로 동작 |
| 후향 평가 성능 | 없음 | 쓸 수 없음 |
| 전문가 판단 일치 | 없음(승인 대기) | 쓸 수 없음 |
| 임상적 유용성 | 없음 | 쓸 수 없음 |
| 환자 결과 | 없음, 이 연구로 입증 불가 | 쓸 수 없음 |

## 지금 서술 가능
- 설계: 진단 상태·출처·시간을 분리한 구조, 승격 차단, 기권 우선.
- EXP-02 v3b TEST 결과(원 범위 그대로), EXP-04 의 엔진 한계(소규모·탐색적), 기존 합성 결과.
- 선행연구: ER-Reason, SCT-Bench(McCoy 등), DiReCT, MIMIC-IV-Ext-CDM. 수치는 조건이 달라 직접 비교 금지.

## 결과 필요조건
ER-Reason 승인, 로컬 LLM, 영어 개념 연결, 검증 관계 일부, HELD_OUT_TEST 1회. 그중 하나라도 없으면 기술 보고·프로토콜 논문으로 범위 축소.

## 표본 한계
194사례. 사례 단위 구간이 넓을 가능성. 전문의 정확 일치 52.6% 라 정답 자체의 불확실성 큼. 단일 기관, 사례 구조는 전문의 작성.

## 재현 패키지
코드 공개(라이선스 8조), 자료 비공개, 분할 규칙·프로토콜 SHA·집계만.

## 주장 금지
오진 감소, 예후 향상, 임상 안전성 개선, 불필요 검사 감소, 하이브리드 우월(결과 전).
