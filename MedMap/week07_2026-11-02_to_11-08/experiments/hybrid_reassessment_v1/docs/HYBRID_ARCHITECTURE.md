# 하이브리드 구조 설계

목적: 의사가 확인한 가설을 출발점으로, 새 증거의 의미·출처·불확실성을 의료진이 검토할 수 있게 제시. 진단을 대신하지 않는다.

```
입력(발화·EMR·검사·영상·병리·증상·병력·가족력·환경·경과)
  → L1 해석(추출 후보 + 출처·주체·시점·부정·불확실성, 확정 아님)
  → 공통 구조(EVIDENCE_SCHEMA)
  → L4 시간 엔진(as_of 공개, 정정, 진단 이력, 검사 상태)  ← 모든 판단 입력은 여기를 통과
  → L3 판단(Reasoner 계약: A 규칙 · B 그래프 · C LLM+검색 · D 조합)
        ↑ L2 지식(관계·출처·검토 상태, 공출현·온톨로지 자동 승격 금지)
  → L5 화면(의료진·환자 분리)
```

## 계층별 현황
| 계층 | 재사용 | 신규 구현 | 미구현 |
|---|---|---|---|
| L1 해석 | v3b(PE 영상), STEP29(한국어, 연결 미실행) | 의사 발화 후보·확인 계약 | 일반 추출기, 영어 임상 개념 연결기, 병리·유전 |
| L2 지식 | EXP-01b 그래프(읽기 전용) | 관계 v2 모델·승격 차단 | 실제 검증 관계 내용, 표준 용어 연결 |
| L3 판단 | R1~R9 | Reasoner 계약, A·B·C·D Adapter, 기준선 E0 | 실제 LLM, 지침 규칙, 약화 지식 |
| L4 시간 | EXP-03 규칙 대조 | 공개·정정·진단 이력·검사 상태 | 실제 EMR 이벤트 연결 |
| L5 화면 | 제품 Doctor 화면 별도 존재 | 없음 | 전부(설계만) |

## 핵심 불변식(코드로 강제)
- 미래 입력이 있으면 모든 Reasoner 기권. 시각 없는 증거는 공개 안 함.
- 모델 추출 진단은 의사 확인 전 가설 불가. 배제·과거·UNKNOWN 진단은 현재 가설 아님.
- 기록 없음 = UNKNOWN(시행 안 함·음성 아님).
- 지식·규칙 없음 = 기권. 임시 추론 금지.
- 제한 자료는 승인 기록 있는 로컬 런타임 외 LLM 호출 불가.

## A·B·C·D 역할(가설이며 우월성 전제 없음)
| 접근 | 기대 역할 | 현재 상태 | 예상 약점 |
|---|---|---|---|
| A 규칙·결정트리 | 검증된 조건의 명시적 판단, 설명 가능 | EXP-03 R1~R5 뿐, 시스템 정의, 임상 검증 아님 | 적용 범위 좁음, 규칙 근거 확보 비용 |
| B 그래프 | 관계·출처 추적, 관련성 연결 | SUPPORT 만 가능, 약화 관계 없음, 개념 연결 필요 | 지식 범위, 공출현 편향 |
| C LLM+검색 | 자유 문장 해석, 넓은 범위 | 미구현, 기본 비활성 | 근거 없는 주장, 재현성, 오염 불명 |
| D 조합 | 규칙 우선, 충돌은 UNCERTAIN | 조합 논리만 구현, 구성요소 지식 부족 | 복잡도, 구성요소 합 이상 기여 미증명 |

## 음성 입력(장기)
음성 → STT → 문맥 분석 → 진단 후보 → 확정/의심/배제/과거 구분 → **의사 확인** → 상태 갱신. STT 오류와 추출 오류를 분리 평가. 실제 음성 수집 없음.

## 환자 화면(설계만)
의료진 확인 진단 + 검증된 교육 자료 + 질문 목록 + 증상 기록. 환자 기록은 PATIENT_REPORTED 로만 저장. 특정 검사를 요구하게 하지 않음. 미확인 내용을 사실처럼 표현하지 않음.

## 회복 경과(설계만)
진단·치료 계획·예상 경과·환자 기록·추적 검사·재평가를 연결. 회복 지연만으로 진단 오류로 판단하지 않음(치료·동반질환·개인차 영향). 효과 연구는 별도.
