# 구현 상태

| 기능 | 상태 | 비고 |
|---|---|---|
| 공통 진단·증거·출처·출력 구조 | 구현·테스트 | `schema.py` |
| 진단 상태 이력, as_of 공개, 정정 | 구현·테스트 | `temporal.py` |
| 검사 상태·중복 후보 | 구현·테스트 | 적절성 판단 없음 |
| E0 기존 엔진 Adapter | 구현 | 엔진 어휘 안에서만 답함 |
| A 규칙 Adapter | 구현(규칙 5개, 시스템 정의) | PE·영상 외 기권, 임상 검증 아님 |
| B 그래프 Adapter | 구현 | SUPPORT 만, 약화 불가 |
| C LLM Adapter | **계약만** | 실제 클라이언트 없음 → NOT_IMPLEMENTED. 제한 자료 차단 |
| D 조합 Adapter | 구현(논리만) | 현재 지식 범위 안에서는 A·B 와 같은 범위 |
| 지표·짝 부트스트랩 | 구현·테스트 | 손계산 대조 |
| ER-Reason 적재·분할 | 구현, 합성 자리표시자로만 시험 | 실제 파일 미확인 |
| 지식 관계 v2 모델 | 구현(내용 없음) | 승격 차단만 |
| 의사 발화 후보·확인 계약 | 구현 | 추출기 없음 |
| 영어 임상 개념 연결기 | **미구현** | 없으면 E0·A·B 대부분 기권 |
| 근거 검색, 로컬 LLM 실행 | **미구현** | 모델 다운로드 승인 필요 |
| 지침 기반 규칙·약화 지식 | **미구현** | 출처 확보 필요 |
| STEP29·30 연결 | 조사만 | 한국어·합성 전용, 공식 판정 유지 |
| 추가 검사 추천 | 상태 구조만 | 추천 논리 없음, 효과 주장 없음 |
| 환자 화면, 회복 추적 | 설계만 | 코드 없음 |
| 제품 통합 | 없음 | 제품 코드 무수정 |
