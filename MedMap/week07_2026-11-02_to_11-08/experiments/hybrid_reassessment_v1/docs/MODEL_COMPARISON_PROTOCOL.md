# 모델 비교 프로토콜 초안 (실행 전 동결 필요, 결과 없음)

## 비교 대상
E0 기존 엔진(수정 없음, 기준선) · A 규칙 · B 그래프 · C LLM+검색 · D 조합. D 우월을 전제하지 않는다. 복잡한 모델이 낮으면 그대로 보고.

## 동일 조건
같은 사례·가설·증거 공개 범위·단계·정답·출력 계약·지표. 입력은 `context_summary`, 가설 문구, 현재·이전 단계 증거뿐. 정답·전문가 근거 설명·최종 진단·이후 단계 차단(코드 검사).

## 허용 지식 차이(공개 보고)
| 팔 | 허용 | 오염 위험 |
|---|---|---|
| E0 | 기존 그래프·R1~R9 그대로 | 없음(평가 전 고정) |
| A | 출처 인용 확인된 규칙, DEVELOPMENT 집계로 필요성 판단 | 작성자가 평가 문항을 보면 무효 |
| B | 관계 v2 중 검토 통과분 | 같음 |
| C | 로컬 모델 + 허가 근거 코퍼스 | 모델 학습 자료 **UNKNOWN**. 공개 벤치마크 문항 포함 여부 UNKNOWN |
| D | A+B+C 동일 버전 | 구성요소 위험 합 |

## 공정성 규칙
- 기권 제외 정확도만 비교 금지. 전체 문항 분모 지표를 주 지표로, 조건부는 적용 범위와 함께.
- 지원 못 하는 문항 제외 금지. NOT_IMPLEMENTED 는 그대로 보고.
- 사례 단위 짝 부트스트랩(같은 재표본). 문항을 독립으로 보지 않음.

## 주 지표·부 지표
- 주: 전체 문항 방향 일치(기권 = 불일치), 적용 범위.
- 부: 조건부 방향 일치, 가중 카파(등급 낸 팔만, n 병기), 약화 재현율, 반대 방향 오류율, 기권률, 근거 연결, 근거 없는 주장 비율(표본 감사), 시간 누출, 하위 집단.
- 우월 주장 조건(사전 고정 후보): HELD_OUT_TEST 에서 주 지표 차이의 95% 구간이 0 초과 **그리고** 반대 방향 오류율이 악화되지 않음. 최소 의미 차이는 DEVELOPMENT 분포 확인 전 사용자 결정 필요.

## 제거 실험(ablation)
D 가 답하는 문항이 충분할 때만: Graph·LLM·Rules·Temporal·Retrieval 제거. 지식이 비어 있는 구성요소 제거는 의미 없어 실행 안 함.

## 시간 추적 비교
전체 증거를 한 번에 주는 조건 vs 단계 공개 조건을 별도로 비교. 누출은 입력 단계에서 차단되므로, '시간 추적 제거' 팔은 누출 건수를 측정 항목으로 삼는다.

## 금지
평가 자료를 보고 규칙 수정 후 같은 자료로 독립 성능 주장 · HELD_OUT_TEST 반복 사용 · 공개 벤치마크 수치를 같은 조건 비교처럼 인용.
