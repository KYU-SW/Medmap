# 연구 한계

- 임상 정확도, 전문가 일치, 실제 Working Diagnosis 검증 없음. 가설은 SIMULATED.
- 관계는 세션이 지침 문구를 읽어 만든 것. 의료 전문가 검토 없음. 지침 적용 조건(혈역학 안정, 검사법, 나이 기준 등)을 일부만 코드화.
- 공개 문장 기준 표시는 세션 1인(비전문가). 정답이 아니라 주석 일치.
- 사전 확률은 실행 확인용으로 가정해 넣음. 실제 방향 판단이 아님.
- 공개 증례는 사후 서술, 선택 보고. 실제 판독문·EMR 과 문체가 다름. 지표를 일반화하면 안 됨.
- 1차에서 잘못된 약화 3건 발견 후 수정. 수정 효과는 새 문장으로 **미확인**.
- 규칙 기반이라 처음 보는 표현에 약함. 커버 범위는 PE 파일럿뿐.
- v3b 는 EXP-02 TEST 결과 범위 밖 문장에 적용. 공개 증례 문장 성능은 미평가.
- Hybrid v1 의 SCT 적용 범위 0% 와 이번 결과는 자료가 달라 비교 금지.
- 온톨로지 라이선스 일부 미확인.
