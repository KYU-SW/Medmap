## 미구현
- 임상 확률 자동 판단, 문서 단위 약어 정의, 문장 간 맥락("The latter")
- 증상·활력징후의 방향 판단, 다른 질환 방향 관계
- 근거 검색, LLM(로컬에 임상 LLM 없음, Ollama 없음, GPU 8188 MiB 확인)
- 제품·의사 음성·환자 화면 연결
- ER-Reason 실행(승인 전 안 함)
