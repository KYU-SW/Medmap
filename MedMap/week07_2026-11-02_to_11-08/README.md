## 요약
- **EXP-03 시간 정책**: 검사·영상·진료 기록이 "언제 일어났고 언제 알 수 있었는가"를 구분하는 정책과 합성 시나리오(18개, 체크포인트 65)를 만들었습니다. 실제 MIMIC 데이터에 쓰는 사전 심사(EXP-MAI-003)는 **NEEDS_FIX**로 끝났고, 실제 데이터로는 실행하지 않았습니다.
- **EXP-04**: 진단 재검토를 평가할 공개 자료를 찾았습니다. 그러나 실제 진단 가설, 시간순 근거, 독립 재검토 정답을 모두 갖춘 자료가 없어 **NOT_EVALUABLE**로 판정했습니다. 공개 SCT 174문항과 CC BY 증례 11건으로 질적 확인만 했습니다.
- **하이브리드 재평가 엔진 v1 ~ v5-2A.2**: 질병별 규칙과 근거 그래프로 "의사 가설을 지지·약화하는 근거"를 출처·시점·정정 이력과 함께 계산하는 엔진입니다. 다질환 비교, 검사 사건 단위 근거 묶기, 정정이 어느 판단에 귀속되는지까지 구현했습니다. **새로 활성화한 진단 방향 관계는 0개**입니다(전문의 검토 없음).

## 아직 검증되지 않은 것
- 모든 하이브리드 결과는 **합성 사례** 기준입니다. 그래프 = 평면표 일치는 같은 지식을 두 방식으로 계산했다는 뜻이며, 의학적 정확성이나 그래프 우월성이 아닙니다.
- 문헌 원문 발췌를 모은 지식 파일(`knowledge/`)은 저작권 때문에 올리지 않았습니다. 그래서 일부 실행 코드는 이 저장소만으로는 돌아가지 않습니다.
- EXP-03의 실제 MIMIC 실행 결과는 없습니다. 크기 제한(1 MB) 때문에 `time_v2/disclosure_relations/relations_v2.json`도 빠졌습니다.
