# STEP29.2 마침표 없는 ASR 발화 문장 분리 정책

구현: `scripts/asr_sentence_segmenter.py`(kiwipiepy 로컬, 신규 설치 없음). 수치는 `step29_2_report.md`.

## 경계 규칙(형태소 태그 기준)
- B1 문장부호 SF(. ? !) 뒤 경계. 하위 문장 구간에서 '.'·'!' 는 빼고 '?' 는 남긴다(질문 판정은 '?' 가 의미를 가짐).
  → 같은 의미의 마침표 있음/없음 쌍이 같은 하위 문장 문자열을 갖는다.
- B2 종결어미 EF 뒤에 내용 토큰이 이어지면 경계('열이 났어요 | 오늘은 괜찮아요').
  예외: 인용·전달(EF 다·냐·자·라·래 + 인용 조사 또는 하·그러·그렇 용언, '아프다 그래요'), EF 바로 뒤 '요'는 '요' 뒤에서 자름.
- B3 연결어미/접속조사 + '요'(구어 종결 '-고요'·'-서요') 뒤 경계.
- 연결어미 단독('-고'·'-는데'·'-서')은 문장 경계가 아니다 — 절 경계는 STEP29 clause_segmenter 가 하위 문장 안에서 처리.
- 띄어쓰기·조사 하나만으로 자르지 않는다. kiwi `split_into_sents` 는 비교 기록(`kiwi_agrees`)만 한다.
- 분석 시작(`body_start`)은 문장 앞 감탄사(음·어)·접속부사(그리고·근데)를 건너뛴 위치. 채움말은 `lead_filler` 로 보존.

## 오프셋
- 모든 구간은 원문 code point. 하위 문장 분석 결과의 mention 오프셋은 `span_start += body_start` 로 원문 기준 복원, `raw_span == source_text[s:e]` 를 매번 assert.

## 알려진 한계
- 띄어쓰기를 없앤 '기침이나요'처럼 kiwi 가 종결어미를 다른 품사로 분석하면 경계를 놓칠 수 있다.
- 도치('아파요 머리가')는 뒤 조각이 따로 문장이 된다.
- 실제 ASR 전사문으로 검증하지 않았다(합성 평가만).
