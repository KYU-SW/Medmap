# STEP29.3 의미 구별 규칙

구현: `scripts/semantic_disambiguator.py`(문서열이 규칙 원문). 문자열 유사도가 아니라 술어·부위·양태·동반 단서로 판단하고, 단서가 부족하면 판단하지 않는다(검색기 결과 유지).

| 범주 | 단서 | 결과 |
|---|---|---|
| 구토 계열 | 토하·게워·오바이트·구토 + 혈액('피'(코피 제외)·'혈') + 기침 없음 | hematemesis |
| | + 양태('…ㄹ 것 (만) 같'·'듯'·'뻔'·'토하고 싶') | nausea(실제 구토 아님) |
| | 그 외 | vomiting('토하다'만으로 토혈 확정 금지) |
| 객혈 | 기침·가래 + 혈액 | hemoptysis |
| 가래 | 가래 + 나오·끓·생기, 혈액 없음 | cough |
| 목·인후 | 목 + 통증·불편 술어 + 인후 단서(침·삼키·목구멍·편도·목 안·따끔·칼칼·목소리) | sore_throat |
| | + 경부 단서(뒷목·목덜미·목 뒤·고개·움직·돌리·뻐근·결리·당기) | pain(부위 경부) |
| | 단서 없음 | 판단 안 함 |
| 속 증상 | 속·명치·위 + 쓰리·화끈·타는·따가 | heartburn |
| | + 울렁·메스꺼·미식·느글·구역 | nausea |
| 어지럼 | 어지러·어질어질·아찔·핑 돌·빙빙·빙글('정신이 오락가락'·'헷갈' 제외) | dizziness |
| 결핍 | 팔·다리·손·발 + 힘 + 없·빠지·안 들어가 | limb_weakness |
| | 기운·기력 또는 몸·온몸 + 힘 + 없·빠지 | fatigue |
| 떨림·오한 | 떨리 + 추위 단서 또는 몸·온몸 | chills |
| | 떨리 + 손·손가락·팔·다리·입술·눈꺼풀, 추위 없음 | SILVER 떨림(HP:0002378 손 / HP:0001337), 모델 입력 불가 |
| 비증상 | 날씨·기온·바람·방·에어컨 + 춥·쌀쌀·덥 | 증상 아님 |
| | '…ㄴ지/는지 헷갈리·모르' | 인식 표현(혼동 증상 아님) |

- 연결이 이미 있고 규칙과 다를 때: 같은 증상군의 일반↔특이(통증↔속쓰림·인후통, 피로↔피로·몸살 E_175, 어지럼↔E_82, 호흡곤란↔E_75, 피로↔사지 근력 저하)는 기록만(`semantic_refinement`).
  그 외 충돌은 R2 에서는 기록만(`semantic_conflict`), N4·R3·R4 에서는 보류(UNCERTAIN, SEMANTIC_CONFLICT_HOLD).
- 규칙은 개발 자료(DEV29_3·노출 회귀 사례·STEP29.2 HOLDOUT 오류)에서 만들었고 같은 작성자가 평가 세트를 만들었다 — 일반화는 FROZEN 결과로만 본다.
