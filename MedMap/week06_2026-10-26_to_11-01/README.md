# 6주차 (2026-10-26 ~ 11-01, 진행 중) — 메인 AI 연구: 질문 선택 실험(EXP-01)과 의료 관계 그래프 추론(EXP-01b)

## 요약
- **EXP-01(사전등록 실험, FINAL 1회 완료)**: 같은 우도표에서 "물어본 음성 답을 반영하는가", "사후비가 낮은 질환의 확인 질문을 미루는가" 등을 한 번에 하나씩 바꿔 비교했습니다. 음성 답 반영은 Top-5를 **+12.1 %p** 올리고 전체 중증 누락을 **−15.0 %p** 줄였지만, 폐색전증 누락이 늘어 사전 규칙상 **SAFETY_HOLD** → 채택 모델은 기본형(C)입니다.
- **EXP-01b(의료 관계 그래프 추론, 탐색)**: 실제 그래프 경로로 근거·조건·출처를 추적하는 추론 엔진을 만들고, HSDN·DisMech·HPO 지식과 DDXPlus 환자 입력을 연결했습니다. 하지만 4질환 판별력은 거의 없었습니다(정답 1위 20~23 %, 무작위 25 %). 원인은 정렬 방식이 아니라 **질환별 판별 근거 부족**으로 확인했습니다.

## EXP-01 FINAL 핵심(합성 DDXPlus 시뮬레이션, 임상 성능 아님)
| 모델(질문 5개) | Top-5 | 중증 누락 |
|---|---|---|
| A(기존 MedMap 엔진, 정보 조건 다름) | 0.9985 | 0.04 % |
| C(양성 근거만) — **채택** | 0.8130 | 18.73 % |
| PA(+물어본 음성 답) | 0.9344 | 3.72 % |
| PB(+사후비 기준 확인 질문 하향) | 0.9402 | 3.91 % |
- 폐색전증(n 2,666) 누락: C 0 → PA 144 → 사전 등록한 질환별 안전 규칙으로 SAFETY_HOLD.
- 사후비 하향(τ)은 지표 변화 없이 계산량 0.60배. 의사 진단 확인 질문 우선은 중증 누락 +3.7~4.4 %p.
- **입증하지 않은 것**: "그래프 추론 효과"(EXP-01 계열은 확률표 기반), A 대비 우월(입력 정보가 다름), 임상 성능.
