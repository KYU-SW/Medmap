# EXP-01 ~ EXP-06 실험 계획(사전 설계, 미실행)

표기: **[사실]** 파일·코드 확인 · **[문헌]** 문서 근거 · **[가설]** · **[제안]** 미검증.
공통 규칙은 `protocol.md`(분할·누출·지표·재현성). 모든 실험은 실행 전 RG `rg-plan → rg-gate RUN` 을 받는다.

공통 분할(DDXPlus, `protocol.md` §1):
`TRAIN16` = STEP16B 해시 규칙의 train 820,939행 · `SELECT` / `FINAL` = STEP16B holdout 204,663행을 새 해시로 반분.
공식 validate(반복 사용 이력)·공식 test(STEP13B 1회 개봉, 사용자 규칙상 미개봉 유지)는 사용하지 않는다.

## EXP-01 증상 중심 트리 vs 관계 그래프 (DDXPlus)

| 항목 | 내용 |
|---|---|
| 1 가설 | **[가설]** 같은 질문 예산에서 질환·증상 관계 그래프 + 부정 정보 탐색은 증상 루트 결정 트리보다 Top-5 재현율이 높고 중요 후보 누락률이 낮다 |
| 2 데이터 | DDXPlus en train 파일만(`TRAIN16`/`SELECT`/`FINAL`) **[사실: 1,025,602행, 49질환, 223근거]** |
| 3 정답 | 있음: PATHOLOGY(단일 정답), DIFFERENTIAL_DIAGNOSIS(시뮬레이터 감별 분포) — 합성 라벨 |
| 4 기준 | Baseline A(STEP16B MODEL_k + INTERNAL_IG), B(증상 루트 결정 트리), C(관계 그래프 탐색) — 상세 `exp01_predesign.md` |
| 5 알고리즘 | Proposed A(그래프+음성), B(관계 유형+조건 가지치기), C(+WD 부분그래프) |
| 6 지표 | 후보 재현율@5·@8, Top-1/3/5, 중요 후보 누락률(severity ≤2), 부정 정보 반영, 질문 수, 탐색 노드 수, 추론 시간, 잘못된 분기 종료율, 보정(ECE·Brier, 측정만) |
| 7 안전성 | 잘못된 분기 종료율(정답 질환이 비활성화된 뒤 끝까지 재활성 안 됨) + 합성 규칙 시나리오(알려진 정답 규칙 주입)에서 잘못된 가지치기율 |
| 8 누출 | conditions.json 을 모델 입력에 쓰면 순환 → 주 팔 금지. DIFFERENTIAL_DIAGNOSIS 입력 금지. 분할 간 동일 프로필 중복률 보고 |
| 9 자원 | CPU 전용. 우도표 49×(답변 열) 소형, 결정 트리 학습 수 분, RAM < 4 GB **[제안: 추정, 미측정]** |
| 10 실행 가능 | **가능** — 데이터·기존 코드(STEP16B 모델·IG 표·시뮬레이터) 로컬 확인 **[사실]** |
| 11 추가 데이터 | 없음 |
| 12 판정 | 성공: Proposed A − Baseline C 의 Top-5 재현율 차 95% CI 하한 > 0 **그리고** 중요 누락률 비열등(+0.5%p 이내). 실패: CI 가 0 포함 또는 누락률 악화. 복잡한 그래프라는 이유만으로 우수 판정 금지 |

## EXP-02 환자별 그래프 ↔ 질환별 그래프 근거 연결 (MIMIC)

| 항목 | 내용 |
|---|---|
| 1 가설 | **[가설]** source·시간을 보존한 환자 그래프를 질환 그래프에 연결하면, 같은 출처 중복을 묶지 않은 연결보다 근거 과대계산이 줄고 ICD 라벨과의 정합이 높아진다 |
| 2 데이터 | MIMIC-IV-ED 2.2(triage·vitalsign·diagnosis·edstays), hosp labevents·d_labitems·admissions·patients, Note radiology(+detail), ECG-ext-ICD 라벨 **[사실: 헤더·열 일치 확인]** |
| 3 정답 | 부분: ED `diagnosis` ICD(ED 코딩), ECG 연결 stay 의 `all_diag_hosp`. **hosp `diagnoses_icd` 미보유 [사실]** → 입원 전체 진단 라벨 없음. 코딩 라벨은 임상 Gold 아님 |
| 4 기준 | 평면 bag-of-findings(출처 무시) · 시간 무시 연결 |
| 5 알고리즘 | Observation 스키마 적재(source_id=specimen_id/note_id/study_id), as_of 시점 질의, source 단위 우도 묶음 |
| 6 지표 | 연결 정밀도(수작업 감사 표본), 중복 근거 비율, as_of 누출 0건 검사, ICD 상위 k 재현율 |
| 7 안전성 | 잘못된 연결(다른 stay·미래 기록) 0건 검사기, 연결 오류 표본 감사 |
| 8 누출 | storetime 기준 시점 필터, 같은 subject 의 여러 stay 는 같은 분할(**환자 단위 분할**), 검사 시행 여부 자체를 질환 신호로 쓰지 않음(선택 편향 별도 보고) |
| 9 자원 | labevents 2.59 GB gz 스트리밍 필요(/mnt/c 대량 I/O 느림 → 1회 추출 후 리눅스 쪽 parquet 캐시 권장, RAM 90% 상한) |
| 10 실행 가능 | **조건부** — ED 범위(흉통·호흡곤란 등)로 한정하면 가능. 증상은 triage `chiefcomplaint` 짧은 원문뿐 → 증상 구조화가 선행 과제 |
| 11 추가 데이터 | hosp `diagnoses_icd`·`d_icd_diagnoses`(같은 MIMIC-IV 3.1 자격으로 내려받기 가능 — 사전 승인), 필요시 MIMIC-IV-Ext-DiReCT |
| 12 판정 | 성공: 누출 검사 0건 + source 묶음이 중복 근거 비율을 줄이고 ICD 재현율 비열등. 실패: 연결 감사 정밀도 < 사전 기준(예 0.95) |

## EXP-03 원본 텍스트 vs 구조화 그래프 vs 결합

| 항목 | 내용 |
|---|---|
| 1 가설 | **[가설]** 판독·병력 원문 + 그래프 결합이 각각 단독보다 진단 후보 재현율이 높다 |
| 2 데이터 | MIMIC-IV-Ext-Cardiac-Disease 1.0.0(HPI·physical_exam·chief_complaint·영상/ECG 요약 + ICD) **[사실: 헤더 확인]**, Note radiology |
| 3 정답 | 부분: cardiac-ext `heart_diagnoses_all(_true)` ICD — 데이터 문서 확인 필요(라벨 정의 **확인 필요**) |
| 4 기준 | 텍스트 단독(BM25/TF-IDF + 선형), 그래프 단독(EXP-02 구조화) |
| 5 알고리즘 | 텍스트 임베딩(로컬 모델) + 그래프 특징 late fusion, 근거 문장 포인터(provenance) |
| 6 지표 | Top-k 재현율, 근거 포인터 정확도(감사 표본), 보정 |
| 7 안전성 | 근거 포인터가 실제 문장을 가리키는지 검사, 부정문(negation) 오분류 감사 |
| 8 누출 | 퇴원 시점 서술(진단명 직접 포함)을 입력에서 제거 — HPI/PE 만, 판독은 판단 시점 이전 storetime 만. 진단명 문자열 마스킹 검사 |
| 9 자원 | 소형 인코더 추론 GPU 8 GB 이내 **[제안]** |
| 10 실행 가능 | **조건부** — 라벨 정의·외부 LLM 사용 금지(로컬 모델만), 원문 열람은 PhysioNet DUA 범위 |
| 11 추가 데이터 | MIMIC-IV-Ext-DiReCT(진단 추론 주석) 권장, discharge note(Note 2.2 discharge) 미보유 |
| 12 판정 | 성공: 결합 − 최고 단독 Top-5 차 CI 하한 > 0. 실패: 차 없음 또는 누출 마스킹 후 성능 붕괴 |

## EXP-04 베이즈 갱신 + 정보가치(VOI) 탐색 (DDXPlus → MIMIC)

| 항목 | 내용 |
|---|---|
| 1 가설 | **[가설]** 오분류 비용(중증도 가중)을 넣은 VOI 질문 선택이 순수 IG 보다 중요 후보 누락률을 줄인다(같은 질문 수) |
| 2 데이터 | DDXPlus(`TRAIN16`/`SELECT`/`FINAL`) |
| 3 정답 | 있음(합성) |
| 4 기준 | INTERNAL_IG(STEP16B, **[사실]** 1Q recovery 0.459 vs RANDOM 0.053 — `12_summary.json`) |
| 5 알고리즘 | 나이브 베이즈 사후확률(EXP-01 우도표 재사용) + 기대 손실 감소(VOI), 중지 규칙(VOI < 질문 비용) |
| 6 지표 | 중요 누락률, Top-k, 평균 질문 수, 보정(ECE·신뢰도 곡선) |
| 7 안전성 | 중지 규칙이 중증 질환 미확인 상태에서 멈춘 비율 |
| 8 누출 | 비용 행렬은 severity(conditions.json)에서 오는 **평가용 메타데이터** — 이를 쓰는 VOI 팔은 "비용 지식 사용"으로 명시, 증상 지식은 쓰지 않음 |
| 9 자원 | CPU, 소형 |
| 10 실행 가능 | **가능** |
| 11 추가 데이터 | 없음(MIMIC 확장 시 검사 비용·위험 정보 필요) |
| 12 판정 | 성공: 같은 평균 질문 수에서 중요 누락률 차 CI 상한 < 0, Top-5 비열등 |

## EXP-05 선택적 근거 검색(RAG) + 강화학습 탐색 정책

| 항목 | 내용 |
|---|---|
| 1 가설 | **[가설]** (a) 불확실할 때만 검색하는 RAG 가 항상 검색보다 같은 정확도에서 호출 수가 적다 (b) 시뮬레이터에서 학습한 RL 정책이 탐욕적 IG 보다 다단계 성능이 높다 |
| 2 데이터 | DDXPlus(시뮬레이터 환경), 근거 코퍼스: 기존 `research/safety-net-rag` 브랜치 자산(재사용성 **확인 필요**), HPO·HSDN |
| 3 정답 | 진단: 있음(합성). 검색 근거의 정답성: 없음 → 감사 표본 필요 |
| 4 기준 | 탐욕 IG, EXP-04 VOI, 항상 검색/검색 안 함 |
| 5 알고리즘 | POMDP 정식화(상태=관측, 행동=질문/검색/종료), 정책 학습(PPO 또는 DQN, 소형) |
| 6 지표 | Top-k, 중요 누락률, 질문·검색 호출 수, 학습 seed 간 분산(평균±std) |
| 7 안전성 | 종료 행동이 중증 후보 미배제 상태에서 일어난 비율, 보상 해킹 점검 |
| 8 누출 | 보상 계산에 정답 사용은 학습 시만, 평가 시 정책 입력에 정답·DIFFERENTIAL 금지. 시뮬레이터 = 데이터 생성기와 같음 → 합성 성능을 임상 성능으로 표현 금지 |
| 9 자원 | GPU 8 GB 소형 정책, 여러 seed — 장시간 → wait_for_resources + ram_guard |
| 10 실행 가능 | **조건부** — RL 라이브러리(gymnasium 등) 미설치 **[사실: pip 목록]**, 설치 승인 필요. 외부 LLM RAG 는 과금·데이터 정책상 금지 → 로컬 검색만 |
| 11 추가 데이터 | 근거 코퍼스 라이선스 확인 |
| 12 판정 | 성공: RL − IG 다단계 Top-5 차 CI 하한 > 0 (seed ≥ 3 평균) **그리고** 안전 지표 비악화 |
