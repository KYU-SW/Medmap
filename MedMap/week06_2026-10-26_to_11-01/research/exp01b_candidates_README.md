# EXP-01b 후보: 실제 다중 경로 의료 관계 그래프 추론 (별도 탐색 연구 — 미등록·미구현)

출처: EXP-01 독립 코드 감사(2026-10-27). EXP-01 의 C·PA·PB 계열은 확률표 기반 나이브 베이즈 + 휴리스틱 질문 선택이며
그래프 추론이 아니다(EXP-MAI-001 manifest rev6 expected_claim). 이 문서는 별도 탐색 연구 후보의 범위만 적는다.
실행 전 RG rg-plan → rg-gate 필요. EXP-01 SELECT·FINAL 결과를 보고 이 설계를 조정했다면 그 사실을 기록하고 EXPLORATORY 로 둔다.

## 추가 구현해야 할 그래프 기능
| 기능 | EXP-01 현재 | EXP-01b 에서 필요한 것 |
|---|---|---|
| 명시적 그래프 구조 | 질환×근거 확률표(행렬) | `common/evidence_graph.py` 의 노드·간선(증상·질환·아형·검사·소견)을 실제 추론에 사용 |
| 다중 경로 | 없음(질환별 독립 점수) | 같은 질환에 이르는 여러 증상 경로(AND/OR 조건)를 경로 단위로 평가·재사용, 경로 간 근거 공유 처리 |
| 관계 유형 기반 점수 | 관계 유형은 질문 선택에만 | SUGGESTS·ARGUES_AGAINST·EVALUATED_BY·SUBTYPE_OF 를 점수(또는 메시지 전달)에 반영, 유형별 가중을 TRAIN16 에서만 학습 |
| 의존 근거 처리 | 독립 가정(나이브 베이즈) | 부모-자식·상관 근거의 중복 계산 방지(조건부 우도 또는 근거 묶음) |
| 범주형·하위 질문 | 그래프 계열은 이진 질문만 | 범주형 값 노드(통증 위치 등)와 하위 질문 경로 — A 와 같은 질문 풀 |
| 그래프 탐색 질문 선택 | 상위 8 후보 연결 합 휴리스틱 | 경로 완결도·판별력 기반(예: 그래프 위 기대 정보이득) |
| 조건 기반 가지치기 | 사후비 τ 하향 | 규칙 층의 명시적 필수 조건 불충족 시 하위 경로 비활성·재활성(합성 시나리오에서만 안전성 평가) |
| 출처·시간 | 없음 | Observation source_id·recorded_at(MIMIC 확장 대비) |

## 공정 비교 조건(사전 고정 후보)
- 같은 질문 풀(범주형 포함)·같은 입력(AGE·SEX 사용 여부 통일)·같은 학습 분할(TRAIN16)·같은 예산.
- 기준: A_BINARY_ONLY(STEP16B BINARY_ONLY_IG 와 같은 조건) 와 그래프-이진, A 와 그래프-전체 질문 풀을 각각 짝지어 비교.
- 지식원 순환: release_conditions 를 그래프로 쓰는 팔은 ORACLE 로만.
- 평가 분할: EXP-01 의 SELECT·FINAL 은 이미 노출 — 새 분할 규칙(예: TRAIN16 내부 재분할)과 FINAL 1회 규칙을 새로 사전등록.
