## 3. 15개 질문 답변

**Q1. 논문 오류는 이미 알려진 문제인가?** — **예**.
- [초록] LLM 형식화의 비충실성은 autoformalization 분야의 중심 문제(S03·S06·S07·S25). 지침 형식화에서 "coverage가 충실성을 못 가린다·기본값 대입"은 GuidelineForge가 정면으로 지적(S05). NICE→ASP에서도 "부분 누락"이 주 오류(S08) — 대상 논문 "맥락 손실"과 같은 계열
- [초록] 용어 매핑 오류(개체 접지)는 SNOMED/RxNorm LLM 매핑 연구에서 반복 보고(모호어·세분화 차이·약어)

**Q2. 해결하는 기존 기술** — 오류 유형별:
| 오류 유형(비율) | 기존 기술 | 해결 정도 |
|---|---|---|
| 술어 왜곡(12.6%) | round-trip SMT 동치(S03), 다중 샘플 동치 군집(S04·S06), 반례 기반 수리(S04), Logic-LM self-refine(S21) | 대부분 탐지 가능 [가설: 이 데이터에서 미실측] |
| 행동 정렬 오류(8.1%) | 스키마 제약 출력, 허용 permission 열거, 다중 샘플 일치 | 공학 문제 |
| 개체 접지 실패(19.6%) | RAG·SapBERT류 용어 연결, UMLS/RxNorm API, 사람 검토 | 부분 해결(분야 공지 한계) |
| 맥락 손실(56.7%) | 원문 문장 연결·거부 측정(S05), NLI drift(S03 보조), 섹션 단위 입력 | **자동 검출 미해결** (4절) |
| 충돌 판정(형식 규칙 이후) | SAT/SMT(S12), KB anomaly 검사(S13) | 해결 |

**Q3. 남는 이유** — 계산 아님. **데이터·구현** 쪽.
- [가설] 맥락 손실은 문장 단위 추출(저장소 `lsh_cluster.py`로 문장 군집 후 추출)이 섹션 제목·모집단 한정어·앞 문단 전제를 떨어뜨리는 입력 설계 문제
- [원문] 정답 생성 과정(전문가 수, 일치도)이 기술되지 않아 오류율 자체의 신뢰구간이 없음

**Q4. 강한 기존 방법으로 대부분 해결되는가?** — **조건부 예**. 형식 규칙이 정확하다면 충돌 탐지는 자명(Q14). 형식화 오류 중 약 43%(접지·왜곡·정렬)는 기존 기술 범위. 나머지 57%(맥락 손실)는 round-trip으로 못 잡음(4절) — 하지만 그것을 잡는 데 "새 계산 방법"이 필요하다는 근거도 없음.

**Q5. 새 알고리즘이 꼭 필요한 오류가 있는가?** — **현재 근거 없음**.
- 유일한 후보: "형식화와 back-translation이 함께 같은 맥락을 빠뜨리는 공통 누락"(4절). 그러나 이 탐지는 원문 단락 ↔ 규칙 간 함의 검사(NLI) 또는 범위 상속 규칙(섹션 → 권고)으로 접근 가능하며, 이는 NLP 공학·평가 문제다 [가설]

**Q6. 기존보다 나은 계산 방법을 정의할 수 있는가?** — **현재 정의 불가**. "맥락 손실 탐지"를 계산 문제로 쓰면 = "원문 단락 P가 규칙 R의 조건보다 더 좁은 모집단을 함의하는가" → 함의 판정(NLI) + 술어 포함 관계(SMT 함의, 대상 저장소 `check_implication`이 이미 구현). 결합일 뿐 새 계산 아님 [가설]

**Q7. 단순히 더 좋은 LLM 아닌가?** — **위험 높음**.
- [원문] 대상 논문 핵심 결과는 "LLM 단독 0.08–0.19 recall vs 파이프라인 0.898" — 그러나 비교 대상이 **쌍 판정을 하는 LLM**이지 다른 neuro-symbolic 방법이 아님. Logic-LM·SatLM·VERIMED식 기준선이 없음
- [가설] 개선 연구를 하면 성능 향상의 큰 몫이 형식화 LLM 교체(DeepSeek-V3.1 → 상위 모델)에서 나올 가능성이 큼. LLM 고정 ablation 없이는 기여 분리 불가

**Q8. 의료지식·수작업 규칙 추가 효과 아닌가?** — **위험 높음**.
- [실행] 저장소는 `terms.json`·`meds.json`·`predicates.json`(표준 라이브러리)을 런타임에 읽지만 파일이 없음. 금 규칙이 참조하는 술어 394개의 형식 정의가 미공개 → 원 논문의 성능에 수작업 사전이 얼마나 기여했는지 확인 불가
- [가설] 개선안이 맥락 상속 규칙·용어 사전 보강이면 "지식 공학 투입 효과"로 해석될 것

**Q9. 검증 데이터가 개발에 쓰였나?** — **확인 필요, 순환 위험 높음**.
- [원문] 226쌍은 "후보 규칙 쌍을 전문가가 검토해 오분류 교정" → 후보 생성이 파이프라인 자신(LSH 후보) → 정답이 시스템 출력에 정박(anchoring)됨. 시스템이 후보로 내지 않은 충돌은 정답에 들어갈 길이 없어 recall이 과대 추정될 수 있음
- [원문] 프롬프트 튜닝에 벤치마크 사용 여부 미기재. 하향 표본으로 유형 분포가 인위적

**Q10. 독립 정답** — **현재 없음**. 금 규칙 563건은 저자 측 교정본이고 쌍 라벨은 미공개. 독립 정답은 구현자 아닌 임상의 2인 이상이 원문 지침에서 직접 쌍을 열거해야 하는데, 원문 지침 접근·저작권(Q13·9절)이 선결 조건.

**Q11. 계산 성능 향상의 의료적 의미** — **약함**.
- [원문] F1은 "규칙 쌍 관계 분류" 지표. 환자 결과·처방 오류 감소와 연결된 근거 없음
- [실행] 아래 계산에서 보듯 "Local Conflict"는 서로 다른 질환 조건을 가진 반대 극성 규칙 쌍이면 정의상 대량 발생. 상당수는 임상적으로 이미 알려진 상황별 분기(예: eGFR 구간별 약물 선택)일 가능성 → 임상적으로 의미 있는 충돌의 비율은 미측정 [가설]

**Q12. 임상 효과 과장** — **예(경미~중등도)**. "logical verification이 retrieval보다 먼저 와야 한다", "단일질환 지침이 다루지 않는다"는 결론은 226쌍·1개 약물군·중국 지침에서의 쌍 분류 결과로 일반화 범위를 넘음. 임상의 판단·환자 사례 평가 없음 [원문 기반 판단].

**Q13. 원본 동일 설정 비교 가능성** — **불가능(현재)**.
- [실행] 공개된 것: 규칙 563건, 파이프라인 코드. 없는 것: 226쌍 라벨, 술어·용어 표준 라이브러리, 원문 지침 텍스트, 실행 스크립트·프롬프트 로그, 시드
- [실행] LLM 호출은 OpenRouter `deepseek/deepseek-v3.1-terminus`(유료) — 과금 승인 없이 실행 불가. 모델 버전 고정 불가(서빙 측 변경)
- "저장소 공개 = 전체 평가 재현 가능"은 **거짓**

**Q14. 새 모델 없이 제약 해결기로 해결 가능한가?** — **충돌 판정 부분은 예**.
- [실행] 금 규칙 563건으로 메모리 내 계산(파일 미생성, 극성 분류는 E 임의 정의: recommend/allow/consider/continue/require/start_low_dose/increase_dose/titrate = 양, avoid/contraindicate/stop = 음; 술어를 독립 불리언으로 가정):
  - 같은 약물 대상 + 반대 극성 쌍 6,025 / 전체 158,203쌍. 그중 조건 술어 집합이 서로소 5,061(84%), 공유 964. 출처 지침이 다른 쌍 5,025
  - 해석: 술어가 서로소이고 상호배타 제약이 없으면 두 조건은 동시 만족 가능 → 정의상 "동반질환에서만 생기는 충돌(Local)". 즉 **Local 우세(90.6%)는 상당 부분 정의와 지침의 전문분야 분할 구조에서 기계적으로 나오는 결과**일 수 있음 [가설]. 단 이 수치는 술어 정의·mutex를 모르는 상한 근사로 논문 수치(2,442)와 직접 비교 불가
- 형식 규칙만 정확하면 SAT/SMT + 행동 비호환 표로 끝남(Bowles 2019, Preece 1994와 동형)

**Q15. 기여는 알고리즘/데이터셋/평가 방법 중 무엇인가?** — 대상 논문: **데이터셋 + 응용 파이프라인**(taxonomy는 KB 검증 분류의 의료 재명명에 가까움). 팀이 남길 수 있는 것: **평가 방법·독립 정답 데이터셋**. 알고리즘은 아님.

## 4. 핵심 확인: autoformalization 충실성 검증이 이 오류 유형을 이미 다루는가

| 기법 | 다루는 오류 | 맥락 손실을 잡는가 |
|---|---|---|
| Round-trip + SMT 동치(S03) | 번역 단계의 의미 변형, 연산자·한정어 오류 | **못 잡음**: 원문 문장 자체에 전제가 없으면 F1 → NL' → F2 모두 같은 누락을 공유해 동치 통과. 저자도 "두 형식화가 함께 틀리면 통과" 인정(2차 요약) |
| 다중 샘플 일치(S04·S06·S23) | 샘플 간 해석이 갈리는 모호성 | **못 잡음**: 입력에 맥락이 없으면 모든 샘플이 일관되게 같은 누락 |
| SMT 동치 검사(대상 저장소도 보유) | 술어 간 동치·함의 | 동치 판정 도구일 뿐 |
| NLI drift(S03 보조) | 원문 ↔ back-translation 의미 차이 | 원문 범위를 문장 → 단락으로 넓히면 부분적으로 가능 [가설] |
| 원문 연결 + 거부 측정(S05) | 근거 없는 규칙, 기본값 채움 | 부분(사람 검토 보조) |

결론: 술어 왜곡·연산자 오류 계열은 **이미 다루어짐**. 맥락 손실(대상 논문 최대 오류)은 기존 충실성 검증의 **구조적 사각지대**. 다만 이는 "검증 기준(원문 범위)을 어디까지 잡느냐"의 평가 설계 문제이지 새 solver 알고리즘 문제가 아님 [가설].

## 5. 기존에 해결된 부분

- 형식 규칙 쌍의 충돌·중복 판정(SAT/SMT, KB anomaly 검사)
- 번역 단계 비충실성 탐지·수리(round-trip, 다중 샘플 동치, 반례 수리)
- 지침 형식화 결과의 원문 추적·거부 측정(GuidelineForge)
- 복합질환 다중지침 충돌 탐지 프레임(MitPlan·GoCom·TMR4I·Bowles) — 이전 탐색 재확인

## 6. 미해결 부분 (근거 있는 것만)

1. [원문] 지침 형식화 오류의 최대 범주(맥락 손실 57%)를 자동으로 검출하는 방법의 정량 평가 — 대상 논문은 수작업 감사로만 측정
2. [원문+실행] 다중지침 충돌 탐지에 대한 **독립 정답** 벤치마크 부재(대상 논문 정답은 시스템 후보에 정박, 라벨 미공개)
3. [원문] neuro-symbolic 기준선(Logic-LM·SatLM·VERIMED·round-trip)과의 정면 비교 부재 — 대상 논문은 LLM 단독만 비교

## 8. 기존 방법으로 대체 가능한 부분

- 충돌 판정 엔진(Z3) → 어떤 SMT/SAT로도 동일
- 술어 동치·함의 격자(`analyzer.py` PredicateLattice) → 표준 SMT 질의
- LSH 후보 축소 → 표준 근사 최근접 탐색
- 술어 왜곡 탐지 → round-trip(S03) 또는 다중 샘플 SMT 동치(S04) 그대로 적용
- taxonomy → Preece 분류(redundancy/subsumption/ambivalence) + "동시 만족 가능성이 동반질환에서만 성립" 조건 한 줄

## 10. 강력한 반론 (이 연구를 하지 말아야 할 이유)

1. **재현 불가 위에서 개선 주장 불가**: 기준(226쌍)이 없으므로 "원 논문보다 낫다"는 문장을 쓸 수 없음. 자체 벤치마크를 만들면 그 순간 원 논문과 비교가 끊김
2. **경쟁 선점**: 충실성 검증(S03 ICML 2026, S04 의료기기), 지침→CQL 충실성(S05 NeurIPS 2026 워크숍)이 2026년에 이미 나옴. 남은 틈은 좁고 빠르게 닫히는 중
3. **개선 = 더 좋은 LLM·더 많은 사전 위험**(Q7·Q8): 비용 통제 없이 성능 향상을 방법 기여로 주장하면 심사에서 바로 반박됨
4. **맥락 손실은 NLP 정보추출 문제**: 섹션 상속·모집단 추출은 기존 IE 문헌 영역 [미검증이나 가능성 높음]. neuro-symbolic 신규성으로 포장하기 어려움
5. **Local Conflict 다수는 구조적 산물일 수 있음**(Q14 실행): 충돌 수 증가를 "발견"으로 주장하면 반박됨
6. **라이선스·저작권**: 코드·정답 재사용 허가 없음, 원문 지침 보호 가능성 → 공개 벤치마크 작성 자체가 막힐 수 있음
7. **유료 LLM**: 원 설정 재실행은 과금 승인 대상, 모델 버전 고정 불가

## 11. 연구 중단 기준

다음 중 하나라도 해당하면 중단(또는 평가 연구로만 축소):
- S1. 맥락 손실 자동 검출을 정량 평가한 기존 연구(지침 IE·PICO·CQL 충실성)가 확인됨
- S2. round-trip(S03) 또는 다중 샘플 SMT(S04)를 같은 LLM으로 적용했을 때, 금 규칙 대비 오류 검출률이 개선안과 통계적으로 구분되지 않음
- S3. 개선 효과의 과반이 LLM 교체 또는 수작업 사전 추가로 설명됨(LLM·사전 고정 ablation)
- S4. 독립 정답 작성 임상의 2인 미확보, 또는 평가자 간 일치도(kappa) < 0.6
- S5. 저자로부터 226쌍 라벨·술어 사전 확보 실패 **그리고** 독립 정답도 불가
- S6. 중국 지침 원문 사용 허가 불명확 상태에서 규칙화 데이터 공개가 필요해지는 경우
- S7. 과금 승인 없이는 핵심 실험이 불가능한 경우(무료 로컬 LLM 대안으로 형식화 품질이 원 논문 수준에 못 미치면 비교 무의미)
