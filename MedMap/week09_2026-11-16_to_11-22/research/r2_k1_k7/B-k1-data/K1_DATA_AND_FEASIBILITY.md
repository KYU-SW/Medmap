- 외부 LLM API 금지 원칙과 충돌: TrialGPT 매칭 단계는 OpenAI/Azure 필수 [직접 확인] → 그대로 재현 불가. 공개된 캐시 출력만 사용 가능.

- 라이선스 미확인: TREC CT 코퍼스·qrels, SIGIR 2016, IHDP/Twins 파일, AACT 약관 [아직 검증하지 못한 사항].

## 3. 실제 변수 (K1 질문1에 필요한 것)

당뇨+CKD 6개 RCT의 등록부 기준에서 반복 등장하는 변수 [직접 확인한 사실, data/ctgov]:
eGFR(CKD-EPI, 범위·OR 분기), UACR(범위, "2 of 3 samples" 지속성), HbA1c(범위, % 와 mmol/mol 병기), 칼륨(≤4.8 / >5.5), ACEi/ARB 사용(예외 조항 "unless not tolerated" 유무 차이), 유지투석·이식, 1형당뇨, NYHA IV/HFrEF, 최근 MI/뇌졸중(30/60/84일), SGLT2i·GLP-1RA 사용 시점, 수축기혈압, 당뇨망막병증, ASCVD.
MIMIC-IV Demo에서 확인 가능성 [연구 가설, 직접 미검증]: 크레아티닌·칼륨·HbA1c는 labevents에 있음. UACR은 ICU 환자에서 드물 것, NYHA·망막병증은 구조화 필드 없음(ICD로 간접). → 실제 기록에서는 "미확인"이 대량 발생할 것.

## 5. 독립 검증 방법

1. 질문1: TREC CT 2021–2023 qrels로 시험 단위 정확도 평가(외부 의사 판정 → 우리 정답과 독립).
2. '미확인' 처리: TREC 환자 서술에서 특정 정보를 **제거(ablation)** 해 원 판정이 eligible→판정 불가로 바뀌어야 하는지 확인(정답을 새로 만들지 않고 기존 판정 + 정보 제거로 정의). [연구 가설]
3. 등록부 텍스트 불완전성: CT.gov 텍스트 vs 출판 프로토콜(NEJM 부록) 기준 대조. [아직 검증하지 못한 사항]
4. 겹침 부족 탐지: NHANES로 시험 적격 비율 계산 → 출판된 적격 비율 연구와 방향 비교(정확 일치가 아니라 순위·방향). [연구 가설]
5. 질문2는 독립 검증 수단 없음. 반합성 자료는 방법 동작 확인일 뿐 당뇨+CKD 주장 검증이 아님.

## 6. 연구 가능 범위

- 가능: 등록부 기준의 구조화, 3값(충족/위반/미확인) 대조, 미확인 원인 분류(결측·시간 조건·모호 표현·판단 위임·등록부 누락), 시험 간 적용 범위 비교(eGFR·UACR 구간 지도), 인구 수준 적격 비율.
- 조건부(승인 후): MIMIC-IV 정식에서 실제 결측 패턴, n2c2 기준 단위 평가.
- 불가: 개인 치료효과, "범위 밖 환자에게도 효과가 있다/없다" 판정, 치료 권고 정답.

## 7. 검증 불가능한 주장 (쓰면 안 됨)

- "이 환자에게 시험 효과가 적용된다/안 된다"를 정답과 비교해 맞혔다는 주장.
- "근거 범위 밖"이 "부적절·금기"라는 주장(시험 제외 ≠ 금기).
- 개인 효과 예측 정확도, 범위 밖 환자의 효과 크기.
- 실제 임상 안전성 확보.
- CT.gov 기준만으로 "시험 적격"을 확정했다는 주장(아래 8.3: 등록부 텍스트는 불완전).

## 8. 최소 실험 결과

### 8.1 설계 [실제 실행한 실험 결과]
- 시험 6개(DAPA-CKD, EMPA-KIDNEY, CREDENCE, FIDELIO-DKD, FLOW, SCORED) 기준을 CT.gov v2에서 받음.
- **합성 환자 24명**(경계값·결측·예외 조항 설계, 실제 환자 아님) × 6 = 144쌍.
- 정답: 등록부 텍스트를 손으로 구조화한 기준(`gold/gold_criteria.json`) + Kleene 3값 평가. 실행 전 동결 2026-11-17T20:19:36+09:00, sha256 기록(`gold/FROZEN_AT.txt`). 별도 수작업 판정 20쌍(`gold_manual_spotcheck.csv`)으로 평가기 검증.
- 비교: 2×2 = {손 구조화, 정규식 기준선} × {3값, closed-world(결측=없음/불충족, OMOP 코호트 쿼리 관행)}. 정규식 기준선은 실행 전 sha256 동결(`logs/baseline_frozen.log`), 결과 후 수정 없음.
- 범위 밖 조건(시간 지속성, 동의, 질환 목록 등)은 in-scope 판정에서 제외하고 시험별로 목록화.

### 8.3 등록부 텍스트 자체의 한계 [직접 확인한 사실] (`results_criteria_text_audit.csv`, `logs/lung_renal_grep.log`)
- 13개 시험 기준 197줄 중 수치 조건 51(25.9%), 시간 조건 43(21.8%), 모호 표현 19(9.6%), 판단 위임 2.
- CREDENCE 등록부 텍스트에 **연령 조건 없음**. SCORED는 "목록이 전부가 아님"을 명시. DECLARE-TIMI 58은 기준 7줄뿐이고 신기능 조건 없음(출판 프로토콜의 CrCl 기준 존재 여부 [아직 검증하지 못한 사항]).
- 폐선암: KEYNOTE-189는 신기능을 "adequate organ function" 한 줄로만 표기, FLAURA 등록부 텍스트에는 신기능 조건 없음 → **등록부만으로 CKD 환자의 적용 범위 판정 불가**.
- 부수 발견: 대소문자 무시 정규식이 "EGFR 돌연변이"를 eGFR로 잡음(감사 스크립트의 renal_mention 열이 폐암 시험에서 오탐) — 폐암 영역에서 단순 규칙의 실제 위험.

### 8.4 해석
- [실제 실행한 실험 결과] 구조가 주어지면 3값 평가는 결정적이다(손 구조화 + 3값 = 정답 정의 자체). 즉 "조건 대조" 단계는 새 연구 문제가 아니다. OHDSI ATLAS/Criteria2Query 출력 위에 Kleene 논리만 얹으면 된다 [연구 가설].
- [실제 실행한 실험 결과] 같은 손 구조화라도 closed-world 관행은 정보 부족 29쌍(20.1%)을 전부 확정 판정으로 바꾸고 그중 6쌍을 ELIGIBLE로 만든다. 단, 이 비율은 **내가 설계한 합성 환자의 결측 비율**에 좌우되므로 실제 빈도 주장 불가.
- [실제 실행한 실험 결과] 텍스트→구조 단계에서 단순 정규식은 OR 분기·괄호·단위·복합 조건에서 실패해 정답 INELIGIBLE을 ELIGIBLE로 11건 바꿨다. 그러나 이 기준선은 내가 짠 약한 기준선이며 Criteria2Query·LLM 추출기와 비교한 것이 아니다 → "기존 방법이 못 푼다"는 근거가 아니다.
- 한계: 정답·환자·기준선을 한 작성자가 만듦(순환성), 환자 24명 합성, 시험 6개, 의사 검토 없음. 의학적 안전성 판단 아님.

## 10. K1 데이터 관점 판정

- **질문1(참가 조건 충족): 조건부 가능.** 평가 정답은 TREC CT(공개)로 확보 가능. 그러나 매칭 자체는 기존 연구가 많고, 구조화 후 3값 평가는 자명하다. 차별점이 될 수 있는 것은 **'미확인'을 명시하는 평가 설계(정보 제거 ablation)와 등록부 텍스트 불완전성 측정** 정도 [연구 가설]. TrialGPT 등이 이미 '정보 부족' 기준 레이블을 쓰는지는 A 영역 확인 필요.
- **질문2(효과 적용 근거 충분성): 현재 불가능.** 공개 자료에 개인 효과 정답 없음, 제외 환자 유형의 무작위 자료 없음. 승인 IPD로도 "시험 안 하위집단 이질성"까지만 가능.
- **좁힌 문제 판정: 부분 통과.** "근거 범위 안/밖/판정 불가 + 이유 분류"는 평가 가능하나, 핵심 어려움은 새 알고리즘이 아니라 (a) 텍스트→구조 (b) 결측 의미 (c) 등록부 불완전성이며 셋 다 기존 도구(Criteria2Query, OHDSI, GIST 2.0, 적격 비율 연구)와 겹친다.
- 다음 한 가지: TREC CT 2021/2023 qrels·topic 라이선스 확인 후, 당뇨/CKD 관련 topic 수를 세어 질문1 독립 평가 세트 규모를 확정.
