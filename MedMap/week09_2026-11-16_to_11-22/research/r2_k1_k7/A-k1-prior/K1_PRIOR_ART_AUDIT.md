# K1 직접 경쟁 선행연구 심층 감사 (SUBAGENT A)

작성일: 2026-11-17 · 범위: K1 = 권고 → 근거 시험 → 포함·제외 기준 → 환자 부분 기록을 3값(범위 안 / 지식 부족 / 정보 부족)으로 대조

## 0. 결론 먼저

| 항목 | 판정 |
|---|---|
| K1을 **독립적인 새 알고리즘 연구**로 진행 | **NO-GO** |
| K1을 의료정보학 **과제 정의·벤치마크** 연구로 진행 | **CONDITIONAL(좁음)**: 5절 P\*(4값 판정, 시험 공개 자료가 집계표뿐일 때)로 범위를 줄이고, 7절 조건을 통과할 때만 |
| 이전 Gate 0 K1 정의(기준식 3값 대조)를 그대로 쓰기 | **불가**: 질문1(시험 적격성)과 질문2(효과 적용 근거)를 섞고 있음. 3절·6절의 반례 I2·I3에서 틀린 답을 낸다 |

핵심 이유 3가지:
1. [직접 확인한 사실] 질문1 쪽 "정보 부족" 범주는 이미 있다. TrialGPT(기준 단위 `Not enough information`), TrialMatchAI(`Unclear`), arXiv 2512.08026(시험 단위 `Need More Information`). 모두 **모집 목적**(질문1)이다.
2. [직접 확인한 사실] 질문2 쪽 "이 환자가 시험 자료 범위 밖인가"를 개인 단위로 판정하는 연구도 이미 있다. Laffin 2019 Trial Score(data-rich / data-limited / data-free 구역), Seneviratne 2023(지침 권고 → 인용 연구 → Table 1 → 환자 비교, 범위 밖 특성 시각 표시). 통계 쪽에서는 positivity/overlap 진단이 바로 이 질문의 정식 형태다(Degtiar & Rose 2023 리뷰가 정리).
3. [연구 가설] K1의 "정보 부족 vs 지식 부족" 구분은 **결측 공변량 아래에서 지지 영역(support) 소속을 판정하는 문제**, 즉 완성(completion) 집합에 대한 certain/possible 판정으로 환원된다. 계산 자체는 Kleene 평가, 불완전 데이터베이스의 certain answer, Fréchet 경계·선형계획 같은 기존 도구로 풀린다. 새 알고리즘이나 증명 가능한 개선의 여지는 찾지 못했다.

## 1. 두 질문의 분리 (이 문서 전체의 기준)

| | 질문1: 시험 적격성 | 질문2: 효과 적용 근거 |
|---|---|---|
| 물음 | 이 환자가 시험 *참가 조건*을 충족하는가 | 시험에서 확인된 효과를 *이 환자에게 옮길* 근거가 충분한가 |
| 판정 대상 | 포함·제외 기준식 Φ_t | 효과 수정인자 W에 대한 시험 지지 영역 A_t = supp(P(W \| S_t=1)), 그리고 S-admissibility(조건부 교환가능성) |
| "범위 밖"의 의미 | 기준 위반 | 시험 표본에 그런 환자가 없거나 거의 없어 효과가 식별되지 않음(positivity 위반) |
| 관계 | A_t ⊆ {w : Φ_t(w)=1} (구조적 positivity). **역은 성립하지 않는다**: 기준을 통과해도 실제 등록자가 없으면 지지 영역 밖 | |
| 운영 기준 | 동의서·피임·참여 가능성 등 포함 | 이런 기준은 빼야 함 |
| 기준에 없는 동반질환 | 무시(참가 가능) | 시험 기초특성표에 그 동반질환 환자가 있었는지로 결정. "언급 없음 = 근거 없음"은 틀릴 수 있음 |

이전 Gate 0의 K1 정의는 질문2를 묻는다고 하면서 Φ_t(질문1 도구)만 쓴다. 이 불일치가 6절 반론의 중심이다.

## 5. K1이 기존 문제로 환원되는 부분 (환원 사상)

### 5.1 기호
- 환자 속성 변수 X = (X_1,…,X_n), 효과 수정인자 W ⊆ X.
- 환자 부분 기록 σ: X → {참, 거짓, ⊥}. 완성 집합 C(σ) = {x : x가 σ와 일치}.
- 시험 t: 기준식 Φ_t, 실제 지지 영역 A_t = supp(P(W | S_t = 1)) ⊆ {w : Φ_t(w) = 1}.
- 권고 r의 근거 시험 집합 T(r).

### 5.2 질문1의 3값 판정 = 불완전 정보 아래의 certain/possible 판정
- 범위 안 ⇔ ∀x ∈ C(σ): Φ_t(x) = 1 / 범위 밖 ⇔ ∀x ∈ C(σ): Φ_t(x) = 0 / 정보 부족 ⇔ 그 외.
- 사상: (Φ_t, σ) ↦ 불완전 데이터베이스(Codd 테이블 단일 행)의 boolean 질의 Φ_t에 대한 certain answer.
- Kleene 3값 평가는 이 판정의 **건전한 근사**다(참/거짓이 나오면 맞다). 일반 식에서는 불완전하다(⊥이 남을 수 있음). 정확 판정은 "σ로 제한한 Φ_t가 항진식인가"를 묻는 것이라 일반적으로 coNP-완전(항진식 판정)이다. [연구 가설: 표준 결과로 알고 있으나 이번에 출처 확인 안 함] 각 변수가 한 번만 나타나는 식(read-once)에서는 Kleene 평가가 정확하다고 알려져 있다 [아직 검증하지 못한 사항]. 실제 적격성 기준은 대부분 리터럴·구간의 논리곱이라 Kleene로 충분할 가능성이 높다 [연구 가설].
- 최소 확인 속성 집합 = 판정을 확정하는 최소 변수 부분집합 = prime implicant / 최소 히팅셋(이전 Gate 0 E 결론과 같음).

### 5.3 질문2의 3값 판정 = 결측 공변량 아래의 지지 영역 소속 판정
- 범위 안 ⇔ C_W(σ) ⊆ ∪_{t∈T(r)} A_t / 지식 부족 ⇔ C_W(σ) ∩ ∪A_t = ∅ / 정보 부족 ⇔ 그 외.
- 사상: (σ, A_t) ↦ "부분 관측 점의 모든 완성이 overlap 영역 안인가"(Oberst 2020의 overlap 집합이 Boolean 규칙이면 5.2와 같은 certain answer 문제가 된다).
- 부분 식별과의 관계: 효과 τ(w)가 지지 영역 안에서만 식별되고 결과가 유계 [a,b]이면, 환자 효과의 식별 집합은
  I(σ) = conv( {τ(w) : w ∈ C_W(σ) ∩ A} ∪ ([a,b] if C_W(σ) ⊄ A) ).
  - 범위 안: I(σ)가 식별된 값들의 볼록포 → 결측을 채우면 줄어들 수 있음.
  - 지식 부족: I(σ) = [a,b](Manski 최악 경계). 더 물어도 줄지 않음.
  - 정보 부족: I(σ) = [a,b]이지만 결측 변수를 관측하면 줄어들 수 있음.
  → **"정보 부족 vs 지식 부족" = "추가 관측이 식별 구간을 줄일 수 있는가"**, 즉 부분 식별 구간 위의 정보 가치 문제로 환원된다. [연구 가설: 정의 수준 환원. 문헌상 동일 정식화는 찾지 못했으나 체계 검색은 안 함]
- 이 환원에 들어가는 부품은 모두 기존 것이다: positivity(Petersen 2012), overlap 규칙(Oberst 2020), 부분 식별 경계(Manski 계열, Degtiar & Rose가 Chan 2017·Gechter 2015 인용), 결측 공변량은 표준 결측 자료 문제.

### 5.4 이전 K1 정의가 쓰던 Φ_t는 A_t의 상한일 뿐
- A_t ⊆ {Φ_t = 1}이므로 "Φ_t 위반 ⇒ 지지 영역 밖"은 맞다(구조적 positivity 위반).
- 그러나 "Φ_t 충족 ⇒ 지지 영역 안"은 틀릴 수 있다. 따라서 Φ_t만 쓰는 K1은 **과일반화 오류(범위 밖을 범위 안으로)** 를 구조적으로 낸다. 이는 K1이 막겠다고 한 바로 그 오류다.

## 6. 가능한 신규 계산 문제와 기존 방법이 실패하는 작은 인스턴스

모든 인스턴스는 손으로 만든 예시다. [실제 실행한 실험 결과] 없음. 기존 시스템 출력은 실행하지 않았으므로 "어떻게 답할 것인가"는 그 방법의 정의에서 따른 [연구 가설]이다.

### I1. Kleene 불완전성 (질문1, 이미 알려진 이론)
- Φ_t = (eGFR ≥ 60) ∨ (eGFR < 60 ∧ 용량조절가능). σ: eGFR = ⊥, 용량조절가능 = 참.
- Kleene: ⊥ ∨ (⊥ ∧ 참) = ⊥ → "정보 부족". 정답: 모든 완성에서 참 → "범위 안".
- 의미: 정확 판정은 certain answer로 풀린다. 기존 이론이라 신규성 없음.

### I2. 기준 통과 ≠ 지지 영역 안 (K1 정의 자체의 실패)
- 시험 기준: eGFR ≥ 30. 환자: 폐선암 + CKD 3b, eGFR 35. 실제 등록자 최소 eGFR 48(가상).
- K1(Φ_t 3값) 및 TrialGPT류: 범위 안/적격.
- 개인 IPD가 있으면 overlap 진단·Trial Score류: 지지 영역 밖 → 지식 부족.
- 결론: **기존 positivity 방법이 맞고 K1이 틀린다.**

### I3. 기준에 없는 동반질환 (K1의 "언급 없음 = 지식 부족" 규칙의 실패)
- 기준에 CKD 언급 없음. 기초특성표에 CKD 18%(가상).
- K1 규칙: 지식 부족. Seneviratne 2023식 Table 1 비교: 범위 안.
- 결론: **Table 1 기반 기존 방법이 맞고 K1 규칙이 틀린다.**

### I4. 집계표만 공개, 결합 지지 영역 미확정 (남은 빈틈 후보)
- 시험 Table 1: 75세 이상 30%, CKD 20%. 환자: 78세 + CKD. 결합 비율 미공개.
- Fréchet 하한: P(75세+ ∧ CKD) ≥ max(0, 0.30 + 0.20 − 1) = 0 → **0일 수 있다**. 상한 min(0.30, 0.20) = 0.20.
- 변수별 비교(Seneviratne 2023의 평균±SD 방식으로 읽힌 것): 두 변수 모두 범위 안 → "범위 안".
- IPD 기반 overlap 방법: IPD가 없어 적용 불가.
- Φ_t 3값(K1 원안): 범위 안.
- 올바른 답: **"공개 근거로는 판정 불가"** — 환자 정보 부족도 아니고, 지지 영역 밖이라는 확정도 아님.

### P\* 정의 (I4를 일반화한 후보)
- 입력: T(r), 각 t의 Φ_t와 공개 집계표 M_t(주변분포·일부 교차표), 환자 σ, 지지 임계값 ε.
- 𝒫_t = {P : P가 M_t와 일치하고 supp(P) ⊆ {Φ_t = 1}}.
- 출력 4값:
  1. 범위 안: ∀x ∈ C(σ), ∃t: min_{P∈𝒫_t} P(이웃(x)) ≥ ε
  2. 지식 부족: ∀x ∈ C(σ), ∀t: max_{P∈𝒫_t} P(이웃(x)) < ε
  3. 공개 근거 불충분: 위 둘이 아니고, σ를 완전히 알아도(어떤 완성에서도) 판정이 안 남
  4. 정보 부족: σ의 결측 변수를 관측하면 1·2 중 하나로 확정될 수 있음
- 계산: 고정 x에서 min/max P(셀)은 주변 제약 아래 선형계획(분할표 셀 경계 문제). 완성 열거는 결측 변수 수에 지수적.
- 기존 대응물: 주변 제약 아래 분할표 셀 경계는 통계적 공개 제한 분야의 기존 문제다(Dobra & Fienberg 계열로 알고 있음 [아직 검증하지 못한 사항]). 따라서 P\*는 **"기존 방법의 새 결합"** 이며 **새 계산 문제나 증명 가능한 개선은 아니다** [연구 가설].

### 신규성 후보 분류

| 분류 | K1 해당 여부 |
|---|---|
| 새로운 의학 문제 | 아니오. 시험 결과의 개인 적용성은 Dans 1998, Rothwell 2005, GRADE 간접성, Trial Score가 이미 다룸 |
| 기존 알고리즘의 의료 적용 | 부분. certain answer/Kleene, positivity 진단은 이미 의료에서 쓰임 |
| 기존 방법의 새 결합 | **예(유일한 후보)**: 기준식(구조적 지지) + 집계표 Fréchet/LP 경계(결합 지지 불확실성) + 환자 결측(완성 집합)을 4값으로 분리하는 P\* |
| 실제 새 계산 문제 | 찾지 못함. P\*의 각 하위 문제는 LP·항진식 판정·히팅셋으로 환원 |
| 증명 가능한 효율·정확성 개선 | 찾지 못함 |

## 7. 강력한 반론

1. **질문 혼동**: 이전 K1은 질문2를 묻는다고 하면서 질문1 도구(Φ_t)로 답한다. I2에서 과일반화, I3에서 과소일반화를 낸다. 이 문제를 고치면 K1은 positivity/overlap 진단이 되고, 그 분야는 이미 성숙하다.
2. **"정보 부족" 범주는 이미 산업 수준으로 존재**: TrialGPT(2024), TrialMatchAI(2025), 2512.08026(2025). 심사자는 "질문2로 옮긴 것 말고 무엇이 새로운가"를 묻는다.
3. **개인 단위 지식 부족 탐지도 이미 존재**: Trial Score data-free zone(2019), Jesson 2020, Oberst 2020. 권고 → 연구 → Table 1 → 환자 연결도 Seneviratne 2023이 프로토타입으로 구현.
4. **기준 기반 접근의 임상적 타당성 의문**: Orcutt 2025(2차)는 적격성보다 예후가 일반화 실패를 설명한다고 보고. 기준·집계표 대조가 실제 효과 차이를 예측하는지 보여줄 정답 자료가 없다.
5. **정답 부재**: "이 환자에게 근거가 충분한가"의 의학적 정답은 IPD + 결과 자료 없이는 만들 수 없다. 기준식으로 만든 기계 정답은 정의상 참이라 구현 검증일 뿐이다(이전 Gate 0 E도 같은 지적).
6. **알고리즘 깊이 부족**: P\*조차 LP + 완성 열거. 지도교수가 알고리즘 깊이를 요구하면 통과 어렵다.
7. **결측 변수 수가 많을 때만 계산이 어렵다**는 점은 실무 기준식 대부분이 짧은 논리곱이라 실제 난이도가 낮을 가능성이 높다 [연구 가설].

## 8. 신규성 판정

| 질문 | 판정 | 이유 |
|---|---|---|
| K1이 독립적인 새 알고리즘 연구가 될 수 있는가 | **NO-GO** | 3값 판정은 certain answer/Kleene, 최소 확인 집합은 히팅셋, 지식 부족은 positivity/overlap, 정보 부족 vs 지식 부족은 부분 식별 구간 위의 정보 가치로 환원. 새 계산 문제·증명 가능한 개선을 찾지 못함 |
| K1을 과제 정의·벤치마크(의료정보학)로 | **CONDITIONAL(좁음)** | 남은 후보는 P\*(4값: 범위 안 / 지식 부족 / 공개 근거 불충분 / 정보 부족). 다음 조건을 모두 통과해야 함 |

CONDITIONAL 통과 조건:
1. 질문2만 다룬다. Φ_t는 구조적 지지(상한)로만 쓰고, 지지 영역은 시험 기초특성표로 추정한다. 이전 K1 정의(기준식 3값)는 폐기.
2. 체계 검색(PubMed·ACM·arXiv)에서 다음이 없음을 확인: (a) 집계표 기반 개인 적용성 판정에서 결합 지지 불확실성을 명시한 연구, (b) Seneviratne/Chari 그룹 후속(정량 cohort similarity), (c) Laffin Trial Score 후속의 결측 처리, (d) Dahabreh 다중 시험 전이의 개인 단위 버전.
3. 정답 자료: IPD 공개 시험(예: SPRINT·ACCORD-BP는 BioLINCC 경유로 알려짐, 사용 조건 [아직 검증하지 못한 사항])으로 "집계표만 보고 낸 4값 판정"을 "IPD로 계산한 실제 지지 여부"와 대조할 수 있어야 한다. 이게 안 되면 정답이 없어 NO-GO.
4. 알고리즘 기여를 주장하지 않는다(결합·평가 틀 기여로만).

이전 Gate 0 정책(JNP·MDQ NO-GO, 이름만 바꾼 재제안 금지)과의 관계: P\*는 선호 추론·질문 최소화를 핵심으로 쓰지 않으므로 JNP·MDQ 재제안은 아니다. 단, "정보 부족일 때 최소 확인 속성"을 핵심 기여로 내세우면 MDQ와 겹친다 → 부가 기능으로만 둘 것.
