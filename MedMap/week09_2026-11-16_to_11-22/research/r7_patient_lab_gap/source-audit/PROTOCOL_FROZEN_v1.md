# 환자 검사 공백 파일럿 — 분석 사양 (메인 에이전트, 결과 분석 전 동결)

동결 시각·sha256: `PROTOCOL_FROZEN_v1.sha256.txt`. 동결 전에 확인한 것은 데이터 구성(항목·단위·결측 수)뿐이며, 간격·경계·변화량·비교 결과는 보지 않았다.

## 0. 데이터
- MIMIC-IV Clinical Database Demo v2.2 (PhysioNet, ODbL v1.0, DOI 10.13026/dp1f-ex47). hosp 6개 파일만, 공식 SHA256 일치, 읽기 전용.
- 로컬 다운로드 폴더의 정식 MIMIC-IV 3.1(자격 인증 데이터)은 **사용하지 않는다**.

## 1. 변수와 항목
- 칼륨(주): itemid 50971 "Potassium", Blood, Chemistry, mEq/L. 전혈 칼륨 50822(Blood Gas)는 **합치지 않고** 별도 민감도로만.
- 크레아티닌: 50912 "Creatinine", Blood, Chemistry, mg/dL. 전혈 52024는 사용 안 함.
- eGFR(주, 파생값): CKD-EPI 2021 크레아티닌 식(인종 계수 없음, Inker 2021 NEJM):
  142 × min(Scr/κ,1)^α × max(Scr/κ,1)^−1.200 × 0.9938^나이 × (1.012 여성), κ=0.7(여)/0.9(남), α=−0.241(여)/−0.302(남).
  - 나이 = anchor_age + (검사 연도 − anchor_year). 비식별 연도 이동으로 정확한 나이 아님. anchor_age ≥ 89는 나이 상한 처리된 값이라 '나이 불확실' 표시하고 민감도에서 제외.
  - 급격한 신기능 변동(예: AKI) 시 크레아티닌 기반 eGFR은 정상 상태 가정이 깨져 해석 제한 — 해석 제한 표시만 하고 제외하지 않는다.
- eGFR(민감도, 기록값): itemid 50920 비고 문장의 "Estimated GFR = X if non African-American" 숫자. ">75"는 75 초과로 검열(censored) 처리, "___"/파싱 불가는 제외. MDRD + 인종 계수 체계이므로 주 분석과 섞지 않는다.

## 2. 정제
- valuenum 결측, 크레아티닌 ≤ 0 제외.
- 같은 환자·항목·charttime 중복은 storetime이 가장 이른 1건만 남기고 중복 수 기록.
- storetime < charttime(저장 시각 역전)은 표시하고 이용 가능성 분석에서 제외.
- 입원 밖(hadm_id 결측) 검사도 포함하되 '외래/입원 외'로 구분.

## 3. 경계값 (이전 파일럿 동결 규칙 `~/medmap-real-evidence-pilot/shared-variables/CURATED_LABEL_RULES.csv`에서)
- eGFR: 20, 25, 30, 45, 50, 60 (mL/min/1.73m²). 각 경계에 연결된 규칙 ID를 보존한다(약물·적응증·개시 여부·문서 버전은 그 파일에 있음).
- 칼륨: 4.8, 5.0, 5.5 (mEq/L).
- 경계 근처 정의(두 가지, 둘 다 보고): 절대 eGFR ±5, K ±0.2 (주) / 상대 ±10% (보조).

## 4. 간격 구간
- 같은 환자·같은 변수의 인접 관측 charttime 간격: ≤6시간, 6–24시간, 1–3일, 3–7일, >7일.
- 같은 입원 / 다른 입원 / 입원 외 포함으로 구분.
- 결과 지연: storetime − charttime.

## 5. 평가 시점 (수준 1: 실제 기록)
- 각 환자·변수에서 첫 관측을 제외한 모든 새 채혈 시각 t(charttime)를 평가 시점으로 한다.
- t 시점에 이용 가능한 정보 = storetime ≤ t 인 관측 중 charttime이 가장 최근인 값(마지막 이용 가능 값). 정보 나이 = t − 그 값의 charttime.
- t의 새 결과는 storetime 전까지 '대기(pending)'. 그 값은 나중에 관측되는 사후 실현값(retrospective)으로만 쓰고, t 시점 판단 입력으로 쓰지 않는다.
- 상태 분류: (a) 이용 가능 값 없음, (b) 정보 나이 ≤ 24시간, (c) 24시간 초과(오래된 값).

## 6. 불확실성 구간 (수준 2: 자료 기반 추정)
- 환자 단위 분할: 환자 무작위 50/50 (seed 20261121) → train / test. 같은 환자의 관측은 한쪽에만 들어간다.
- train의 인접 관측 쌍에서 변화량 Δ = 나중 값 − 이전 값(eGFR는 파생 CKD-EPI 척도, K는 mEq/L)을 간격 구간별로 모아 경험적 2.5–97.5% 분위 구간을 만든다.
- 간격 구간별 train 쌍이 30 미만이면 그 구간은 NOT_EVALUATED.
- test에서 실제 재검 변화량이 구간 안에 드는 비율(포함률)을 간격 구간별로 계산한다. 환자 단위 부트스트랩 1,000회(seed 20261121)로 95% CI.
- 이 구간은 확률적 주장(약 95% 포함 목표)이며, 모든 가능한 값의 논리적 보장이 아니다.

## 7. 비교 (수준 3 성격: 실제 문서 조건 × 실제 기록 기반 창)
- 대상: 이전 파일럿의 LEVEL 3 약물–시험 쌍·변수 52개(`~/medmap-real-evidence-pilot/results/pairs_level4.csv`), 이전 `run_compare.py` 함수를 복사본에서 재사용(원본 무수정, sha 기록).
- 창: test 환자의 평가 시점마다 [마지막 이용 가능 값 + 그 정보 나이 구간의 경험적 Δ 구간]. 이용 가능 값이 없는 시점은 '계산 불가'로 센다.
- 방법 A(모듈 곱) vs 방법 B(결합 정확 열거), 이전과 같은 범주·지표.
- 추가: 사후 실현값으로 본 (라벨, 근거) 상태가 결합 집합 J에 드는지(구간 포함 여부의 결과). 실현값이 J 밖이면 '구간 밖'으로 센다.
- 집계: 평가 시점 단위와 환자 단위 둘 다.

## 8. 판정 기준 (결과 전 고정)
- A: test 환자 기반 창에서 가짜 조합이 1건 이상 발생하고, 최종 범주 또는 추가 확인 항목이 달라짐
- B: 가짜 조합은 발생하나 최종 범주 변화 0
- C: 경계 근처 공백 자체가 드묾(경계 근처 + 오래된 정보 평가 시점이 test 환자에서 거의 없음)
- D: eGFR 또는 K 분석 가능 환자 수가 부족해 구간 추정이 대부분 NOT_EVALUATED
- 빈도 수치만으로 자동 결정하지 않는다.
