## 결론 먼저

**판정: B — 경계 근처 검사 공백은 실제 기록에서 흔하다. 모듈 방식의 불가능한 설명 조합도 자주 생긴다. 그러나 최종 판단 범주와 추가 확인 항목은 바뀌지 않는다.**

| 질문 | 답 |
|---|---|
| 실제 환자에서도 미확인 상태가 경계 근처에서 생기는가 | **예** [수준1·실측]. eGFR(파생)은 100명 중 45명이 경계 ±5 안의 값을 가졌다. 평가 시점 2,898개 중 1,000개에서 마지막으로 이용 가능한 값이 경계 근처였고, 그중 306개는 정보 나이가 24시간을 넘었다. 칼륨은 57명, 평가 시점 443개, 오래된 값 187개 |
| 마지막 이용 가능 값으로 본 경계 위치가 새 결과와 달랐나 | **예** [수준1·실측, 사후 실현값과 비교]. eGFR 2,898개 중 560개(44명), 칼륨 2,915개 중 562개(60명) 평가 시점에서 적어도 하나의 경계 기준으로 반대편이었다 |
| 그 때문에 모듈 계산이 불가능한 조합을 만드는가 | **예** [수준2 구간 + 수준3]. 검증 환자 50명의 쌍 평가 80,230건 중 20,426건(25.5%), 평가 시점 1,965개, 환자 49명에서 가짜 조합이 생겼다. "허용 + 근거 범위 밖" 12,048건, "불가 + 범위 안" 17,639건 |
| 판단 보류·추가 확인 항목·근거 설명까지 달라지는가 | **근거 설명(가능한 조합 목록)만 달라졌다.** 최종 범주 변화 0, 잘못된 확정 0, 불필요한 보류 0. 추가 확인 항목은 두 방식 모두 같은 변수(eGFR 또는 칼륨) — 창이 변수 하나라 구조상 동일 |
| 기존 결합 계산으로 해결되는가 | **예.** 같은 창에서 결합 방식은 가짜 조합 0 |
| 새 알고리즘이 필요한가 | **아니오** |

**가장 중요한 실측 결과는 비교 실험이 아니라 수준 1이다.** 새 채혈 시점의 약 19%에서 "마지막 이용 가능 값"과 "곧 나올 실제 값"이 경계 기준으로 서로 달랐다. 이것은 정보의 신선도·가용성 문제다. 모듈 계산 대 결합 계산의 문제가 아니다.

**권고**:
- 공유 변수 정보 손실 세부 방향은 **새 알고리즘 연구로 종료**하고, 평가 연구로도 **우선순위를 낮춘다**.
- MedMap 시스템에는 "검사값 + 정보 나이 + 경계 근처 표시"를 보여주는 기능이 더 직접적인 가치를 가질 수 있다 [가설, 임상 평가 NOT_EVALUATED].

## 5. 추정 사구체여과율 확보 및 계산 방법
- 기록된 eGFR(50920)은 숫자 칸이 아니라 비고 문장에 들어 있다. 예: "Using this patient's age, gender, and serum creatinine value of 1.1, Estimated GFR = 68 if non African-American (mL/min/1.73 m2)…"
  - MDRD 식 + 인종 계수
  - 75 초과 검열
  - 일부 비식별 처리
  - → **민감도 분석에만** 썼다.
- **주 분석은 파생값**: CKD-EPI 2021 크레아티닌 식(인종 계수 없음; Inker et al. 2021 NEJM)
  - 입력: 혈청 크레아티닌(mg/dL, 단위 단일), 성별, 나이
  - 나이 = anchor_age + (검사 연도 − anchor_year). 비식별 연도 이동 때문에 정확한 나이가 아니다.
  - anchor_age ≥ 89인 4명은 '나이 불확실'로 표시했다. 이 4명은 모두 학습(train) 쪽에 배정돼 비교 결과에 영향 없음 [사후 확인].
  - 급성 신손상 등 비정상 상태에서는 크레아티닌 기반 eGFR의 해석이 제한된다(표시만 하고 제외하지 않음).
  - **기록값과 파생값은 섞지 않았다.**
- [사후] MDRD 기록값: 숫자 310건(60명) 중 경계 ±5 안 199건(49명). 75 초과 검열 때문에 상단 경계(60 근처) 판정이 제한된다.

## 22. 실제 환자 기록으로 확인된 부분 [수준1·실측]

## 23. 통계적 가정에 의존한 부분 [수준2·추정]

## 24. 합성 실험에 해당하는 부분 [수준3 성격]
"그 창 안의 모든 값이 가능하다"는 전제의 조합 계산. 라벨·시험 조건은 실제 문서지만, 이 환자들이 해당 약을 고려 중이거나 시험 대상이라는 근거는 없다. 대상 질환 셋을 모두 가진 환자는 7명뿐이다.

## 25. 임상적으로 검증하지 못한 부분 — NOT_EVALUATED

## 26. 결과 신뢰구간과 표본 크기 한계
- 환자 100명(검증 50명). 평가 시점·쌍 평가는 같은 환자의 반복이라 독립 표본이 아니다. 환자 단위 수(45명, 57명, 49/50명 등)를 함께 보고했다.

- 최종 범주 변화 0건은 이 자료와 이 구간에서의 결과다. 다른 자료에서 발생 확률이 0이라는 뜻이 아니다. 다만 모듈 결과가 결합 결과의 상위 집합이라는 구조 때문에, 범주가 'HOLD'로 같아지는 것은 이 정의에서 구조적으로 예상된다.
