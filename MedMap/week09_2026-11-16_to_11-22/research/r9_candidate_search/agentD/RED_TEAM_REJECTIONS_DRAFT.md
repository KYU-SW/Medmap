### PA 진단 가설과 검사·영상 판독·후속 기록의 미완료/미확인 상태 감사

| Q | 판정 | 근거 |
|---|---|---|
| Q1 | ● | Singh·Murphy 계열 e-trigger(2015 RCT, 2024 VA 시험), 폐쇄 루프(closed-loop) 검사 결과 관리 문헌이 '발행→열람→조치→후속' 단계 실패를 이미 분류·측정 [검색요약] |

| Q4 | ● | '후속이 필요했는가', '진단 가설에 필요한 검사였는가'는 임상 판단 |
| Q5 | ● | 기준선: Singh e-trigger 규칙(이상 결과 + N일 내 후속 없음) 미비교 시 성립 |
| Q6 | ● | 열람·설명 상태의 실제 정답 없음 |
| Q7 | ● | '미완료' 정의를 연구자가 정하면 측정이 정의를 재확인할 뿐 |
| Q8 | ? | MedMap 상태 표시 결함(R2 K7 stateAsOf 승인 시각 결함)과 같은 성격일 가능성. 코드 확인 전 미확인 |

- 반증 방법(최소): MIMIC-IV 스키마에서 열람·확인·환자 통지에 해당하는 열/이벤트가 있는지 grep(10분). 없으면 PA는 PG로 축소.
- 탈락 권고. 생존 조건: 관측 가능한 상태(발행, 후속 시행)로만 좁히면 PG와 같아짐 → PG에 흡수.

| Q | 판정 | 근거 |

- 사람 판단 없는 독립 정답: **좁은 형태에서만 가능** — "퇴원 기록에 적힌 검사값·투약 진술이 같은 입원의 구조화 기록과 시간상 일치하는가". 정답 = labevents·emar/prescriptions의 시각과 값.
- 반증 방법(최소): ① 보유 MIMIC-IV-Note에 경과 기록 유형이 있는지 확인(note_type 열 집계, 로컬). ② 퇴원 기록 50건에서 수치 진술 추출 후 구조화 기록과 대조 가능 비율 측정. 대조 가능 비율이 낮거나 불일치가 '정당한 요약 시점 차이'로만 설명되면 종료.
- 조건부 생존. 생존 조건: (a) 정식 MIMIC-IV/Note 사용 사용자 승인(51회차 결정), (b) 범위를 '수치·투약 진술 vs 구조화 기록'으로 제한, (c) 기준선 = 복사 정렬 + 최근값 규칙 + LLM 판정, (d) 주장은 측정(빈도·유형)까지.

## 3. G5(새 알고리즘) 판정

| 후보 | 강한 기존 알고리즘 | 실패 반례 존재 근거 | 판정 |
|---|---|---|---|
| PA | e-trigger 규칙 | 없음(실패는 데이터 부재) | 불가 |
| PB | LLM 변환 + 원문 연결 | 실패는 해석(지식) 문제, 계산 아님(R8 TYPE E 0) | 불가 |
| PC | 복사 정렬 + NLI/LLM | 미측정 | 미확인 → 근거 없음 |
| PD | 무시율·ML | 데이터 없음 | 불가 |
| PE | Safer Dx + ML | 정답 없음 | 불가 |
| PF | LLM 사실 대조 | 정답 결함 | 불가 |
| PG | LLM 추출 + 규칙 매칭 | 미측정. 예상 실패는 부위·검사 동등성 지식 문제 | 근거 없음 |
| PH | LOCF·GBM 예측 | R7: 새 알고리즘 불필요 | 불가 |

**판정: G5 주장 가능 후보 없음.** 이전 R5·R7·R8에서 계산적 한계(TYPE E)가 반복해서 0건이었다. 이번 후보들의 실패 원천도 데이터 부재·해석·정답 부재다. 가능한 기여는 시스템·평가(측정·벤치마크) 연구뿐이다. G5 재개 조건은 '독립 정답 세트 위에서 강한 기준선이 계산 불가(TYPE E)로 틀린 사례가 사전 동결 기준 이상 발생'뿐이다.

## 4. 전체 탈락 권고 요약

- 탈락: PA(→PG 흡수), PB, PD, PE, PF(→PG 하위 항목), PH(연구로서).
- 조건부 생존: **PG**(1순위, 독립 정답 가장 근접, 선점 높음), **PC**(2순위, 좁힌 형태, 데이터 유형 확인 선행).
- 두 생존 후보 모두 다음이 공통 전제: 정식 MIMIC-IV/Note 사용 사용자 승인, 기준선 사전 고정, 임상 효과 주장 금지.
- 가장 먼저 할 한 가지: **Park 2025(arXiv 2511.11867) 본문에서 데이터 출처 확인.** MIMIC이면 PG의 '공개 벤치마크' 신규성이 소멸한다.
