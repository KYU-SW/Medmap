## PA 검사·영상 결과 후속 조치 누락, 미확인 상태 감사
**이미 해결된 것**
- 이상 결과 + 정해진 기간 안의 후속 행위 부재를 잡는 규칙 기반 e-trigger(PA1). RCT에서 진단 평가까지의 시간 단축을 입증했다(PA2, 대장암·전립선암 트리거 유의, 폐 트리거 유의차 없음).
- 퇴원 시 결과 대기 검사(TPAD)의 빈도와 의사 미인지 비율 측정(PA3, 설문 기반). 결과 최종화 시 자동 통보 RCT(PA4).
- 판독문 후속 권고 추출(PA5, F1 0.92/0.65/0.73/0.84). 운영 중인 폐쇄 루프: 권고 감지 → BPA → 오더 또는 닫는 사유 기록(PA6).

**남은 것**
- 행위가 있었는지가 아니라 누가 언제 결과를 인지했는지를 기록으로 재구성하는 감사. Roy 2005는 이 부분을 설문으로만 측정했다.
- 판독문 권고와 실제 후속 오더·결과를 연결하는 이행 판정 정답을 공개 데이터로 만든 사례는 찾지 못했다(확인 필요).

**조합으로 해결 가능 여부: 가능.** Lau식 추출 + Singh식 규칙(기간 창) + Dalal식 통보로 대부분 재현된다.
- MedMap만의 차별점은 인지 시점(as-of) 기록 하나다.
- MIMIC에는 결과 확인(acknowledgment) 로그가 없어 독립 정답을 만들기 어렵다(로그 부재 여부는 확인 필요).
- R7(정보 신선도 가설)과 연결할 수는 있지만 인지 정답이 없다는 문제는 그대로 남는다.

## PB 지침·원문→실행 규칙 변환 의미 손실 감사
**이미 해결된 것**
- GuidelineForge(PB1): CQL로 변환하면서 규칙마다 출처 문장을 연결하고, 3값 판정과 6종 거부 사유를 낸다.
  - 기본값을 채우면 의미가 손실된다는 점을 정량으로 보였다(4,304쌍 중 207명 오인증). MedMap PB와 문제 정의가 거의 같다.
- NICE→ASP 변환과 전문가 검토(PB3). 이 연구는 오류 대부분이 부분 누락이었다고 보고했다.
- 지침 간 충돌의 SAT 검증(PB2, Xie & Du 2604.17340).
- 해석 단계와 실행 단계를 분리한 MedDEx(PB4).
- 기대 결과 단위 테스트(PB5, CQL Testing Framework). GLIF 등 컴퓨터 해석 가능 지침(CIG) 표현(PB6).

**남은 것**
- 독립 정답이 약하다. PB1·PB3은 정답 작성자를 밝히지 않았다(초록 기준). PB5는 테스트 작성자의 해석을 정답으로 삼는다.
- 원문 문장 ↔ 규칙 ↔ 실제 환자 기록 판정의 3자 대조로 손실 유형별 임상 영향(오인증 환자 수)을 공개 데이터에서 측정한 연구는 PB1 외에 찾지 못했다.

**조합으로 해결 가능 여부: 대부분 가능.** GuidelineForge 방식에 CQL 테스트와 MIMIC 기록 판정을 붙이면 된다.
- 차별화는 손실 분류 체계와 MIMIC 공개 재현에 한정된다.
- 이전 R4·R8(지침 해석 단계 오류 8건, 독립 정답 없음)과 같은 정답 부재 문제가 반복될 위험이 높다.

## PC 시간에 따른 상태 변화 vs 기록 모순, copy-forward
**이미 해결된 것**
- 중복 정량(PC1)과 복사 탐지(PC2).
- 문서 내부 시간 관계 추출(PC3).
- 장기 EHR 시간 질의 LLM 평가(PC4 TIMER, PC5 MedAlign, PC6 EHRSHOT은 예측 과제라 관련성 낮음).
- 노트 ↔ 구조화 테이블 불일치(PC7 EHRCon, 전문가 주석, PhysioNet 공개).
- 장기 노트 간 모순 3단계 판정(PC8 TBU, 2026). 시간 참조 대조(PC9, 확인 필요).

**남은 것**
- 복사되어 남은 진술이 원 작성 시점에는 사실이었지만 이후 구조화 데이터(검사값, 투약 중단 등)가 바뀌어 오래된 정보가 된 경우를 판정하는 문제. 시간 경과 축의 판정이다.
- 구조화 시계열에서 정답을 결정론적으로 만들 수 있다(수학 정답).
- 검색 범위 안에서 이 축을 직접 다룬 LLM 연구는 찾지 못했다(한계: 검색 2회).

**조합으로 해결 가능 여부: 조건부 가능.** Cohen 복사 탐지 + EHRCon식 테이블 대조 + 시점 비교를 조합하면 대부분 구현된다.
- 새로움은 시점별 사실 여부 판정과 정답 생성 절차에 있다. 기법 자체는 새롭지 않다.
- MedMap의 출처·발생 시점·인지 시점 기록과 정정·중복 처리 기능이 그대로 연결된다.
- 공유 변수(신장 기능, 칼륨)는 반복 금지 대상이므로 다른 변수를 선정해야 한다.

## PD 불필요 경고·확인 요구 감소
**이미 해결된 것**
- 경고 무시 예측 ML(PD1 VUMC AUC 0.919, PD5 대만).
- LLM 경고 개선 제안(PD2). 오작동 분석과 발동률 이상 탐지(PD3).
- 스튜어드십 관리 방법(PD4). 적절성 평가 프레임워크(PD6, 확인 필요).
- 요청서에 적힌 Kaiser 사례는 특정 논문을 찾지 못했다(확인 필요).

**남은 것**
- 무시 = 불필요라는 가정 대신 하류 위해 결과로 정답을 정의하는 문제. 일부는 PD6이 다뤘다.

**조합으로 해결 가능 여부: 기법상 가능, MedMap 데이터로는 불가에 가까움.** 보유 데이터에서 CDS 경고 발동·응답 로그를 찾지 못했다(MIMIC 포함 여부 확인 필요). 우선순위 최하위.

## PE 진단 기록 불확실성·진단 오류 탐지
**이미 해결된 것**
- SPADE 방법론(PE1).
- e-trigger 포트폴리오 운영(PE2, PPV 11~52%). 뇌졸중 트리거 검증(PA7).
- 인공 오류 삽입 탐지 벤치마크(PE3 MEDEC, 공개).
- 불확실성 표현 보존 벤치마크(PE4, MIMIC-IV-Note, 2026).

**남은 것**
- 진단 가설-근거 연결이 바뀌는 과정(가능성 변화)의 기록 품질 평가. ER-REASON(전문의 가능성 변화 점수)과 MIMIC-IV-Ext-PE(전문가 2인 라벨)를 독립 정답으로 쓸 여지가 있다.

**조합으로 해결 가능 여부: 가능.**
- SPADE를 MIMIC-IV ED+hosp에 적용하는 것은 재현에 해당하고 새 기여가 아니다.
- 불확실성 보존은 PE4와 정면으로 겹친다.

## PF 퇴원 요약·인계 내용 누락·정확성
**이미 해결된 것**
- LLM 퇴원 요약의 누락·부정확 평가(PF1, 맹검 의사). 인계 노트 생성 평가(PF2).
- 환각·누락 분류 체계(PF3 CREOLA). 요약 품질(PF4).
- MIMIC 퇴원 요약 생성 공유 과제(PF5). I-PASS 구조화 인계(PF6).
- 퇴원 요약의 대기 검사 기재율 수작업 측정(PF7 11%, PA3 계열).

**남은 것**
- 구조화 기록 사건을 정답으로 쓰는 자동·대규모 누락 감사. 예: 결과 시각이 퇴원 시각보다 늦은 검사가 요약에 언급되었는지.
- 기존 연구는 사람 평가(PF1~PF3)이거나 수작업 소표본(PF7)이다.

**조합으로 해결 가능 여부: 조건부 가능.** PF7 방법 + MIMIC-IV labevents·note 시각 + 개체 매칭(EHRCon식)으로 구현할 수 있다.
- 새로움은 규모, 자동화, 공개 재현에 한정된다. 임상적 신규성은 낮다(문제 자체는 2005~2011년에 확립).

## 독립 정답 관점 정리(사용자 제약: 전문의 섭외 불가)
- **기록 사건, 수학 정답 가능:** PC(구조화 시계열 시점 비교), PF(결과 시각 > 퇴원 시각), PA(후속 오더 존재 여부. 다만 인지 여부는 불가)
- **공개 전문가 라벨 이용 가능:** PC(EHRCon, MIMIC-III 자격 인증), PE(MIMIC-IV-Ext-PE, ER-REASON, MEDEC)
- **정답 부재 위험 높음:** PB(R4·R8 반복 위험), PD(로그 없음)
