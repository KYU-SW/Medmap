## 생존 후보 반대 의견 (먼저 작성)
### S1 퇴원 기록 작성 시점 근거 가용성 감사 (C02+C04)
| 반론 | 판정 | 근거·반증 방법 |
|---|---|---|
| 이미 존재하는 기술 | **부분 성립** | 퇴원 시 미결 검사 자동 표시는 운영 도구로 존재(AHRQ 과제, 2014 EMR 도구, Dalal 2014). 차이는 '작성 시점(storetime) 기준'과 '작성 시점에 이미 대체된 값'을 함께 공개 데이터로 재현 감사하는 것뿐 |
| 기존 두 방법 합치면 해결 | **성립 가능** | EHRCon식 일치 판정 + 결과 저장 시각 비교로 대부분 구현 가능 → 새 알고리즘 주장 금지, 시스템·평가로만 |
| 입력 자료 부족일 뿐 | 부분 | 열람·환자 설명은 관측 불가 → 주장 범위를 '가용성 상태'로 제한 |
| 임상의 판단 필요 | **'조치 필요' 판단은 필요** | 조치 필요·임상 중요도는 주장하지 않음. 검사실 flag(비정상 표시)는 기록 값이지 임상 판단 아님 |
| 강한 기준선 누락 | 대응 | 기준선 2개 사전 고정: EHRCon식 ±1일 일치(독자 구현), 퇴원 시각(dischtime) 기준 최신 값 |
| 실제 정답 없음 | 부분 불성립 | 가용성 상태는 시각 비교로 결정됨(사건 정답). 노트 수치 추출은 연구자 파이프라인 → 추출 정확도를 별도 보고, 가능하면 EHRCon(MIMIC-III, 외부 저자 주석)으로 독립 대조(미보유·확인 필요) |
| 연구자 정답 순환 | 부분 성립 | 시각 비교 규칙을 사전 동결; 추출 규칙과 상태 판정 규칙을 분리 |
| 구현 오류를 연구 문제로 | 불성립 | 운영 시스템 결함이 아니라 기록 시점 불일치 빈도 측정 |
| 의료 효과 미증명 안전 주장 | 위험 | 안전·위해 주장 금지. 빈도·기준선 불일치만 |
| 원문·코드 미확인 단정 | 부분 | EHRCon [본문 앞 100k자], Park [본문], BRIE·VeriFact·AHRQ 도구 [검색요약] → 본문 확인 필요 목록 유지 |
| (추가) MIMIC-IV-Note 날짜 비식별로 노트 속 시각 고정 불가 가능 | **미확인 — 최대 위험** | 최소 실험 1단계에서 측정, 중단 기준 포함 |
| (추가) 신장 기능·칼륨 반복 | 대응 | 크레아티닌·eGFR·칼륨은 주 분석에서 제외(민감도만) |
