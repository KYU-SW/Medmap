# 평가 사례 선택 편향 검토 체크리스트 (Agent C)

작성일 2026-11-21 · 사용 시점: **메인이 사례 구조화를 끝낸 뒤, 정답 작성·시스템 실행 전**. 각 항목에 PASS / FAIL / N/A와 근거 파일 경로를 기록한다. FAIL 항목이 있으면 해당 한계를 결과 본문에 명시한다.

## A. 사례 출처 편향

| ID | 점검 항목 | 확인 방법 | FAIL 기준 |
|---|---|---|---|
| S1 | 출판 편향: 공개 증례는 드물고 극적인 사례 위주 | 사례별 출처 유형(EHR 유래 / 출판 증례 / 교육 vignette / 벤치마크 구성) 집계 | 출판 증례·구성 사례만으로 "일상 진료 대표" 주장 |
| S2 | 흥미로운 사례 위주: 충돌이 뚜렷한 사례만 선택 | 사전 정의한 포함·제외 기준을 사례 수집 **전**에 기록; 제외 사례 목록과 사유 보관 | 수집 후 기준 변경, 제외 사유 미기록 |
| S3 | 충돌 없는 사례(수렴) 부족 | 정답 범주별 분포(확정/보류/충돌 없음) 보고 | "충돌 없음" 정답 사례가 0 |
| S4 | 선호 기술 사례의 희소성 | 원문에 환자 진술 선호가 있는 사례 수 / 전체 | 선호 진술 사례 < 전체의 소수인데 "실제 선호" 주장 |
| S5 | 질환 조합 편중 | 질환 조합·지침 출처별 사례 수 | 한 조합(예: CKD+고혈압+심방세동)이 과반 |
| S6 | 동일 출처 중복(같은 증례의 변형) | 출처 ID 기준 군집; 분석 단위를 출처 군집으로 | 변형 사례를 독립 표본으로 계산 |

## B. 정답 작성 편향

| ID | 점검 항목 | 확인 방법 | FAIL 기준 |
|---|---|---|---|
| S7 | 연구자가 정답 작성 시 순환(시스템 설계를 아는 사람이 작성) | 작성자·역할·시스템 출력 열람 여부 기록 | 구현자가 작성했는데 REF-R 표기 누락 |
| S8 | 정답이 시스템 출력 범주 체계에 맞춰짐(정답 작성 양식 = 시스템 출력 형식) | 정답 양식을 임상의 언어로 먼저 받고 범주 매핑은 별도 단계 | 정답 작성자가 시스템 범주(P/Q/K 등)를 직접 선택 |
| S9 | 정답 보류 기저율 과다 → 모든 보류 기준선 유리 | n_D/N 계산 | n_D/N > 0.5 (METRIC_DESIGN 5절) |
| S10 | 사례 마스킹이 시스템 강점에 맞춰짐(결합 정식화가 잘 푸는 공유 변수 구조를 골라 마스킹) | 마스킹 규칙 사전 등록 + 무작위 마스킹 조건 병행 | 사후 마스킹 선택 |
| S11 | 정답 사후 수정 | 동결 sha256, 수정 append 기록, 수정 전후 점수 | 기록 없는 수정 |

## C. 지표·비교 편향

| ID | 점검 항목 | 확인 방법 | FAIL 기준 |
|---|---|---|---|
| S12 | 과도한 보류가 유리한 지표 | B-DEFER-ALL / B-CONFIRM-ALL / B-RANDOM / B-ASK-ALL 동시 보고 | B-DEFER-ALL이 주 지표에서 제안 방법 이상 |
| S13 | 가중치 사후 선택 | λ 격자 전체 결과표 | 단일 λ만 보고 |
| S14 | 기존 방법 약화(독자 구현, 점 선호 강제) | 원 팀 해법 보고서 출력과의 비교, 구현 충실도 표 | 독자 구현을 원 방법 이름으로 표기 |
| S15 | 여러 변수 동시 변경을 단일 원인으로 해석 | 조건별(임상 결측/선호 결측/둘 다) 분리 결과 | 분리 결과 없음 |
| S16 | 사례 단위 무시(항목을 독립 표본으로) | 사례 단위 bootstrap | 항목 단위 CI |

## D. "모든 판단 보류" 기준선 검사 절차

1. B-DEFER-ALL 출력 파일을 실제로 생성해 같은 채점 스크립트로 채점한다(손계산 금지).
2. 주 지표 S에서 B-DEFER-ALL = 0(구조적)인지 확인 → 0이 아니면 채점 코드 오류.
3. 보조 지표 전부에서 B-DEFER-ALL의 순위를 표로 보고. 1위가 되는 지표는 "보류 편향 지표"로 표시.
4. λ 격자 9점 전부에서 제안 방법 S > 0 인지 확인.
5. 정답 보류 기저율을 0.3/0.5/0.7로 재표본(사례 층화 재추출)해 S 순위 유지 여부 확인(민감도).
6. 변이 검사: 채점 스크립트에 정답 보류 항목을 확정으로 바꾼 가짜 출력을 넣어 WC가 올라가는지 확인(검증기 자체 검증).

## E. 보고 시 필수 문장(해당 시)

- "사례는 공개 자료에서 선택되어 출판·흥미 편향이 있을 수 있다"(S1·S2 FAIL 시)
- "선호 불완전성은 원문 선호를 가려 만든 조건이다"(S4·S10 해당 시)
- "정답은 연구자 작성(비독립)이다"(S7 해당 시)
