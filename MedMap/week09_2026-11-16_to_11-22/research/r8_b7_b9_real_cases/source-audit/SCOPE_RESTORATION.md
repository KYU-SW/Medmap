# 연구 범위 복원 (52회차, 2026-11-21, 메인)

## 원래 목표
의사의 진단 가설을 증상·검사·과거 기록·출처·시점·불확실성과 연결해 의료진이 근거를 검토하도록 지원. 확장 = 복합질환 환자의 개인별 진료지침 적용 + 근거 통합.

## 중심 질문 (B7+B9)
여러 질환 환자에게 진료지침을 적용할 때 환자 정보와 선호가 불완전하면 무엇을 확정하고, 무엇을 보류하고, 무엇을 먼저 확인해야 하는가.

- B7: 다질환 권고 동시 적용 — 실제 충돌 / 조건부 충돌 / 보완 / 중복 / 적용 조건 미확인 시 보류
- B9: 목표·선호·치료 부담 — 불완전 선호를 실제 선호로 간주하지 않음, 선호에 따라 바뀌는 판단이면 먼저 물을 선호 식별
- B10(확장): 시험 참가 조건 vs 효과 일반화, 근거 부족 vs 환자 정보 부족

## 이전 범위 이탈 (R1~R7)
| 회차 | 다룬 것 | 원래 질문 대비 |
|---|---|---|
| R1~R2 | 불완전 선호 결합 판단(JNP), 최소 질문(MDQ), 근거 범위(K1), 시간 as-of(K7) | 부분 문제 계산 |
| R3 | 복합질환 6유형 반례 | 합성 반례 |
| R4 | GuidelineCoordination 규칙 충돌 재현 | 지침 규칙 변환만 |
| R5 | B7+B9+B10 통합 | 합성 1,261건, 실제 지침·선호·정답 없음 |
| R6 | openFDA 라벨 × 임상시험 공유 검사 변수 | 단일 변수 공유만 |
| R7 | MIMIC Demo eGFR·K 시간 공백 | 단일 검사값 시간 변화만 |

이탈 원인: 실제 사례·실제 선호·독립 정답 확보가 어려워 계산 가능한 부분 문제로 옮겨 감.

## 이번 회차 범위 규칙
- 모든 실험은 "한 환자 사례 안에서 지침 적용(B7) × 선호(B9)가 함께 작용"하는지에 직접 기여해야 함.
- 단일 검사값·공유 변수·규칙 변환만 다루는 작업이 생기면 중단하고 결과만 보존.
- 사례 종류 4분류(REAL_WITH_PREF / REAL_NO_PREF / GUIDELINE_VIGNETTE / SYNTHETIC_STRESS)를 섞어 정확도로 평가하지 않음.
- 정답 수준 A/B/C/D 를 사례별로 기록. C·D 없으면 의료적 정확도·임상 효과 주장 금지.
