# SUBAGENT D: 기존 방법으로 풀리지 않는 계산 문제와 반례 탐색

- 작성일: 2026-11-17. 다른 서브에이전트(A·B·C·E)의 결과는 보지 않고 독립적으로 수행함(작성 시점에 그 폴더들은 비어 있었음).
- 모든 규칙·약물·수치는 **[가상] SYNTHETIC**임. 약 이름(ACEi, NSAID 등)은 구조를 설명하는 데만 썼고, 임상 수치나 규칙을 뜻하지 않음. 실제 환자에 대한 결론은 없음.
- 태그: [원문으로 확인] [초록·요약으로 확인] [실험으로 확인] [연구 가설] [미검증]
- 정답 기준: 모든 실험의 정답은 **brute force 전수 열거**로 만들었고, MILP 코드와는 독립적으로 작성함. 따라서 "검증"은 합성 인스턴스에서 계산이 정확한지만 뜻하며, 임상적으로 타당한지와는 무관함.
- 이전에 NO-GO로 판정한 후보(JNP, MDQ, 선택적 재평가, K1, K7)는 다시 제안하지 않음. 유형 2·4·6에서 겹치는 부분은 이전 결론을 인용해 철회함.

## 1. 유형 1: 여러 질환 지침 조건이 얽힘

- **① 입력**: 권고 R1..Rm. 각 권고는 처방 변수에 대한 선형·논리 제약임. 예시 H2 [가상]:
  - R1: 혈압약 A+B+C ≥ 2
  - R2: 전체 약 수 A+B+C+S ≤ 2 (치료 부담)
  - R3: 스타틴 S = 1
- **② 기대 출력**: 전체를 함께 만족할 수 있는지, 그리고 불가능하다면 최소 충돌 집합(MUS). 이 예시의 답은 "불가능, MUS={R1,R2,R3}"임.
- **③ 기존 방법**: SAT/MILP 실행 가능성 판정, MUS/MCS 열거, MitPlan식 FOL과 완화 연산자, ABA+G/ASPIC+G 논증.
- **④ 실패 가설**: 권고를 쌍으로만 비교하는 충돌 검사기(GoCom의 2종 탐지 같은 방식)는 3항 이상의 충돌을 놓침.
- **⑤ 반례**: H2에서 세 쌍은 각각 충족 가능하지만 세 권고를 동시에 충족할 수는 없음.
- **⑥ 재검증** [실험으로 확인, `logs/e2_highorder.log`]:
  - 쌍 3개 모두 jointly satisfiable=True, 3개를 함께 넣으면 False
  - MILP status=2(실행 불가) → MUS={R1,R2,R3}
- **⑦ 철회**: 쌍 검사기의 한계는 CSP의 "국소 일관성 ≠ 전체 충족" 문제와 같고, 교과서 수준의 사실임 [미검증 서지 S22]. MILP·SAT·MUS·FOL은 n항 제약을 그대로 표현함. → **철회. 분류: 특정 구현의 한계, 단순 적용으로 해결.**
- **⑧** 해당 없음.

## 2. 유형 2: 환자별 근거가 부족한 상태에서 지침 적용

- **① 입력**: 임상 항목 T/F/U(미확인), 영역 제약 Φ, 권고의 적격 조건.
- **② 기대 출력**: 필연·가능 적격, 필연·가능 최선, 확인해야 할 항목.
- **③ 기존 방법**: 3값 판정, 가능 세계 나열 + ROR(R1), 시나리오 MMR MIP(R2), 최악 ODT/ECD(R4), TrialGPT의 "정보 부족" 범주, Laffin data-rich zone.
- **④·⑤**: 이전 Gate0의 CE-J2(미확인을 false로 채우기), CE-J4(entailment만 사용), CE-M1이 이미 이 유형의 반례임.
- **⑥ 재검증**: 이전 B의 MILP와 상태별 LP 조합이 정답과 4,320/4,320 일치, C가 160/160 일치 [로컬 원문 S19·S20, 이번에 재실행하지 않음].
- **⑦ 철회**: JNP·MDQ·K1이 NO-GO이므로 같은 문제를 이름만 바꿔 제안하게 됨. → **철회. 분류: 단순 적용 + 데이터 부족(독립 정답 IPD).**

## 3. 유형 3: 근거 수준이 다른 권고를 같은 환자에 함께 적용 (방향 a)

- **① 입력**: 결론 X와 ¬X가 서로 반박함. 각 쪽은 k∈{1,2}개 논증을 가짐. 논증은 길이 L∈{1,2}인 사슬(전제 근거 확실성, 규칙 강도)이고, 원소 등급은 1~4(GRADE의 very low..high)임.
- **② 기대 출력**: X, ¬X, 미결정 중 하나와 결론의 확실성.
- **③ 기존 방법**:
  - WL: GRADE 간접추정은 두 직접 추정 중 "낮은 쪽", 근거가 일치하면 "높은 쪽"을 씀. 이는 possibilistic min/max와 같고, ASPIC+ weakest-link와도 같음.
  - LL: ASPIC+ last-link
  - PROB: 확률 곱 + noisy-or(독립 가정)
- **④ 실패 가설**: 방법마다 서로 다른 결론을 내는 구조가 있음. 그렇다면 어느 방법을 "정답"으로 쓸지가 문제가 됨.
- **⑤ 반례** [실험으로 확인, `logs/e3_certainty.log`]:
  - 사슬 반례: X=[very low 근거, high 강도 규칙], ¬X=[moderate, moderate] → WL=¬X, LL=X, PROB=¬X
  - 누적(accrual) 반례: X는 독립적인 LOW 논증 2개, ¬X는 MODERATE 논증 1개 → WL=¬X, LL=¬X, PROB=X
  - 셋 모두 다름: X=[(1)], ¬X=[(1,2)] → WL=미결정, LL=¬X, PROB=X
- **⑥ 재검증** [실험으로 확인, 전수 85,264 구조]:
  - 판정이 다른 비율(미결정 포함): WL≠LL 44.5%, WL≠PROB 28.5%, LL≠PROB 46.1%
  - X와 ¬X가 정반대인 비율: WL vs LL 9.3%, WL vs PROB 2.4%, LL vs PROB 14.4%
  - 세 방법이 모두 다른 비율: 5.51%
  - ASPIC+ grounded 구현과 max 비교 판정의 불일치: 0
  - **GRADE-NMA 규칙과 possibilistic min/max의 일치: 64/64**
- **⑦ 철회 근거**:
  1. 불일치는 서로 다른 정의를 계산한 결과일 뿐, 각 정의 안에서는 계산이 정확함.
  2. weakest-link와 last-link는 ASPIC+가 의도적으로 제공하는 선택지임 [검색 요약 S5]. 계산 복잡도 차이(weakest-link grounded는 NP-hard, last-link는 다항)도 이미 알려져 있음 [S6].
  3. GRADE의 조합 규칙은 possibilistic 전파와 구조가 같음(64/64). 따라서 "GRADE를 계산 규칙으로 옮기는 일"은 새로운 계산이 아님.
  4. 누적 문제(Prakken 2005)와 drowning effect(Dubois-Prade)는 알려진 문제임 [미검증 서지 S23].
  - → **알고리즘 후보로서 철회. 분류: 전문가 판단 필요(규범 선택).**
- **⑧ 남는 것(비계산)**:
  - 다질환 결합 처방에서 "결론 확실성"을 어떤 규칙으로 정할지 GRADE가 명시하지 않음. 검색에서 다질환 결합 계획의 확실성 전파 규칙은 찾지 못함 [초록·요약으로 확인, S18; 찾지 못했다는 것이 존재하지 않는다는 뜻은 아님].
  - 이 질문은 "임상가 판단이 어느 규칙과 일치하는가"라는 **경험적·규범적 연구 질문**임. 새 계산 방법이 필요하지 않음.

## 4. 유형 4: 환자 상태에 따라 유효 권고 집합이 바뀜 (방향 c, 순환 의존)

- **① 입력** [가상]:
  - 기준 상태 e0 (eGFR 유사 수치)
  - 약 i의 상태 효과 Δ_i (가산), 적격 조건 e ≥ t_i, 이득 b_i, 질환별 요구
- **② 기대 출력**: 의미론에 따라 다름.
  - POST: 처방 후 상태에서 처방한 모든 약이 적격
  - TRAJ: 시작 순서를 포함하고, 모든 중간 상태에서 적격
- **③ 기존 방법**: 고정점 제약 MILP(big-M), 시간 색인 MILP 또는 bounded model checking, PDDL durative action 계획(MitPlan [초록 S11]), ASP.
- **④ 실패 가설**:
  - 기준 상태에서만 판정하는 정적 규칙 엔진은 치료가 바꾼 상태를 무시함.
  - 지침 순서대로 탐욕적으로 적용하면 결과가 순서에 따라 달라짐.
- **⑤ 반례** [실험으로 확인, `logs/e4_dynamic.log`]:
  - D1: e0=33. 약0은 Δ=−5, 약1은 t=30. STATIC은 {0,1}을 승인하지만 사후 상태가 28이므로 POST·TRAJ 모두 "해 없음"
  - D2: e0=28. 약0은 Δ=+5, 약1은 t=30·Δ=−2. 약0을 먼저 시작해야만 가능함. SEQ(1→0)는 [0]만 고르고 요구를 충족하지 못함. SEQ(0→1)는 [0,1]을 고름. TRAJ와 시간 색인 MILP는 모두 9로 정답임.
  - D3: e0=31. B_full(e≥30, Δ=−2), B_red(e<30, Δ=−2).
    - POST: B_red가 자기 효과(29) 덕분에 적격이 되는 자기정당화 해가 나옴
    - TRAJ: 시작 시점에 부적격이므로 "해 없음"
    - **두 의미론이 서로 다른 답을 냄**
- **⑥ 재검증** [실험으로 확인, N=300, n=6]:
  - POST MILP와 brute force 일치: 300/300
  - 시간 색인 TRAJ MILP와 순열 brute force 일치: 300/300
  - STATIC 최적해가 사후 적격을 위반한 경우: 150/300
  - SEQ가 순서 의존적이었던 경우: 164/300
  - POST와 TRAJ 최적값이 다른 경우: 4/300
- **⑦ 철회**: 순환 의존은 고정점 제약 또는 시간 전개로 정확히 인코딩되고, 표준 MILP·계획·모델 체킹으로 풀림. 시간 축은 K7(as-of) NO-GO 범위와도 겹침. → **철회.**
- **⑧ 남는 것(비계산)**:
  - D3처럼 의미론마다 답이 다른 경우, 어느 것이 맞는지는 임상 판단의 문제임. 예: "예상되는 eGFR 감소를 미리 반영한 감량을 허용하는가".
  - Δ_i 같은 효과 크기는 데이터나 전문가가 정해야 함.
  - MitPlan이 수치 상태(eGFR) 효과를 표현하는지는 원문에서 확인하지 못함 [미검증].

## 5. 유형 5: 개별 선택지는 유효하지만 조합하면 문제 (방향 b, 치료 부담, 목표 충돌)

### 5-1. 고차 상호작용 (b)

- **① 입력** [가상]: 약 8개, 질환별 "하나 이상" 요구, 쌍 금지, **3항 금지(하위 쌍은 모두 허용)**, 상태 의존 누적 위험 Σr_i + s_state ≤ T, 이득.
- **② 기대 출력**: 최대 이득을 주는 안전한 처방, 그리고 단순 합산 처방의 MUS.
- **③ 기존 방법**: n항 제약 MILP, MUS 열거, FOL 규칙(MitPlan식 "ckd ∧ ACEi ∧ MRA → 위해"), TMR4I [S10].
- **④ 실패 가설**: DrugBank형 pairwise DDI 검사는 3제 병용 위해(triple whammy형)와 상태 의존 누적(RAS 억제제 + MRA + CKD → 고칼륨형)을 표현하지 못함.
  - 실제로 3제 병용만 AKI 증가를 보이고 2제에서는 뚜렷한 증가가 없었다는 보고가 있음 [초록·요약으로 확인, Lapi 2013 S1].
  - pairwise 방식의 한계도 이미 지적되어 있음 [초록·요약으로 확인, Yao 2020 S3].
- **⑤ 반례** [실험으로 확인, `logs/e2_highorder.log`]:
  - H1, ckd=0: 단순 합산 {ACEi, DIU, NSAID, MRA}는 pairwise 검사를 통과하지만, MUS={ACEi, DIU, NSAID}
  - H1, ckd=1: MUS={ACEi, MRA}(상태 의존), {ACEi, DIU, NSAID}. 이 경우 요구를 모두 충족하는 안전한 처방이 없음(MILP status=2, brute force None 일치).
    - [가상 요구 설정 때문임. 실제로는 요구를 완화할 대상이 됨]
- **⑥ 재검증** [실험으로 확인, N=600]:
  - n항 MILP와 brute force 일치: **600/600** (실행 불가 95건 포함)
  - 쌍 금지만 넣은 최적 처방이 고차·누적 규칙을 위반한 경우: 584/599 (3항 위반 512건, 누적 위반 557건)
    - 이 비율은 목적함수에 부담 항이 없어서 약을 거의 다 고르는 설정 때문에 부풀려진 값임. 의미는 "위반이 존재한다"는 데까지만 있음.
  - 보수적 pairwise 근사(3항 집합의 모든 쌍을 금지):
    - 최적값 손실이 생긴 경우: 356/505
    - 실제로는 가능한데 "불가능"으로 판정한 경우: 33건
  - 단순 합산 처방 중 크기 3 이상의 MUS가 있는 경우: 11/600
- **⑦ 철회**:
  - MILP·MUS·FOL은 n항 제약과 상태 조건을 그대로 표현하고 정확히 계산함.
  - pairwise만 쓰는 한계는 특정 지식 표현(쌍 DDI 데이터베이스)의 한계이며, 이미 지적된 사실임 [S3].
  - → **철회. 분류: 특정 구현의 한계 + 단순 적용으로 해결.**
- **⑧ 남는 것**:
  - 고차 상호작용 **지식 자체**가 부족함(데이터 부족). FAERS 기반의 고차 DDI 발굴은 진행 중인 별도 분야이고, 3제를 넘으면 조합 폭발 문제가 있음 [초록·요약, S3·S4].
  - 이는 약물감시 데이터 마이닝 문제이지, 다질환 권고 통합의 계산 문제가 아님.

### 5-2. 목표 충돌과 치료 부담

- **① 입력** [가상]: 약 7개, 목표 (이득 max, 위험 min, 약 수 min), 요구, 금지쌍.
- **② 기대 출력**: 파레토 집합 전체.
- **③ 기존 방법**: 가중합 스칼라화, epsilon-constraint MILP, 사전식 최적화, MitPlan 2.0 비용·선호 최적화 [S12].
- **④ 실패 가설**: 가중합은 비지지(non-supported) 파레토 점을 찾지 못함.
- **⑥ 재검증** [실험으로 확인, N=60, `logs/e5_pareto.log`]:
  - 파레토 점 683개 중 가중합 격자(1,331개 가중치)가 찾지 못한 점: 152개
    - 비지지 점과, 동점 때문에 가려진 점을 함께 센 값임
  - 누락이 생긴 인스턴스: 49/60
  - epsilon-constraint MILP와 brute force 파레토 집합 일치: **60/60**
- **⑦ 철회**: Das & Dennis(1997)가 지적한 알려진 사실이고 [미검증 서지 S21], epsilon-constraint로 해결됨. → **철회.**
- 비가산 이득(약을 추가할수록 한계 이득이 감소함) [S18]은 효과 크기를 정하는 데이터 문제임.

## 6. 유형 6: 연구 대상 범위와 지침 적용 범위가 다름

- **① 입력**: 시험의 개별 환자 자료(IPD, 가상, d차원, 상관 0.7, n=300)와 적용 대상 환자.
- **② 기대 출력**: 환자가 시험의 결합 지지 영역 안에 있는지.
- **③ 기존 방법**:
  - Table 1 주변 범위 비교(Seneviratne 2023형 [S20])
  - 볼록 껍질 소속 LP(King & Zeng 2006 WhatIf [S16])
  - 다변량 overlap [S17]
  - transportability의 positivity 진단
- **④ 실패 가설**: 공변량별 범위 안에 있어도 그 조합은 시험에 없을 수 있음.
- **⑤ 반례** [실험으로 확인, `logs/e6_joint_support.log`]: 2D 공변량 상관 −0.8. "고령 + 높은 eGFR" 조합 [가상]은 두 범위 안에 모두 들지만 볼록 껍질 밖에 있음.
- **⑥ 재검증** [실험으로 확인]: 주변 범위 안에 있는 환자 200명 중 껍질 밖에 있는 비율

  | 차원 d | 껍질 밖 비율 |
  |---|---|
  | 2 | 45.5% |
  | 3 | 85.5% |
  | 5 | 98.5% |
  | 8 | 100% |

  - 반대로 차원이 높으면 껍질 기준은 거의 모든 환자를 "밖"으로 판정하므로, 너무 보수적이라는 것도 알려진 문제임 [연구 가설].
- **⑦ 철회**: 볼록 껍질 LP와 다변량 overlap으로 해결됨. K1 NO-GO 범위(Laffin data-rich zone)와 겹침. → **철회.**
- **⑧ 남는 것**: 결합 지지를 판정하려면 IPD가 필요함. 공개 자료는 주로 Table 1 요약 통계라서 **데이터 부족**이 핵심임. 계산 문제가 아님.
