| 남은 빈칸이 **알고리즘**인가, **지식·데이터·평가**인가 | **지식·데이터·평가 쪽**: (a) 동반질환 조합별 효과 근거 부족(Weiss 2014, Hanlon 2019), (b) 지식 구축 부담(Fdez-Olivares 2019 저자 명시), (c) 독립 정답과 평가 기준 부족(Van Woensel 2023, Wu/Peleg 2026) |

Wilk 2017 본문은 여전히 접근 실패. 다만 같은 계열의 선호 처리 원문(Michalowski 2015 AMIA, PMC)과 2014 AMIA 원문으로 상당 부분을 메움. **가장 중요한 새 발견 2가지**

1. [원문으로 확인] **ATLAS(Wang 외, arXiv 2608.09443, 2026-08)**: 고령 복합질환자의 약물 안전 판단에서 다음을 이미 한다. 보고되지 않은 정보를 "없음"이 아니라 미확인으로 유지한다(§III-A, 부록 C.1: "retains unknown values as unknown rather than converting missing information into negative evidence"). 그리고 "답에 따라 계획이 바뀔 수 있을 때" 질문을 만든다. 정지 규칙은 "결정을 의미 있게 바꿀 미해결 항목이 없을 때"다(§III-C). 이것은 이전 Gate 0의 MDQ 아이디어와 같은 방향의 **임상 응용**이다. 다만 질문 선택은 휴리스틱 순위(위험 심각도 → 영향받는 약물 결정 수)이며, 근거 확실성이나 시험 적용 범위는 다루지 않는다(본문에 해당 내용 없음).
2. [원문으로 확인] **분야 스스로 만든 기능 목록(O'Sullivan 외 2021, AMIA, PMC8861752)**: 18개 기능(A1–A18) 가운데 **미확인 환자 정보, 근거 불확실성, 근거 적용 범위를 다루는 항목은 없다**. 상호작용 7종, 완화 7종, 기타 4종(선호·부담, 자원 최적화, 설명, 대안 전략)뿐이다. 이것은 "불가능하다"는 증거가 아니라, **분야가 이 축을 평가 대상으로 삼지 않았다**는 직접 근거다.

## 1. 비교 기준: 기준 문제 P_MM

판정이 흔들리지 않도록, 복합질환 치료 결정을 아래 구성요소로 나눠 놓고 각 계열이 어디까지 푸는지 본다.

| 기호 | 구성요소 | 쉬운 뜻 |
|---|---|---|
| C1 | 상호작용 탐지 | 약-약, 약-질환, 목표 충돌, 중복, 시간 겹침 찾기 |
| C2 | 완화·계획 생성 | 대체·추가·중단·용량 조정·지연으로 안전한 계획 만들기 |
| C3 | 선호·부담 반영 | 환자 선호, 복용 횟수, 비용, 방문 수 등으로 고르기 |
| C4 | 미확인 임상정보 | 환자 정보가 빠졌을 때 "없음"으로 채우지 않고 처리, 필요한 질문 고르기 |
| C5 | 불확실한 연구근거 | 근거 확실성(GRADE 등), 상호작용 발생 확실성, 서로 다른 위험모형 |
| C6 | 근거 적용 범위 | 이 환자의 동반질환 조합이 근거 시험 모집단 안에 있는가 |
| C7 | C4와 C5·C6의 구분 출력 | "정보를 더 모으면 풀리는 불확실" vs "지식이 없어 안 풀리는 불확실"을 따로 표시 |
| C8 | 강건 결정 | 불확실성 아래 minimax regret, 최악 기준, 다중 모형 평균 |
| C9 | 형식 검증 | 통합 계획의 일관성·안전 성질 증명 |
| C10 | 임상 평가 | 독립 정답 대비 정확도·안전성 |

## 2. 계열별 계산 원리(쉬운 설명)와 확인 수준

### F1. FOL 완화 프레임워크 (Michalowski 2014 AAAI/AMIA, Michalowski 2015 AMIA, Wilk 2017 JBI)

- **원리**: 지침 흐름도(actionable graph)와 환자 사실을 1차 논리 문장으로 바꾼다(D_comb = 공통 공리 + 지침 + 환자 정보). 상호작용 조건 α가 이 이론에서 **함의되면**(D_comb ⊨ α) 해당 수정 연산자(제거·추가·대체)를 적용한다. 그 뒤 모델 찾기로 "모순 없는 치료 시나리오" 하나를 만든다.
- **선호(2015 원문)**: 환자 쌍대 비교 → GRIP(가법 가치함수)로 선호를 끌어낸다. 실제 연산자 적용은 **우선순위 순서대로** 하며, 적용 뒤에도 이론이 일관되고 시나리오가 나올 때만 남긴다. **비용 함수나 최적화는 없다.** 현재는 행동을 "대체"하는 선호만 지원한다고 저자가 명시 [원문으로 확인, PMC4765594 "Applying Preferences" 등]. 선호가 없으면 지침 제안을 수용한다고 가정한다.
- **미확인 정보**: 2014 AMIA·2015 AMIA 원문은 결측을 따로 다루지 않는다. 출력 시나리오에 "환자 상태에 대한 가정"이 포함된다 [원문으로 확인]. 2014 AMIA는 간접 상호작용을 entailment로 정의하지만, 사례 1에서는 "α1이 D_comb와 일관되므로 상호작용 존재"라고 써서 정의와 서술이 어긋난다 [원문으로 확인, PMC4419977]. Wilk 2017 초록은 "possibly incomplete" 환자 정보와 "possible patient states" 출력을 말한다 [초록·요약으로 확인]. **이것이 상태 열거인지, 모델 하나의 가정값인지는 본문을 못 봐서 [미검증].**

### F2. MitPlan(2021) · MitPlan 2.0(2021) · 그래프 재작성(2023) · 설명 구성요소(2024)

- **원리**: 지침을 PDDL 계획 문제로 바꾼다. 임상 행동(투약·검사)은 지속시간이 있는 행동(durative action)이다. 상호작용은 계획 공간 안에서 완화 행동으로 처리하고, 의사가 정한 계획 기간 안에서 **환자 선호와 행동 비용(치료비·수정 비용)으로 계획을 최적화**한다. 출력은 시각이 붙은 행동 순서다 [초록·요약으로 확인, PubMed 33581823]. 2022 파이프라인 논문에 따르면 OPTIC 계획기를 썼다 [초록·요약으로 확인, 검색 요약].
- **MitPlan 2.0**: 완화 과정을 계획 공간 안으로 옮기는 새 PDDL 인코딩을 쓴다. 목적은 환자 선호, 치료 비용, 예상 복약 순응도 가운데 하나로 둔다(AF 사례) [초록·요약으로 확인].
- **그래프 재작성 2023(AIIM 140:102550)**: 저자는 **Michalowski M, Rao M, Wilk S, Michalowski W, Carrier M** [초록·요약으로 확인, PubMed/Europe PMC 메타데이터]. 지침을 task network로 표현하고, 2차 의학 지식을 그래프 재작성 규칙 형태의 "수정(revision)"으로 형식 정의한 뒤 어휘(vocabulary)로 구체화한다. 합성 사례와 임상 사례로 시연했다. "복합질환 완화 이론"은 향후 과제로 남겼다 [초록·요약으로 확인].
- **설명 2024(JBI 156:104681)**: 사후 설명(왜 이 행동이 있나, 왜 수정했나, 비용·순응도의 영향)을 만든다. 의사 21명이 충실도·해석 가능성을 수용 가능하다고 평가했다 [초록·요약으로 확인].
- **공개 코드**: 검색으로는 찾지 못함 [미검증].

### F3. GoCom (Kogan·Peleg 외, AMIA 2018 선행판, JBI 2020)

- **원리**: 지침별로 PROforma 엔진을 실행해 환자별 **목표 나무**를 만든다. Controller가 규칙으로 충돌을 찾는다. 반대 동사 목표(예: 혈소판 응집 증가 vs 감소)와 같은 약 계열의 "중단 vs 처방" 충돌이 대상이다(온톨로지 포함관계 사용). 충돌이 생기면 의사에게 유지·취소 또는 지침 재실행을 묻는다 [원문으로 확인, PMC6371243, Rule 2c–2f].
- **결측**: PROforma는 자료가 빠진 첫 Enquiry에서 **실행을 멈추고**, 의사가 값을 넣으면 재실행한다. 불확실하거나 상충하는 값의 형식 처리는 없다 [원문으로 확인].
- **근거**: PROforma 결정은 후보별 논증 "net support"를 쓴다. 저자는 "결정 논증마다 근거 수준을 표현하는 것"을 향후 과제로 명시했다 [원문으로 확인].
- **2020 평가**: 상호작용 탐지는 2종으로 제한된다. 학생 10명 실험에서 완전성 0.44→0.71, 27명 실험에서 0.31→0.78, 정확성 0.68→0.83 [초록·요약으로 확인, PubMed 33035704].

### F4. TMR4I (Zamborlini 외, Semantic Web 7(4) 2016)

- **원리**: 권고를 "행동이 상황 전이(transition)를 일으킨다"는 구조로 표현한다(TMR). 같은 행동, 역방향 전이, 유사 전이를 FOL 규칙과 OWL+SPARQL로 추론해 **반복(repetition)·모순(contradiction)·대안(alternative)** 상호작용을 찾고, DrugBank로 외부 약물 상호작용을 찾는다. 합쳐진 지침도 같은 방식으로 다시 검증할 수 있다 [원문으로 확인, swj1145.pdf §4, §8].
- **범위 한계(저자 명시)**: "시간·순서 측면은 아직 다루지 않음", 상호작용은 시간 독립 또는 동시로 가정(§4). 향후 과제는 순서, 구성, 시간, 수량, **목표, 근거, 권고 강도**(§8) [원문으로 확인]. 환자 고유 조건은 TMR이 표현하지 않는다는 점을 Čyras & Oliveira가 원문에서 지적함 [원문으로 확인, Čyras §3.2].
- 비교표(§8)에서 Wilk와 López-Vallverdú 방식은 **쌍(pairwise)만 분석 가능**하다고 서술 [원문으로 확인, TMR4I 저자의 서술].

### F5. 규칙·제약·SAT 기반 충돌 해결

- **López-Vallverdú·Riaño·Collado 2012**: 규칙 기반으로 질환별 치료를 하나로 합치면서 원치 않는 약물 상호작용을 피한다(고혈압·당뇨·심부전) [초록·요약으로 확인, 검색 요약]. Riaño & Ortega 2017 JBI 리뷰가 이 계열을 정리한다 [미검증, 서지만].
- **Bowles·Caminati·Cha·Mendoza 2019 (Sci Comput Program 182:42–63)**: BPMN 지침 → 형식 모델 → Isabelle로 정확성 검사, Z3로 불일치 탐지 → **최적화 SMT**로 충돌을 최소화하는 대안을 찾는다. 기준은 약효, 해로운 조합의 심각도, 시간 겹침 [초록·요약으로 확인]. Kovalov & Bowles 2016은 단계별 약물 그래프와 Z3로 "충돌이 가장 적고 덜 심각한" 약물 집합을 찾았다(5개 동반질환 고령 환자) [초록·요약으로 확인, 검색 요약].
- **Xie & Du 2026 (arXiv 2604.17340)**: LLM 에이전트가 지침을 "조건 C ⇒ 행동 A" 규칙으로 바꾸고, Z3로 조건 사이의 동치·함의·교차를 판정한다. 그 결과로 중복·모순·**Local Conflict**(조건이 교차하지만 함의 관계는 없는 경우, 두 질환을 함께 가진 환자에게서만 생김)를 분류한다. **치료를 추천하지 않고 탐지만 한다.** 결측 처리와 근거 등급은 본문에 없다. 행동 어휘에 강도 순서(ALLOW…CONTRAINDICATE)만 있다. 형식화 정확도 80.1%(565 규칙, 감사자 1명), 충돌 F1 0.861 vs LLM 0.148–0.298 [원문으로 확인, HTML 부록 A·C·D, Table 1·3]. 초록의 "90.6%가 Local"과 Table 2 수치(약 94%)가 맞지 않음 [원문으로 확인, 내부 불일치].
- **GuidelineForge 2026**: 3값 판정. 기본값을 false로 채우면 4,304쌍 가운데 207쌍을 잘못 "준수"로 판정한다 [초록·요약으로 확인, 이전 Gate 0 A].

### F6. 다중 에이전트 HTN 계획 (Fdez-Olivares 외, AIIM 96:167–186, 2019)

- **원리**: 질환마다 에이전트 하나가 있고, 각자 지침을 HTN 계획 도메인(HPDL)으로 갖는다. **정성 선호**(예: 경구 vs 주사)는 술어로 표현해 지침의 결정 절차를 걸러낸다. 에이전트들이 약물 상호작용, 일정 제약, 중복 행동을 계획 과정에서 조정해 후보 계획들을 낸다. 마지막으로 **정량 선호**(하루 복용 횟수, 알약 수, 방문 수, 방문 시간, 치료 기간)를 **가중합 MCDM**으로 점수화해 가장 낮은 점수의 계획을 고른다. 식은 p(j)=Σ pr_i·n_ij이고, 기관 비용 m(j)와 합쳐 S(j)=w_p·p(j)+w_m·m(j)를 쓴다. 가중치 pr_i는 환자의 정성 순위를 1,2,…로 바꾼 뒤 정규화한다 [원문으로 확인, riunet 저자판 §6].
- **임상적 동등(equipoise)** 상황을 정량 선호로 해소한다고 명시 [원문으로 확인].
- **저자 명시 한계**: 계획 실행·환자 모니터링·의사-환자 상호작용 미지원(§7), 지식 공학 부담(§8). DM+HTN 단순화 사례 1건 [원문으로 확인].

### F7. GLARE-SSCPM과 모델 검사 (Terenziani·Piovesan·Bottrighi 계열)

- **원리(2019 원문)**: 실행 중인 지침들에서 **예정 행동**(scheduled)과 **후보 행동**(candidate)을 구분한다. 후보 행동은 다음 치료 결정까지 도달 가능한 행동이며, 그 실행 여부는 미래 진단 결과(환자 상태)에 달려 있다. 예정 행동 사이의 상호작용은 실행을 멈추고 관리한다. **후보 행동 사이의 상호작용은 "일어날 수도 있음"으로 미리 알린다** [원문으로 확인, HEALTHINF 2019 §3.4]. 관리 선택지(회피, 효과 모니터링, 용량 조정 등)를 "what-if"로 적용해 본 뒤 의사가 고르고, 이어서 Conciliation 모듈로 병합한다. 치료 결정의 대안은 효과·비용·부작용·순응도·기간의 **정성 평가**로 제시하고 의사가 자유롭게 고른다 [원문으로 확인].
- **시간**: 시간 제약 전파로 실제 실행 시간이 겹칠 때만 상호작용으로 본다(2015). 확률적 시간 제약 질의도 있다(2018) [초록·요약으로 확인, 검색 요약].
- **모델 검사**: GLARE와 SPIN을 느슨하게 결합해 LTL 성질을 검사했다. 뇌졸중 지침에서 수작업으로 못 찾던 불일치를 찾았다(AIIM 48(1), 2010) [초록·요약으로 확인, 검색 요약]. 다중지침 계획의 모델 검사 적용 범위는 [미검증].
- 2019 논문은 프로토타입 개발 중이며 실험은 향후 과제 [원문으로 확인].

### F8. 논증(argumentation) 기반 CDS

- **Čyras & Oliveira 2019 (AAMAS, arXiv 1902.07526)**: TMR 권고를 ABA+ 가정으로 둔다. **상호작용 확실성**을 두 값으로 구분한다. □(반드시 일어남)는 사실 규칙, ◇(불확실)는 공격 가능한 **가정**이다(Def 3.3, Def 4.4). 환자 상태 𝒮는 사실로 넣는다. 환자 선호는 권고 위의 preorder, 의사의 목표 우선순위는 total preorder다. <-preferred extension은 모순 없는 권고 집합임이 증명된다(Thm 4.5). 선호가 전순서이고 최선 권고들이 모순 없으면 모든 확장에 포함된다(Thm 4.6) [원문으로 확인]. 향후 과제로 **TMR의 belief strength 같은 수치 측정 통합**과 다른 상호작용 유형을 명시 [원문으로 확인, §6].
  - [연구 가설] 𝒮에 없는 조건(예: 위장출혈 미확인)은 공격 규칙을 발동하지 않으므로, 결과적으로 "없음"처럼 동작한다. 원문은 이 경우를 따로 논의하지 않는다.
- **Oliveira 외 2018 (AAMAS 확장초록, ASPIC-G)**: ASPIC+에 목표를 붙이고, 목표 선호 순서(전순서)로 preferred extension들의 순위를 매긴다 [원문으로 확인, 확장초록]. 2020 CLAR판은 MCDA와 비교했다고 함 [초록·요약으로 확인].
- **Kökciyan 외 2021 (IEEE Intell Syst, CONSULT)**: 메타수준 논증으로 지침·EHR·센서 자료와 선호(예: 이부프로펜 > 나프록센)를 추론하고, grounded semantics를 쓴다. 각주에서 "시간 정보와 불확실성을 표현하려면 더 복잡한 언어가 필요"하다고 씀. 뇌졸중 혈압 관리 파일럿에서 사용 가능성만 보였다 [원문으로 확인].
- **Hunter & Williams 2012 (AIIM, doi:10.1016/j.artmed.2012.09.004)**: RCT·메타분석의 여러 결과지표 근거로 "치료 A가 B보다 우월/동등" 논증을 만들고, **약한 근거에 기댄 논증을 메타 논증으로 공격**한다. 3개 지침, 56개 근거, 16개 치료에서 선택된 치료가 지침 권고와 일치했다 [초록·요약으로 확인, 검색 요약].
- **Fox / PROforma**: 후보별 찬반 논증과 net support 집계는 GoCom 원문 서술로 확인 [원문으로 확인, 간접]. Fox 원저 자체는 이번에 보지 못함 [미검증].

### F9. 선호 기반 치료계획 최적화

- **원리**: (a) 가중합 MCDM(Fdez-Olivares, 원문), (b) PDDL 목적함수(MitPlan 2.0, 초록), (c) 우선순위 연산자(Michalowski 2015, 원문), (d) 선호가 불완전할 때의 필연·가능 관계(ROR, UTA^GMS)와 minimax regret 질의(Boutilier 2006) [이전 Gate 0 A에서 원문으로 확인].
- **Tinetti "patient priorities care" 계산화**: 임상 절차(목표 확인 → EHR 전달 → 목표에 맞춘 처방·탈처방)와 시험은 있다. 그러나 이를 **최적화 알고리즘으로 만든 연구는 검색 1회에서 찾지 못함** [미검증; 검색 결과가 없다는 뜻이지 없다는 근거는 아님]. 선호 도출 도구(PolyPref, OPT score)는 있다 [초록·요약으로 확인]. SPPiRE에서 환자와 GP의 우선순위 일치도가 낮았다 [초록·요약으로 확인, 검색 요약].

### F10. 강건 결정 · minimax regret

- **Manski(2011 Annu Rev Econ 외)**: 처치 반응을 부분적으로만 알고 주관 확률을 둘 수 없을 때 minimax regret으로 처치 규칙을 고른다. 결측이 많을 때의 유한표본 규칙(2007)이 있고, 3개 이상 처치에서는 모두에게 같은 처치를 배정할 수 있다(Stoye) [초록·요약으로 확인].
- **강건 MDP 치료 모형(Zhang·Steimle·Denton, Optimization Online 2015/2017)**: 전이확률에 불확실성 예산을 두고, 평균 성능과 최악 성능을 교환한다. 제2형 당뇨 혈당약의 순서와 시작 시점에 적용했다 [초록·요약으로 확인].
- **다중모형 MDP(Steimle·Kaufman·Denton, IISE Trans 53(10) 2021)**: **서로 다른 근거 출처(상충하는 심혈관 위험모형)**를 여러 모형으로 두고, 모형들에 대해 평균적으로 가장 좋은 정책 하나를 찾는다. NP-hard임을 보이고, 혈압+콜레스테롤 공동 관리에 적용했다 [초록·요약으로 확인]. → **"불확실한 연구근거"를 결정 모형에 직접 넣은 기존 사례.**

### F13. 지식그래프 근거 추론

### F14. 불확실 근거의 표현 표준

### 5-B. 직접 근거는 없고 "확인 범위에서 보이지 않은" 것 (불가능 근거 아님)

- 다중지침 계획(MitPlan·FOL·HTN)이 **미확인 상태 전체에서 강건한 계획**(모든 가능 상태에서 안전)을 내는지: MitPlan 계열 본문을 못 봐서 [미검증]. Wilk 2017의 "possible patient states"가 핵심 단서임.
- **C7(정보 부족 vs 지식 부족을 출력에서 분리)**을 하는 임상 CDS: 확인한 문헌에는 없다. 다만 GLARE(미래 상태 의존 "가능" 상호작용), ATLAS(미확인 의존 관계), Čyras(◇ 상호작용), FHIR(directnessMatch)가 각각 한쪽을 표시한다 [연구 가설: 두 표시를 곱하는 것은 계산상 단순 결합].
- 근거 적용 범위(C6)를 **다중지침 계획 안에서** 쓰는 시스템: 확인 범위에 없음. K1에서는 단일 권고 수준의 Seneviratne 2023이 가장 가까웠다.
- Tinetti PPC의 계산화: 검색 1회에서 못 찾음.

## 6. 결합해서 풀리는가 (⑨ 종합)

[연구 가설] 다음 결합이면 P_MM의 계산 부분이 채워진다.

1. 지침 → 규칙/계획 표현(F2·F5·F6), 상호작용 탐지(F4·F5)
2. 환자 상태를 3값으로 둔다(GuidelineForge·ATLAS). 미확인 항목마다 완성 세계를 열거하거나 적대자 변수로 둔다(이전 Gate 0 R1/R2)
3. 근거 쪽은 상호작용 확실성 □/◇(F8), 근거 확실성과 직접성(FHIR certainty·directnessMatch), 위험모형 집합(F10 MMDP)
4. 결정: 선호 불완전은 ROR/MMR(F9), 근거 모형 집합은 minimax regret 또는 강건 정책(F10)
5. 출력: "모든 상태·모든 근거 모형에서 안전/최선"(필연), "일부에서만"(가능), 그리고 불확실 원인이 상태 쪽인지 근거 쪽인지를 표시(각 쪽의 열거 축을 따로 고정해 다시 판정하면 되는 표준 절차)
6. 질문 선택: ODT/ECD/DRD(이전 Gate 0), 임상 응용은 ATLAS

이 결합에서 **새 증명이나 새 복잡도 결과가 필요하다는 근거는 찾지 못함**. 막히는 곳은 G5(형식화 비용·오류), G6(조합별 근거 데이터 부재), G8(독립 정답 부재)이며, 모두 알고리즘 밖이다.
