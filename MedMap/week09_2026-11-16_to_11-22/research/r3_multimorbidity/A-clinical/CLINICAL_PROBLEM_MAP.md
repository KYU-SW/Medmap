## 2. 조합별 분석

### 2.1 T2DM + CKD

**지침 내용 (ADA/KDIGO 2022 합의문, 전문 키워드 확인)** [원문으로 확인]
- 메트포르민: eGFR ≥30 권고(KDIGO 1B), eGFR <45에서 용량 조절, 30–44에서 하루 1,000 mg으로 감량, eGFR <30 금기. 급성 질환 시 중단하는 sick-day 프로토콜 권고(젖산산증 대부분이 급성 질환·AKI와 동반)
- SGLT2i: eGFR ≥20에서 권고(신장·심혈관 이득 입증 약제). 메트포르민 사용 여부·HbA1c와 무관하게 장기 보호 목적
- GLP-1 RA: 메트포르민·SGLT2i로 목표 미달 또는 사용 불가 시
- 비스테로이드 MRA(finerenone): eGFR ≥25, 정상 칼륨, ACR ≥30 mg/g이고 최대 내약 RAS 억제제 사용 중일 때. 시험 등록 조건이 칼륨 <4.8 mmol/L였음을 합의문이 명시
- ACEi+ARB 병용은 장기 이득 없이 고칼륨·AKI 증가로 회피
- RAS 억제제·SGLT2i·finerenone 모두 초기 혈역학적 GFR 감소를 일으킴 → 초기 eGFR 하락을 "악화"로 오인할 수 있음

**KDIGO 2024 CKD 지침** [초록·요약으로 확인, 2차 요약]
- SGLT2i: T2D+CKD+eGFR ≥20 (1A); CKD+ACR ≥200 mg/g 또는 HF (1A); eGFR 20–45·ACR <200은 제안(2B). 시작 후 eGFR이 20 아래로 떨어져도 투석 전까지 지속 가능
- ACEi/ARB: 4주 내 크레아티닌 30% 초과 상승이 아니면 지속(practice point)
- sick-day 지침: 탈수성 질환 시 SGLT2i·RAS 억제제·이뇨제·메트포르민 일시 중단

**현장 어려움**
- 같은 eGFR 수치에 약제마다 기준이 다름(메트포르민 30/45, SGLT2i 시작 20, finerenone 25). 규칙 자체는 명확함 → **충돌이 아니라 상태별 적용 조건의 다층화** [초록·요약으로 확인]
- 초기 eGFR 감소가 예상 반응인지 실제 악화인지 판단에는 **시점 정보(투약 시작일, 기저 eGFR, 4주 경과 여부)**가 필요 → 데이터 문제 [연구 가설]
- finerenone 시험은 칼륨 <4.8에서만 등록 → 칼륨 4.8~5.0 환자는 합의문상 "정상 칼륨"이어도 시험 근거 범위 밖 [초록·요약으로 확인 + 해석]
- 수렴 요소: SGLT2i 동반 시 finerenone 고칼륨 위험이 유의하게 낮았다는 분석을 합의문이 인용 [원문으로 확인(합의문 본문), 1차 분석 논문은 미확인]

### 2.2 T2DM + CKD + 심부전

**지침 수렴 (충돌 아님)**
- SGLT2i: HF 메타분석(5개 RCT, 21,947명)에서 심혈관사망·HF 입원 복합 HR 0.77, 박출률과 무관하게 일관 [초록·요약으로 확인]. ESC 2023 업데이트는 HFmrEF/HFpEF에 SGLT2i Class I, T2D+CKD에 SGLT2i Class I [초록·요약으로 확인, 2차 요약]. KDIGO 2024도 HF가 있으면 알부민뇨와 무관하게 SGLT2i 1A [2차 요약]
- finerenone: ESC 2023은 T2D+CKD에서 HF 입원 감소 목적 Class I [2차 요약]. FIDELIO-DKD에서 1차 신장 복합 HR 0.82, 고칼륨으로 인한 중단 2.3% vs 0.9% [초록·요약으로 확인]
- 즉 SGLT2i는 세 질환 지침이 같은 약을 권고하는 **대표적 수렴 사례**. "두 질환 공존 = 충돌" 가정의 반례

**실제 긴장 지점: 칼륨을 올리는 약의 누적**
- HFrEF에서 AHA/ACC/HFSA 2022는 MRA(스피로놀락톤·에플레레논)를 eGFR >30, 칼륨 <5.0일 때 Class 1, 시작 시·이후 3–6개월마다 칼륨·신기능 모니터링 [초록·요약으로 확인, 2차 요약]
- 같은 환자가 RAS 억제제(또는 ARNI) + 스테로이드 MRA(HF 근거) + finerenone(T2D+CKD 근거)의 후보가 될 수 있음. 스테로이드 MRA와 finerenone을 함께 쓰는 근거는 본 조사에서 찾지 못함 → **두 MRA 중 무엇을 고를지에 대한 직접 비교 근거 부족** [미검증: 지침의 명시적 언급 여부 확인 필요]
- 실제 해악 사례: RALES 발표 후 온타리오 66세 이상 ACEi 복용 HF 환자에서 스피로놀락톤 처방이 1,000명당 34→149로 증가, 고칼륨 입원 2.4→11.0, 관련 사망 0.3→2.0. 2001년 한 해 추가 고칼륨 입원 560건, 추가 원내 사망 73건 추정. HF 재입원·전체 사망 감소는 동반되지 않음 [초록·요약으로 확인] → 시험 근거를 시험과 다른 환자(고령, 신기능 저하)에게 모니터링 없이 적용한 결과로 해석됨(저자 결론은 "더 긴밀한 검사 모니터링과 신중한 사용")

### 2.3 폐선암 + CKD

- 페메트렉시드(KEYNOTE-189 계열 비편평 NSCLC 표준 병용요법 구성 약): 라벨상 Cockcroft-Gault 크레아티닌 청소율 <45 mL/min이면 투여하지 않음, 해당 구간 권장 용량 없음 [초록·요약으로 확인: DailyMed 라벨 텍스트를 검색 요약으로 확인, 라벨 페이지 직접 열람 안 함]
- 이전 Gate 0 B 감사: KEYNOTE-189 등록부 기준은 "adequate organ function" 한 줄, FLAURA 등록부에는 신기능 조건 없음 (배경 문서 인용, 이번에 재확인 안 함)
- 암 환자의 신기능 저하 빈도: IRMA(고형암 약 5,000명) 신기능 이상 50–60%, 항암제 처방의 약 80%가 용량 조절 필요 또는 신독성 [초록·요약으로 확인]. 주의: IRMA의 "신기능 이상"은 CrCl <90 수준을 포함하는 넓은 정의라 중등도 이상 CKD 비율과 다름. 폐암만의 수치는 확인하지 못함
- 시험 배제: ASCO-Friends 2017 워킹그룹은 장기 기능 이상·동반질환 환자가 흔히 배제되어 시험 참여자가 실제 환자보다 젊고 건강하다고 보고, 신독성·신배설이 직접 문제가 아니면 CrCl >30 환자 포함을 권고 [초록·요약으로 확인]
- 현장 어려움: CrCl 45 미만 환자는 시험 요법 그대로 쓸 수 없음 → 대체 요법의 근거는 다른 시험 집단에서 옴. 어떤 대체 요법이 적절한지는 종양내과 판단이며 본 조사에서 특정 대안의 근거는 **확인 필요**
- 신기능 지표 불일치: 메트포르민·SGLT2i는 eGFR(mL/min/1.73m²), 페메트렉시드는 Cockcroft-Gault CrCl(mL/min) → 같은 환자가 약마다 다른 수치로 판정됨 [초록·요약으로 확인(각 기준의 단위), 불일치 빈도는 미검증]

### 2.4 근거가 더 강한 다른 조합

**(a) 노인 다약제 복용 (근거 가장 풍부)**
- Guthrie 2015 수치(1절). OPERAM(70세 이상, 3개 이상 만성질환, 5개 이상 약, 2,008명, 중앙값 9개 약): 중재군 86.1%가 부적절 처방, 1인당 STOPP/START 권고 평균 2.75개, 62.2%가 2개월에 1개 이상 이행. 그러나 약물 관련 첫 입원 21.9% vs 22.4%, HR 0.95(0.77–1.17) — **처방은 개선됐으나 결과 개선 없음** [초록·요약으로 확인]
- STOPP/START v3(2023): 190개 기준(STOPP 133, START 57), v2 대비 66.7% 증가 [초록·요약으로 확인]. 단일기관 시험은 이득, 다기관 SENATOR·OPERAM은 ADR·사망·재입원·삶의 질 개선 없음 [초록·요약으로 확인]
- AGS Beers 2023 존재 [서지만 확인]

**(b) 심방세동 + CKD + 출혈 위험**
- DOAC 3상 시험은 CrCl 25–30 미만·투석 환자를 배제, 투석 환자 RCT는 소규모로 검정력 부족 [초록·요약으로 확인, 2차 검토문 검색 요약]
- 실제 용량: 미국 청구자료 14,865명에서 신기능상 감량 대상 1,473명 중 43.0%가 표준용량(과다 가능), 이는 주요 출혈 HR 2.19(1.07–4.46)와 연관. 감량 대상 아닌 13,392명 중 13.3%가 감량(과소 가능), 아픽사반에서 뇌졸중 HR 4.87(1.30–18.26) [초록·요약으로 확인]
- 해석: 규칙(라벨 용량 기준)이 존재하는데도 현장 처방이 불일치 → 지식 부족이 아니라 데이터(최신 CrCl·체중·나이)·운영 문제 비중이 큼. 다만 의도적 감량(출혈 우려 임상 판단)인지 오류인지 청구자료로 구분 불가 [초록·요약으로 확인 + 해석]

**(c) COPD + 고혈압/심부전 (치료 경쟁)**
- Lorgunpai 2014(미국 65세 이상 5,815명): 27개 권고 약군 중 15개(55.5%)가 다른 연구 질환을 악화시킬 수 있음. 91개 질환 쌍 중 25개(27.5%)에 잠재적 치료 경쟁. 참가자 22.6%가 공존 질환을 악화시킬 수 있는 약 복용. 고혈압+COPD 846명 중 16.2%가 비선택적 베타차단제. 37개 경쟁 상황 중 6개(16.2%)에서만 경쟁 질환 보유자가 그 약을 덜 받음 [초록·요약으로 확인]

## 3. 문제별 분석 (P1~P8)

분류: 1 의료지식 부족 · 2 환자 데이터 부족 · 3 의학 규칙 충돌 · 4 기존 알고리즘 계산상 한계 · 5 시스템 운영·사용성. 주 분류를 먼저, 보조 분류를 괄호에 적는다.

### P1. 지침 누적으로 인한 치료 부담과 우선순위 부재
- 의료적 필요성: 지침을 모두 따르면 약 12개·복잡한 요법(Boyd 2005), 경증~중등도만 적용해도 치료 부담 상당(Hughes 2013) [초록·요약으로 확인]
- 원인: 지침이 단일 질환 기준으로 개발되어 누적 효과·상대 이득 비교·우선순위를 제공하지 않음(Hughes 2013 결론)
- 분류: **1** (보조 5). 어떤 권고를 먼저 뺄지 판단할 비교 근거가 없음. 규칙끼리 모순(3)은 아님
- 기존 해결책: NICE NG56(다질환 접근, 치료 부담·목표 고려) [서지만 확인, 본문 403], Ariadne 원칙(상호작용 평가→환자 선호 기반 우선순위→개별화 관리→재평가) [초록·요약으로 확인]
- 미해결 근거: Cochrane 2021(17개 RCT) 다질환 중재는 임상 결과에 "거의 또는 전혀 차이 없음"(중등도 확실성) [초록·요약으로 확인]

### P2. CKD로 인한 약물-질환 상호작용과 신기능별 용량 기준
- 의료적 필요성: NICE T2DM 지침 약물-질환 상호작용의 84%가 CKD 관련(Dumbreck 2015). 메트포르민 eGFR 30/45, SGLT2i 20, finerenone 25, 페메트렉시드 CrCl 45, DOAC 라벨 기준 [초록·요약으로 확인 / 원문으로 확인(합의문)]
- 원인: 규칙은 명확하나 eGFR과 CrCl의 단위·계산식 차이, 최신 검사값 부재, 급성 변화(AKI)에 따른 임시 중단 필요
- 분류: **2** (보조 5). 규칙은 이미 존재하고 서로 모순되지 않음
- 기존 해결책: 신기능 용량 CDS. Chertow 2001에서 적정 용량 처방 54%→67%, 적정 빈도 35%→59%, 재원일수 4.5→4.3일 [초록·요약으로 확인]
- 미해결 근거: CDS 적용 후에도 용량 적정 67%·빈도 59%에 그침(Chertow 2001). 실제 DOAC 감량 대상의 43%가 과다용량(Yao 2017) [초록·요약으로 확인]. 원인이 데이터·운영인지 임상적 의도인지는 **확인 필요**

### P3. 고칼륨 위험 약물의 누적과 시험 밖 환자 적용
- 의료적 필요성: RALES 이후 실제 고칼륨 입원·사망 증가(Juurlink 2004). finerenone 고칼륨 중단 2.3% vs 0.9%(FIDELIO). 시험 등록 칼륨 <4.8 [초록·요약으로 확인]
- 원인: 개별 지침 모두 MRA·RAS 억제제를 권고 → 같은 방향의 약이 누적. 시험보다 고령·신기능 저하 환자에게 적용. 모니터링 간격 준수 여부
- 분류: **1** (보조 2, 5). 스테로이드 MRA vs finerenone 선택·병용 근거 부족(1), 칼륨·eGFR 추세 데이터 시점(2), 모니터링 운영(5). 지침끼리 반대 방향을 권고하는 것은 아니므로 3이 아님
- 기존 해결책: 지침 내 시작 조건(eGFR·칼륨 기준)과 모니터링 주기, 칼륨 결합제 언급(2차 요약), SGLT2i 병용의 고칼륨 감소 관찰(합의문 인용)
- 미해결 근거: 두 MRA 직접 비교·병용 근거는 이번 조사에서 미발견 → **확인 필요**

### P4. 상태 변화에 따른 일시 중단·재개 (sick-day, 초기 eGFR 감소)
- 의료적 필요성: 메트포르민 젖산산증 대부분이 급성 질환·AKI 동반, SGLT2i는 질병 중 중단 권고, RAS 억제제·SGLT2i·finerenone 모두 초기 GFR 감소 유발, ACEi/ARB는 4주 내 30% 초과 상승 아니면 지속 [원문으로 확인(합의문) / 2차 요약(KDIGO 2024)]
- 원인: 같은 약이 같은 환자에서 시점별로 "지속/일시중단/재개"로 바뀜. 판단에 투약 시작일·기저값·급성 질환 여부가 필요
- 분류: **2** (보조 5). 규칙은 시간 조건을 포함해 이미 명시됨
- 기존 해결책: sick-day 프로토콜(환자 교육), 지침의 모니터링 시점 권고
- 미해결 근거: sick-day 지침 준수율·재개 누락 빈도에 대한 정량 근거는 이번 조사에서 **미확인**. 주의: 이전 Gate 0에서 시간·정정 모델(K7)은 기존 4차원 시간 DB로 해결된다고 판정됨 → 이 문제를 계산 문제로 재포장하면 안 됨

### P5. 시험 제외로 인한 환자별 근거 공백
- 의료적 필요성: 고영향 RCT 283건 중 81.3%가 흔한 질환으로, 54.1%가 흔한 복용약으로 배제, 배제 기준 중 47.2%만 강하게 정당화(Van Spall 2007). 신약 시험 116건(122,969명)의 평균 동반질환 수는 지역사회 환자의 약 절반(Hanlon 2019). DOAC 시험의 CrCl 25–30 미만·투석 배제, 암 시험의 장기 기능 이상 배제(ASCO-Friends 2017) [초록·요약으로 확인]
- 원인: 시험 설계상 내적 타당도·안전성 위한 배제
- 분류: **1**. 데이터나 계산으로 해결 불가, 새 근거(시험·관찰연구)가 필요
- 기존 해결책: ASCO-Friends 적격 기준 확대 권고, 실제 자료(registry) 연구, UK Kidney Association 2025 진행성 CKD 항응고 지침(2차 요약)
- 미해결 근거: 투석 환자 DOAC RCT 검정력 부족(2차 요약). Hanlon 2019는 시험 내에도 다질환자가 상당수 있어 하위군 분석 자원으로 활용 가능하다고 함 → 공백의 일부는 기존 시험 IPD로 줄일 수 있으나 IPD 접근은 이전 Gate 0에서 미확인

### P6. 치료 경쟁 (한 질환 권고약이 다른 질환을 악화)
- 의료적 필요성: 고령자 22.6%가 공존 질환을 악화시킬 수 있는 약 복용, 질환 쌍 27.5%에 잠재 경쟁, 경쟁 상황 16.2%에서만 처방이 줄어듦(Lorgunpai 2014) [초록·요약으로 확인]
- 원인: 지침이 다른 질환을 고려한 수정 권고를 거의 제공하지 않음(Dumbreck: 상호작용 대부분이 지침에 강조되지 않음)
- 분류: **3** (보조 1). 이번 조사에서 "실제 규칙 충돌"에 가장 가까운 문제. 단 결과 영향(경쟁 약을 썼을 때 실제 해악 크기)은 Lorgunpai도 "연구 우선순위"로 남김 → 1이 동반
- 기존 해결책: 약물-질환 상호작용 데이터베이스, STOPP 기준(질환별 회피 약)
- 미해결 근거: 처방이 줄지 않은 것이 무지인지 이득이 더 크다는 판단인지 구분 근거 없음 → **확인 필요**

### P7. 경고 피로와 CDS 사용성
- 의료적 필요성: 약물 안전 경고 무시율 49–96%(17개 연구 검토), 원인으로 낮은 특이도·민감도, 불명확 정보, 불필요한 업무 중단 [초록·요약으로 확인]. 다약제 환자일수록 상호작용 경고가 많음(Guthrie: 15종 이상 80.8% 상호작용)
- 원인: 개별 쌍 단위 경고, 환자 맥락(이미 모니터링 중, 의도적 병용) 반영 부족
- 분류: **5**. 무시의 상당수가 정당할 수 있다고 저자가 명시 → 경고의 계산 정확도보다 적합성·업무 흐름 문제
- 기존 해결책: 경고 등급화·필터링(이번에 개별 연구 미확인)
- 미해결 근거: van der Sijs 2006 이후 최신 무시율·개선 효과는 이번 조사에서 미확인

### P8. 투약 검토 도구의 결과 효과 부재
- 의료적 필요성: OPERAM에서 STOPP/START 기반 중재로 부적절 처방은 줄었지만 약물 관련 입원 HR 0.95(0.77–1.17), 낙상·사망도 차이 없음. SENATOR도 무효 [초록·요약으로 확인]
- 원인: 어떤 처방 변경이 실제 결과를 바꾸는지에 대한 지식 부족, 이행률(62.2%) 한계, 기준 자체가 환자 목표를 반영하지 않을 가능성 [연구 가설]
- 분류: **1** (보조 5)
- 기존 해결책: STOPP/START v3, Beers 2023, 약사-의사 공동 검토, CDS(OPERAM의 STRIP 도구)
- 미해결 근거: 다기관 RCT 무효 결과가 반복됨(McGettigan 2023 리뷰)

## 4. 분류 4(계산 한계)를 배정하지 않은 이유
- P2·P7의 실패 수치(Chertow 67%, Yao 43%, 무시율 49–96%)는 규칙 계산의 정확도가 아니라 입력 데이터·임상 의도·사용성 문제로 설명됨(각 초록의 저자 해석)
- Dumbreck 2015의 제언은 "상호작용적 지침 제작·배포 방식"으로, 계산 방법이 아니라 지침 전달 문제
- 이전 Gate 0에서 다질환 처방 조합(JNP)은 MILP·LP로, 최소 확인(MDQ)은 hitting set·결정나무로, 시간·정정(K7)은 기존 시간 DB로 풀렸음(배경 문서) → 같은 계열 문제를 4로 볼 근거 없음
- 4로 분류하려면 "규칙·데이터·근거가 모두 주어졌는데도 기존 계산 방법이 정답을 내지 못하는 실제 사례"가 필요하며, 이번 조사에서는 찾지 못함

## 6. MedMap 관점 시사점 (연구 가설, 채택 아님)
- [연구 가설] 확인된 문제의 대부분은 1(근거 공백)과 2·5(데이터·운영)다. "새 계산 알고리즘"이 직접 해결할 대상은 이번 조사에서 확인되지 않았다
- [연구 가설] MedMap 목표(지지·충돌·미확인 정보·시점 표시)와 가장 가까운 것은 P5의 "이 환자가 근거 시험 범위 밖인지 표시"와 P2·P4의 "판정에 필요한 검사값·시점이 비어 있음 표시"다. 그러나 전자는 이전 Gate 0의 K1(Trial Score·Seneviratne 등 선행), 후자는 K7(시간 DB 선행)과 겹치므로 **신규 알고리즘 근거로 쓰면 안 됨**
- [연구 가설] P6(치료 경쟁)은 유일하게 분류 3 근거가 정량으로 있으나, 기존 약물-질환 상호작용 DB·STOPP가 이미 같은 정보를 다룸 → 기여는 지식 표현·평가 쪽일 가능성
