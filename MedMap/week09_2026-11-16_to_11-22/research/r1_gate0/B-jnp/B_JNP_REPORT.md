## 0. 판정 요약

**신규성 판정: NO-GO (알고리즘 신규성 기준). 문제 정식화·평가 기준(벤치마크)로는 CONDITIONAL.**

- [실제 실행으로 확인된 결과] 합성 인스턴스 700개(선택지 판정 4,320개)에서 기존 방식인 **MILP(scipy milp/HiGHS, 쌍대·Farkas·cutting plane)** 와 **상태 열거 + 상태별 강건선호 LP(ror_lp_combo)** 가 정답(exact_enum)과 범주 100% 일치했다. JNP 후보 알고리즘도 100% 일치. 확장성 실험(nU 20까지)에서도 MILP와 후보가 100% 일치.
- [직접 확인된 사실] 핵심 질문 "기존 제약 최적화(MILP/QCSP)+ROR 조합이 JNP와 같은 출력을 내는가?" → **예, 같다.** 단 조건 3개를 지켜야 한다: (1) 가능 최선을 pairwise 가능 관계의 논리곱이 아니라 "모든 경쟁자에 대해 동시에" LP로 판정, (2) ∃w 판정을 W 꼭짓점만으로 하지 않음, (3) "∃w∀s"(하나의 선호로 모든 상태)는 상태별 결과 결합으로 얻을 수 없으므로 별도 질의(합친 LP 또는 cutting plane)로 계산. 이 조건을 어긴 naive 조합은 실제로 틀린다(아래 실패 사례).
- [직접 확인된 사실] 후보 알고리즘(2-SAT 전파 → 3값 적격성 가지치기 → 관련 변수 투영 열거 → 서명별 LP)은 알려진 기법(단위 전파, 투영 모델 열거, 서명 메모이제이션, ROR LP)의 조합이며 출력은 기존 방식과 동일하다. 새 알고리즘이라고 주장할 근거가 없다.
- [실제 실행으로 확인된 결과] 시간: 미확인 12개(중앙 1,536 상태)에서 중앙값 exact 0.094s, 후보 0.074s, MILP 0.092s, ror_lp_combo 0.311s. 스트레스(규칙 수=nU) nU=20 에서 후보 0.41s(서명 944개)로 증가, MILP 0.087s로 거의 평탄. 모두 같은 Python/같은 장비이며 차이의 상당 부분은 구현 차이일 수 있다.

## 1. 정식화

### 1.1 입력
- 조건 c_1..c_k, 관측 obs_i ∈ {T, F, U(미확인), C(상충: T 출처와 F 출처가 모두 있음)}.
- 의존성 D: `imp(a,b)` = c_a=T → c_b=T, `excl(a,b)` = ¬(c_a=T ∧ c_b=T). (모두 2-절 → 2-SAT 클래스)
- 가능 임상 상태 집합
  S = { s ∈ {0,1}^k : obs_i=T ⇒ s_i=1, obs_i=F ⇒ s_i=0, s 가 D 를 모두 만족 }.
  U 와 C 는 모두 "T/F 둘 다 가능"으로 취급한다(상충 기록 = 둘 다 가능 세계).
- 선택지 o 의 금기 규칙: 리터럴의 논리곱 r = ∧(c_i = v). 하나라도 발동하면 o 는 상태 s 에서 부적격.
  적격 el(o,s) = ¬∨_r r(s). **안전 제약은 hard**: 부적격 선택지는 어떤 선호로도 최적이 될 수 없다.
- 기준 j=1..m 점수 v_j(o,s) = base_{oj} + Σ_{(o,j,i,δ)} δ·s_i (상태 의존 수정 포함). base 가 정의되지 않으면 누락(None).
- 가중치 polytope W = { w ≥ 0, Σ w = 1, w_a ≥ w_b (서열 제약), lo_j ≤ w_j ≤ hi_j }. 효용 U(o,s,w) = Σ_j w_j v_j(o,s).

### 1.2 최적성과 다섯 양화 판정
opt(o,s,w) ⇔ el(o,s) ∧ ∀q: el(q,s) ⇒ U(o,s,w) ≥ U(q,s,w)  (약한 최적, 동점 허용)

| 플래그 | 정의 | 의미 |
|---|---|---|
| AA | ∀s∈S ∀w∈W opt | 필연 최선 |
| EE | ∃s ∃w opt | 가능 최선 |
| AE | ∀s ∃w opt | 어떤 상태든 그 상태에 맞는 선호가 있으면 최선 |
| EA | ∃s ∀w opt | 어떤 상태가 확인되면 선호와 무관하게 최선 |
| EwAs | ∃w ∀s opt | 하나의 선호로 모든 상태에서 최선 (AE 보다 강함) |

[직접 확인된 사실] AA ⇒ EA ⇒ EE, AA ⇒ EwAs ⇒ AE ⇒ EE (S≠∅). AE 와 EwAs 는 다르다: HC4 O1 은 AE=1, EwAs=0 (상태마다 필요한 w 구간이 겹치지 않음).

### 1.3 출력 범주 (정확한 정의)
우선순위 순서로 적용한다.
1. **INSUFFICIENT (정보 부족으로 평가 불가)**: (a) S = ∅ (관측과 의존성이 모순 → 가능 세계가 하나도 없음; 모든 선택지), 또는 (b) o 자신의 점수 v_j(o) 가 정의되지 않았고 그 기준의 가중치가 양수일 수 있음 (max_{w∈W} w_j > 0). (b)의 경우 다른 선택지 판정은 누락값을 [0,1] 미지수로 보고 ∀ 판정은 최악값(o 0, 경쟁자 1), ∃ 판정은 최선값(o 1, 경쟁자 0)을 대입해 정확히 계산한다(w ≥ 0 이므로 단조).
2. **ALWAYS (항상 유지)**: AA = 1.
3. **EXCLUDED (항상 탈락)**: EE = 0. (요청된 4범주에 더해, 완전한 분할을 위해 명시적으로 추가)
4. **CONDITIONAL (일부 조건에서만 유지)**: EE=1, AA=0, EA=1 — 미확인 조건이 특정 값으로 확인되면 선호와 무관하게 확정되는 세계가 존재. "조건 확인"이 판정을 닫을 수 있다.
5. **UNDETERMINED (확정 불가)**: EE=1, EA=0 — 어떤 상태가 확인되더라도 선호 정보 없이는 최선으로 확정되지 않음. 조건 확인만으로는 닫히지 않고 선호(가중치) 정보가 필요.

[직접 확인된 사실] "적격성 판정에 필요한 조건이 미확인이라 세계마다 판정이 갈리는" 경우는 INSUFFICIENT 가 아니라 S 위의 양화로 정확히 표현된다(CONDITIONAL/UNDETERMINED/EXCLUDED 중 하나). 따라서 INSUFFICIENT 는 "계산 자체가 정의되지 않는 경우"로만 좁게 정의했다. 이 선택은 [현재 연구 가설] 수준의 설계 결정이며, 상위 연구(A/C)에서 다른 정의를 원하면 범주 함수만 바꾸면 된다(플래그 5개는 그대로).

### 1.4 꼭짓점 충분성 (증명)
- [직접 확인된 사실] **∀w 판정은 W 의 꼭짓점으로 충분하다.** 고정 s, q 에 대해 f(w) = U(o,s,w) − U(q,s,w) = (v(o,s) − v(q,s))·w 는 w 에 선형. W 는 유계 다면체(심플렉스의 부분집합)이므로 선형 함수의 최소는 꼭짓점에서 달성된다(선형계획 기본정리). 따라서 min_{w∈W} f ≥ 0 ⇔ 모든 꼭짓점 v 에서 f(v) ≥ 0. ∀w∀q = ∀q∀w 이므로 필연 최선 판정 전체가 꼭짓점으로 충분하다.
- [직접 확인된 사실] **pairwise ∃w (a ≿_P b) 도 꼭짓점으로 충분**하다 (max 도 꼭짓점에서 달성).
- [직접 확인된 사실] **"∃w: o 가 모든 경쟁자보다 동시에 좋음"(가능 최선)은 W 꼭짓점만으로 불충분하다.** 반례 HC2: W=심플렉스(꼭짓점 (1,0),(0,1)), O1=(1,0), O2=(0,1), O3=(0.6,0.6). 꼭짓점에서는 O1 또는 O2 가 최선이지만 w=(0.5,0.5) 에서 U(O3)=0.6 > 0.5 이므로 O3 는 가능 최선. 실행 확인: `vertex_only` 기준선이 HC2 O3 를 EXCLUDED 로 오판 (logs/handcases.log).
  그래서 정답 코드는 확장 polytope W ∩ {w : (v_q − v_o)·w ≤ 0, ∀적격 q} 의 꼭짓점 존재 여부(유계 다면체는 비어있지 않으면 꼭짓점을 가짐)로 판정한다.
- [직접 확인된 사실] pairwise 가능 관계의 논리곱(∀b: a ≿_P b)은 가능 최선보다 약하다(∀b∃w ⇏ ∃w∀b). 반례 HC7: O3=(0.4,0.4)는 O1, O2 각각에 대해 가능 우위지만 동시에는 불가(max(w1, 1−w1) ≥ 0.5 > 0.4). `ror_pw_combo` 가 HC7 O3 를 UNDETERMINED 로 오판(불필요 보류).

## 2. 구현한 방법 (각각 독립 파일)

| # | 파일 | 방법 | 성격 |
|---|---|---|---|
| 1 | `exact_enum.py` | 상태 전체 열거 × brute-force 꼭짓점 열거 (W 꼭짓점: ∀w, 확장 polytope 꼭짓점: ∃w, 모든 상태 부등식 합친 polytope: ∃w∀s). LP/MILP 미사용, **다른 모듈 import 없음** | 정답 생성 |
| 2 | `pref_lp.py` | 고정 상태에서 불완전 선호 전체 고려: nec = 경쟁자별 min LP, pos = max τ LP 1개 | 부품(기존) |
| 3 | `ror_pairwise.py` | ROR식 a≿_N b (min ΔU ≥ 0), a≿_P b (max ΔU ≥ 0) 를 LP로; 필연최선 = ∀b ≿_N, 가능최선(pairwise) = ∀b ≿_P | 기존 강건선호 |
| 4 | `ror_combo.py` | 상태 열거 후 상태별 판정을 ∀/∃ 결합. `ror_pw_combo`(pairwise), `ror_lp_combo`(정확 LP). EwAs 는 naive 규칙 EwAs:=AE | naive 조합 기준선 |
| 5 | `milp_solver.py` | 상태 이진변수 + 의존성 선형제약 + 규칙/적격성 AND/NOR 선형화 + w·s McCormick. EE 직접, AA 보완질의(max t), EA = LP 쌍대 내장, AE = Farkas 증명서 + McCormick, EwAs = LP master + MILP separation cutting plane | 기존 정확 제약해결기 |
| 6 | `jnp_candidate.py` | 2-SAT 단위전파 → 강제 리터럴 → 3값 적격성 가지치기 → 관련 변수만 DFS 투영 열거(UP로 확장 가능성 검사) → (적격, 점수) 서명 중복 제거 → 서명별 LP, 조기 종료. **다른 모듈 import 없음** | JNP 후보 |
| a | `naive_baselines.closed_world` | U→F, 상충→마지막 기록값, 의존성 무시, 단일 상태 | 약한 기준선 |
| b | `naive_baselines.ignore_unknown` | 미확인 조건이 들어간 규칙·점수수정 무시, 단일 상태 | 약한 기준선 |
| c | `naive_baselines.penalty` (P=1, 10) | 부적격을 효용 −P 로 섞음. 상태 열거·양화는 정확 | 약한 기준선 |
| d | `naive_baselines.vertex_only` | ∃w 를 W 꼭짓점에서만 검사 | 약한 기준선 |

- [직접 확인된 사실] 정답 코드(`exact_enum.py`)와 후보 코드(`jnp_candidate.py`)는 서로 import 하지 않고, 공통 모듈도 쓰지 않는다. 판정 원리도 다르다(정답: 선형계 brute-force 꼭짓점, 후보: HiGHS LP). MILP는 세 번째 독립 정식화다. (단 `naive_baselines.vertex_only` 는 정답 코드의 꼭짓점 함수를 재사용하는 약한 기준선이다.)
- [직접 확인된 사실] MILP 정식화의 정확성 근거: s 가 이진이므로 AND/NOR 선형화와 McCormick(z = w·s, λ·s) 이 정확. EA 는 "∀w∈W: d(s)·w ≥ 0" 을 LP 강쌍대(μ − Gᵀy ≤ d(s), μ − hᵀy ≥ 0)로 바꾸며 s 는 우변 d(s) 에만 선형으로 들어가 쌍선형 항이 없다. AE 의 보완 "∃s: {w: o 최적} = ∅" 은 Farkas 보조정리로 증명서 존재 문제가 되고, 증명서를 Σ ≤ 1 로 정규화하여 λ·s 곱을 McCormick 으로 정확히 선형화한다. EwAs 는 2단계(∃w∀s) 구조라 단일 MILP 가 아니라 cutting plane(유한 상태 → 유한 반복 종료)으로 푼다.

## 6. 실패 사례 (실제 인스턴스, `results_failure_examples.csv`, `results_failure_breakdown.csv`, `logs/failure_mechanism_check.log`)

[실제 실행으로 확인된 결과] 정확 3방법(milp, jnp_candidate, exact)은 실패 0건. 아래는 약한 기준선의 실패 유형별 대표 사례.

1. **closed_world — 잘못된 확정** (seed 300000, wcons=0, 선택지 O3): 관측 `FTUCUUUUTT`, 의존성 c9→c3. O3 은 "c7=F" 이면 금기. closed-world 는 U→F 로 c7=F 를 가정 → O3 부적격 → EXCLUDED. 실제로는 18개 가능 상태 중 6개에서 O3 적격이며 가능 최선(정답 UNDETERMINED). 또 closed-world 상태 자체가 의존성(c9=T → c3=T)을 위반해 S 에 속하지 않음. 전체에서 closed_world 잘못된 확정 1,129건(이 중 정답 UNDETERMINED→EXCLUDED 973건, CONDITIONAL→ALWAYS 63건).
2. **ignore_unknown — 잘못된 확정과 거짓 EwAs**: 미확인 조건 규칙을 무시하면 적격성은 낙관적이 되지만, 경쟁자도 적격으로 남아 o 를 EXCLUDED 로 확정하거나(705건), 단일 상태라 EwAs 를 과대(1,265건)로 낸다. HC5 처럼 모순 기록도 감지 못한다.
3. **penalty (P=1, P=10 동일 결과) — 불필요 보류 13건, 거짓 EwAs 2건**: seed 400001 (n=3) O1 은 24개 상태 어디서도 적격이 아니지만(정답 EXCLUDED), 6개 상태에서 세 선택지가 모두 부적격 → 벌점 방식은 "가장 덜 나쁜" O1 을 최선으로 고른다(UNDETERMINED). 벌점 크기를 키워도(P=10) 고쳐지지 않는다: 원인은 크기가 아니라 "모두 부적격인 세계에서 아무것도 최선이 아니어야 한다"는 hard 제약 의미를 효용 비교가 표현하지 못하기 때문. n 이 작거나 규칙이 많을 때만 발생(표 4: n=3, rules=9·12).
4. **ror_pw_combo — 불필요 보류 155건**: seed 100003 (nU=0, 상태 1개) O1: 경쟁자 각각에 대해 pairwise 가능 우위는 있지만 동시에 이기는 w 가 없음(정답 EXCLUDED → UNDETERMINED). n 이 클수록 증가(n=12 에서 30건).
5. **vertex_only — 잘못된 확정 175건**: seed 100006 (nU=0) O6: W 내부(꼭짓점 아님)에서만 최선인 타협안을 EXCLUDED 로 확정. n 이 클수록 증가(n=12 에서 27건).
6. **ror_lp_combo — 거짓 EwAs 6건 (범주는 100% 일치)**: seed 801001 O6: 각 상태마다 최선이 되는 w 는 있으나(AE=1) 공통 w 는 없음(EwAs=0). 상태별 결과만 결합하는 구조로는 "하나의 선호로 모든 상태" 질문에 답할 수 없다. 다섯 플래그 중 EwAs 만 틀리고 범주 정의는 EwAs 를 쓰지 않으므로 범주 일치율은 1.000.

[직접 확인된 사실] 위 기준선을 이긴 것은 신규성 근거가 아니다. 이들은 문제를 잘못 정식화한 기준선이며, 올바르게 정식화한 기존 방법(milp, ror_lp_combo+EwAs 별도 LP)은 모두 정답과 같다.

## 8. 핵심 질문: 기존 제약 최적화(MILP/QCSP)+ROR 조합이 JNP 와 같은 출력을 내는가?

**답: 예 (조건부 아님, 단 올바른 질의 구성이 필요).**
- [실제 실행으로 확인된 결과] MILP 단독으로 다섯 플래그 전부와 범주가 정답과 4,320/4,320 일치(+ 확장성 실험 nU 20까지 후보와 100% 일치).
- [실제 실행으로 확인된 결과] 상태 열거 + 상태별 정확 LP(ROR 의 가능/필연 판정을 "모든 경쟁자 동시" 로 확장한 형태) 결합은 AA, EE, AE, EA 와 범주에서 100% 일치. EwAs 만 상태별 결합으로 얻을 수 없어 별도 LP 하나(모든 상태 부등식 합침)가 필요 — 이는 `naive_baselines.penalty` 와 후보 코드에서 쓴 것과 같은 표준 LP 이다.
- [직접 확인된 사실] 수학적으로: ∀s∀w, ∃s∃w 는 단일 MILP(또는 보완 MILP), ∃s∀w 는 LP 쌍대로 단일 MILP, ∀s∃w 는 Farkas 보완으로 단일 MILP, ∃w∀s 는 2단계 문제로 cutting plane. 상태 집합이 2-SAT 의존성 + 유한 이진 변수이므로 전부 기존 MILP/QBF(2단계) 틀 안에 들어간다. 정량화 순서가 섞인 경우(∀∃)는 QCSP/2QBF 형식과 같은 구조이며, 선형 W 덕분에 LP 쌍대로 1단계로 내릴 수 있다.
- [직접 확인된 사실] 같은 출력을 내지 못하는 것은 "잘못 조합한" 경우뿐: pairwise ROR 논리곱(가능 최선 과대), W 꼭짓점만 검사(타협안 누락), 상태별 결과로 EwAs 추정, 미확인을 F 로 가정, 안전을 벌점으로 섞기.

## 9. 신규성 판정

**알고리즘 신규성: NO-GO.**
- [직접 확인된 사실] JNP 후보의 각 단계(2-SAT 단위전파·failed literal, 3값 평가, 투영 모델 열거, 서명 메모이제이션, ROR LP)는 모두 표준 기법이며, 출력은 기존 MILP 및 ROR-LP 조합과 동일하다. 속도 이점도 관련 변수가 적을 때만 있고 규칙이 많아지면 MILP 가 더 평탄하다(표 11). "새 알고리즘"으로 주장할 근거가 없다.

**문제 정식화/평가 프로토콜로서의 기여: CONDITIONAL.**
- [현재 연구 가설] 기여 가능성이 남는 부분은 알고리즘이 아니라 (1) 안전 hard 제약 + 3값·상충 기록 + 불완전 가중치를 묶은 다섯 양화 판정과 5범주(특히 CONDITIONAL vs UNDETERMINED: "조건 확인으로 닫히는가 / 선호 정보가 필요한가") 의 정식 정의, (2) 흔한 잘못된 설계(closed-world, 벌점 혼합, pairwise ROR, 꼭짓점-only, 상태별 결합 EwAs)가 실제로 틀리는 사례와 빈도를 보여주는 검증 벤치마크. 이 정식화 자체가 선행연구(ROR/SMAA, possibilistic/robust MCDA, QCSP, 불완전 정보 하 의사결정)에 이미 있는지는 SUBAGENT A 결과로 확인해야 한다.
- [아직 확인하지 못한 사항] 위 정식화의 선행연구 존재 여부, 실제(비합성) 규칙 구조에서의 관련 변수 수, CONDITIONAL/UNDETERMINED 구분이 사용자에게 유용한지.
