# SUBAGENT E — 대체 연구 문제·추가 기술 탐색 (MedMap Gate 0)

- 작성일: 2026-11-17
- 범위: JNP·MDQ에 신규성이 없을 수 있다고 전제하고, 대체 연구 문제 10개(요청 목록)와 새 후보를 비교한다. 같은 연구는 하나로 합친다.
- 방법: WebSearch(검색 결과 요약·초록 수준) + 로컬 코드 grep(읽기 전용). **원문 전체를 읽은 논문은 없다.** 모든 문헌 판단은 초록·검색 요약 수준이며 `sources.csv`의 `access_level`에 표시했다.
- 태그: **[확인]** = 직접 확인한 사실(코드 grep 결과 또는 검색으로 확인한 초록·메타데이터), **[가설]** = 현재 연구 가설, **[미확인]** = 아직 확인하지 못한 사항
- 참고 문서 3건(연구방향 공동 검토·의사결정·독립비판)은 배경으로만 읽었고 결론을 따르지 않았다.

## 3. 후보별 상세

### K1. 환자별 근거 적용 범위 검증 + 정보 부족/지식 부족 구별 (요청 1·2·9 병합)

**실제 의료 문제**
- [확인] 임상시험 결과를 어느 환자에게 적용할 수 있는가(외적 타당도)는 의사들이 RCT·지침에 가장 자주 하는 비판이라고 Rothwell(Lancet 2005, 초록)이 기술.
- [확인] 동반질환·복합질환 환자는 신약 시험에서 지역사회 인구보다 적게 대표된다(Hanlon 등 BMC Med 2019, 검색 요약). 동반질환 수에 따른 치료효과 차이는 시험에서 거의 보고되지 않는다(Hanlon 등 PLoS Med 2023, 저자 요약 문구만 확인).
- [확인] 지침 개발 쪽에서 적용 가능성 판단은 GRADE '간접성'에 포함되지만 판단이 암묵적이라는 지적(JMIR 2025 e52385, 검색 요약).

**선행연구가 해결한 것**
| 연구 | 해결한 것 | 단위 | 확인 수준 |
|---|---|---|---|
| GIST / GIST 2.0 (Weng 그룹, Sen 등 2016) | 시험 포함·제외 기준이 실제 환자 *집단*을 얼마나 대표하는지 사전 지표 | 시험 × 집단 | 초록·검색 요약 |
| Hanlon 2019/2022/2023 | 시험 인구의 동반질환 대표성, SAE 기반 대표성 | 시험 × 집단 | 검색 요약 |
| TrialGPT (Jin 등 Nat Commun 2024) | 환자 → 시험 기준별 적격성 판정(87.3% 기준 단위 정확도, 초록) | 환자 × 시험(모집 목적) | 초록 |
| n2c2 2018 Track 1, Criteria2Query 등 | 환자 기록에서 시험 적격성 기준 판정 | 환자 × 시험(모집 목적) | [미확인: 이번에 원문·초록 재확인 안 함] |
| JMIR 2025 디지털 도구(Edinburgh/CPRD) | 지침 개발자가 시험 기준으로 층화한 인구의 복합질환·다약제 유병률 확인 | 집단, 지침 개발 단계 | 검색 요약 |

**미해결 부분과 근거**
- [가설] '진료 시점의 *한 환자*에게 *특정 권고*의 근거 시험들이 적용되는가'를 **권고 → 근거 시험 → 포함·제외 기준 → 환자 부분 기록**으로 자동 대조하는 연구는 이번 검색(3회)에서 찾지 못함. 모집 목적(TrialGPT 계열)은 '환자를 시험에 넣을지'이고, 적용 목적은 '시험 결과를 이 환자에게 옮겨도 되는지'라 출력 의미가 다르다. 특히 시험 운영 기준(동의서, 피임 등)은 적용 판단에서 빼야 하고, 반대로 '기준에 언급되지 않은 동반질환'은 모집에선 무시되지만 적용에선 '근거 없음'으로 남아야 한다.
- [미확인] GRADE 간접성의 환자 단위 자동화, CDS Hooks/CQL 기반 적용성 검사, 'evidence applicability' 키워드로 PubMed 체계 검색은 하지 않았다. **이 공백 판단은 검색 범위가 좁아 확정할 수 없다.** A(선행연구) 결과와 대조해야 함.

**새 계산 문제(수학적 형태)**
- 입력: 권고 r, 근거 시험 집합 T(r), 각 시험 t의 기준식 Φ_t = Inc_t ∧ ¬Exc_t (환자 속성 변수 X 위의 식), 환자 부분 할당 σ: X → {참, 거짓, 미확인}, 속성 출처·시점.
- 출력: 시험별 3값 판정 v_t(σ) ∈ {범위 안, 범위 밖, 판정 불가}(Kleene 3값 평가), 권고 수준 판정 = {근거 범위 안 / 지식 부족(모든 t에서 범위 밖, 또는 환자의 주요 동반질환이 어느 Φ_t에도 언급되지 않음) / 정보 부족(판정 불가가 남음)}, 정보 부족일 때 판정을 확정하는 최소 확인 속성 집합.
- 목적: 정보 부족과 지식 부족의 **오분류율 최소화**(특히 '지식 부족을 정보 부족으로 표시해 질문만 늘리는 오류'와 '범위 밖인데 범위 안으로 표시하는 과일반화 오류').

**기존 알고리즘과 차이**
- 3값 평가 = Kleene 논리(신규성 없음). 최소 확인 속성 집합 = 부분 할당의 확장 중 식 값을 고정하는 최소 변수 집합 → prime implicant/최소 히팅셋 계열(신규성 없음, MDQ와도 겹침).
- '언급되지 않은 동반질환 = 지식 부족' 규칙은 계산상 단순하나 **과제 정의로는 [가설] 새로울 수 있음**.
- 판정: **알고리즘 신규성 부족, 문제·평가 틀 신규성 가능성 있음.** '기능 결합'이 아니라 '새 과제 정의'로만 주장 가능.

**공개 데이터**
- ClinicalTrials.gov / AACT(공개) — 기준문 [확인: 공개 레지스트리로 일반 알려진 사실, 이번에 다운로드·접속 확인 안 함 → 사용 조건 확인 필요].
- TREC Clinical Trials 2021–2023 topics/qrels — 환자 요약 × 시험 적격 라벨 [미확인: 이번에 접속 안 함].
- n2c2 2018 cohort selection — DUA 필요 [미확인].
- Synthea 합성 환자, MIMIC-IV Demo(참고 문서 기술, D가 확인 담당).
- 권고 → 근거 시험 연결: 지침 본문 참고문헌. NICE는 AI 재사용 라이선스 제한(참고 문서가 공식 페이지 링크로 기술, E는 직접 확인 안 함). USPSTF·KDIGO·ADA 등 다른 지침의 재사용 조건 [미확인].

**정답 확보**
- 1단계(기계 정답): 기준식 수작업 코딩 + 합성 환자에 대해 판정 참값은 정의상 계산 가능 → **구현 검증일 뿐 의학적 정답 아님**.
- 2단계: TREC CT/n2c2 적격 라벨을 '범위 안/밖' 대리 정답으로 사용(모집 목적 라벨이라 의미 차이 존재 → 한계로 명시).
- 3단계: 의사 2인 이상 독립 판정(권고 20~30개 × 합성 환자 사례), κ 보고. 사람 평가는 IRB 필요 여부 확인.

**구현 가능성**: 중. 기준식 코딩이 병목(권고 1개당 시험 수 개 × 기준 수십 개). LLM 자동 변환은 외부 유료 API 금지 규칙과 충돌하므로 로컬 모델 또는 수작업.

**실패 위험**: (1) A가 동일 과제의 선행연구를 찾으면 신규성 소멸. (2) 포함·제외 기준만으로 적용 가능성을 판정할 수 없다는 근본 한계(참고 문서도 지적) — 출력은 '적용 가능'이 아니라 '근거 범위 안/밖/판정 불가'로 제한해야 함. (3) 권고-시험 연결 수작업 비용.

**논문 기여 가능성**: 중. 의료정보학 학회(AMIA, MIE, JAMIA Open급) 단문·데이터셋 논문 수준 [가설]. AI 알고리즘 학회급 기여는 기대하기 어려움.

### K2. 다중지침 충돌 원인 정확 식별(MUS 진단)

- 실제 문제: [확인] Dumbreck 등 BMJ 2015(참고 문서 기술) 등 지침 간 잠재 상호작용 존재.
- 선행연구: [확인] Bowles 등 2019(Sci Comput Program, 검색 요약) — 지침을 형식 모델로 바꾸고 정리 증명기·제약 해결기로 불일치 탐지. [확인] Xie & Du 2026 arXiv 2604.17340(초록) — LLM 다중 에이전트 + SAT로 충돌 탐지, 'Local Conflict'(동반질환 교차에서만 생기는 충돌) 정의, 12개 SGLT2i 지침에서 90.6%가 Local, F1 0.861. 초록에는 MUS/unsat core 언급 없음. [확인] Z3로 충돌 최소 약물 집합 탐색(Springer 장, 검색 요약). MitPlan 계열(참고 문서).
- 미해결: 충돌을 '어느 권고·어느 환자 조건의 최소 조합이 일으키는가'로 설명하는 것은 SAT 해결기에서 unsat core / MUS 열거(QuickXplain 2004, MARCO 2016)로 바로 얻어진다. [미확인] Bowles 2019 원문에서 MUS 사용 여부.
- 계산 문제: 입력 = 권고 제약 집합 R, 환자 사실 F. 출력 = R∪F의 모든 MUS(또는 최소 교정 집합 MCS). → **표준 MUS/MCS 열거 그대로**. 환자 정보가 미확인일 때 '가능한 MUS / 필연 MUS'로 확장하면 JNP의 3값 확장과 같은 구조가 됨(중복).
- 공개 데이터: 지침 원문(라이선스 문제), MGCDS 4사례(참고 문서). 정답: 전문가가 표시한 충돌 원인.
- MedMap 활용: 충돌 그래프 코드 없음(`grep conflict` 결과 main-ai에서 관련 모듈 미발견) [확인].
- 판정: **신규성 부족.** 기존 알고리즘으로 충분. 시스템 기능으로만 사용.

### K3. 판단 정당성 유지: 검사 정정·시간 만료·근거 무효화 시점 (요청 4·5·8 병합)

- 실제 문제: [확인] 정정된 검사 결과로 진단이 바뀌었는데 의사가 새 결과를 예상하지 못해 이미 잘못된 정보로 행동했을 수 있다(AHRQ PSNet 사례, 검색 요약). [확인] 한 상용 시스템 문서는 인터페이스로 들어온 결과 갱신은 재검토를 강제하지만 수동 수정은 강제하지 않는다고 기술(검색 요약, 벤더 문서).
- 선행연구(의료): [확인, 검색 요약만] 경고를 일으킨 값이 수정되어 기준을 벗어나면 경고를 철회하는 기능(6주 490건 중 2건 철회), 경고 검토 시점에 이후 들어온 관련 데이터 표시(1,104건 중 286건 25.9%) — PMC2233581. 제목·저자는 PMC 접속 차단으로 **[미확인]**.
- 선행연구(계산): [미확인: 이번에 재확인 안 한 고전 문헌] TMS(Doyle 1979), ATMS(de Kleer 1986), provenance semiring(Green 등 2007), why-not provenance(Chapman & Jagadish 2009), 증분 뷰 유지 DRed(Gupta 등 1993), AGM 믿음 수정(1985), 지식 기반 시간 추상화 KBTA(Shahar 1997, 지속 시간·문맥 해석 포함, 검색으로 존재만 확인), bitemporal DB(valid time / transaction time).
- 계산 문제: 입력 = 판단 J와 정당화 집합 S(J)(사실 + 규칙, 각 사실에 유효 구간 [t_s, t_e]와 기록 시각), 변경 이벤트(정정·철회·만료). 출력 = J가 정당한 시간 구간, 무효화 최초 시점 t*, 무효화를 일으킨 최소 사실 집합. → provenance 다항식에서 사실 삭제 전파 + 유효 구간 교집합. **TMS/ATMS + bitemporal 질의로 환원**.
- 공개 데이터: [미확인] MIMIC-IV에 정정 이력(정정 전 값)이 남는지 확인 필요(D 담당 영역). 없으면 합성 정정 주입만 가능.
- MedMap 활용: [확인] `encounterLink.ts`의 `stateAsOf(view, at, {reviewedOnly})` — `availableAt <= at` 기준 '그 시점에 알 수 있었던 것' 계산(transaction time 구현), 같은 증상 시간순 다중 관찰(`order`). valid time(유효 기간)은 없음.
- 판정: **신규성 부족.** 단, MedMap 시스템 안정성 기능(정정 후 오래된 판단 표시)으로는 가치 있음 → K7의 평가 항목 하나로 흡수 권장.

### K4. 다중 출처·다중 시점 진술 충돌 유형 분류 (요청 6 일반화: 진료과 간·환자↔의사)

- 실제 문제: [확인] 환자 보고 증상과 의무기록 증상 사이 불일치(Pakhomov 등 2008 Mayo 1,119명, 흉통·호흡곤란·기침; AML 2026 31명, 심리 증상 과소 기록; 유방암·C형간염 연구, 모두 검색 요약). [확인] 'diagnosis momentum'—초기 '가능' 진단이 기록 복사로 고착(교육 자료 수준, 통제 연구 미발견).
- 선행연구: 불일치 *측정* 연구는 많음. [미확인] 임상 문서 간 모순 자동 탐지(NLI 기반, MedNLI 등)와 시간 변화 vs 진짜 모순 구분 연구는 이번에 검색하지 않음 → A와 대조 필요.
- 계산 문제: 입력 = 진술 집합 {(대상, 속성, 값, 출처, 말한 시각, 기록 시각, 확인 상태)}. 출력 = 진술 쌍별 유형 {일치, 시간 변화, 진짜 모순, 범위·세분도 차이(예: '기침' vs '마른기침'), 판정 불가}. 목적 = 유형 분류 정확도, 특히 '시간 변화를 모순으로 오인'과 '모순을 시간 변화로 덮음'의 비용 비대칭.
- 기존 알고리즘과 차이: 시간 구간 추론(Allen) + 개념 계층(용어 체계 포함 관계) + 규칙. **새 계산 방법 아님**. 과제 정의·오류 분류 체계가 기여.
- 공개 데이터: 합성 가능. 실제 다출처 기록은 MIMIC-IV note(자격 필요) [미확인 접근성].
- MedMap 활용: [확인] `encounterLink.ts`의 `NeedsCheck` — 환자 기록과 의사 설명이 다르면 "서로 다른 시점일 수 있음"으로 표시하고 어느 쪽도 지우지 않음. 이미 '시간 변화 vs 모순'을 구분하려는 문구가 있음.
- 판정: 알고리즘 신규성 부족. **K7과 합쳐 평가 항목으로 쓰는 것이 가장 효율적.**

### K5. 의사 진단 가설 vs 새 근거 불일치

- 실제 문제: [확인] premature closure, diagnosis momentum — 상충 데이터를 잡음으로 넘기지 말고 대안 진단을 찾으라는 권고(Merck Manual 등 교육 자료). [확인] 의사결정 지원이 이를 줄인다는 통제 연구 결과는 이번 검색에서 미발견.
- 선행연구: 감별진단 시스템(DXplain, Isabel; [미확인] 이번에 재확인 안 함), 일관성 기반 진단(Reiter 1987), parsimonious covering(Peng & Reggia) [미확인: 고전 문헌, 재확인 안 함]. MedMap main-ai 자체가 베이즈 사후확률 + 정보이득 질문 선택(DDXPlus 기반) [확인: `next_information.py` 주석].
- 미해결 [가설]: 모델이 아니라 **의사가 세운 가설을 고정 입력**으로 두고, 새 근거를 지지/충돌/무관/미확인으로 나누며 출처(환자 vs 의사)를 보존하는 설정. 그러나 이것은 '가설 h에 대한 각 근거의 우도비 부호 표시'로 환원됨.
- 계산 문제: 입력 = 의사 가설 h, 근거 집합 E(출처·시각), 지식 K(소견-질환 관계). 출력 = e별 {지지, 충돌, 중립, 판단 불가(K에 없음)} + h를 유지할 때 설명되지 않는 근거 집합. → 일관성 기반 진단 / 우도비. **신규성 부족**.
- 공개 데이터: DDXPlus(합성 환자, 정답 병리 포함 — main-ai가 이미 사용 [확인: `eligibility.py`의 E_134 등 evidence ID]) → 일부러 틀린 가설을 넣고 충돌 근거 검출률을 시뮬레이션 가능. 실제 의사 가설 데이터는 없음.
- MedMap 활용: [확인] `main-ai/medmap/diagnosis.py`, `evidence.py`, `next_information.py`; [확인] `clinicianStatement.ts`의 `DiagnosisStatus = suspected | considered | confirmed_by_clinician | ruled_out | unknown | mentioned_only`.
- 실패 위험: 지식 K의 근거 출처가 없음([확인] `knowledgeRegistry.ts` 주석 "no SUPPORT / WEAKEN relation ... is produced"). DDXPlus 지식은 합성 데이터의 생성 규칙이라 순환 평가 위험.
- 판정: 알고리즘 신규성 부족. MedMap 정체성과 맞아 **시스템 기능 + 시뮬레이션 평가**로는 의미 있음.

### K6. 근거 기반 재평가로 불필요 경고 감소(alert fatigue)

- 선행연구: [확인, 검색 요약] Daniels 등(JAMIA Open 2019, PMC6398362) — 약물상호작용 경고 30.2% 맥락화 + 16.5% 억제로 무시율 93.9% → 46.8%. 맥락 기반 DDI 알고리즘(PMC7976224), 교차 시험 연구. O'Sullivan 등 메타분석 44개 연구 무시율 79.8%(2025 JMIR 프리프린트, 동료심사 여부 [미확인]).
- 미해결: 맥락 기반 억제는 이미 연구·운영됨. '정당화가 사라진 경고만 재평가'는 K3 계산과 동일.
- 공개 데이터: [미확인] 공개 경고 발생·무시 로그를 찾지 못함. MIMIC에는 경고 로그가 없는 것으로 알고 있으나 확인 필요.
- MedMap 활용: 경고 시스템 없음.
- 판정: **신규성 부족 + 데이터 부족.** 제외 권장.

### K7. 시스템·평가 연구: 출처·시점 구분 인계의 정확성·사용성 (요청된 비교 경로)

- 실제 문제: [확인] 환자 보고와 의무기록 증상 불일치가 반복 보고됨(K4의 문헌). 환자 사전 문진·인계가 출처와 시점을 잃으면 '환자가 말한 것'이 '의학적 확인'처럼 읽히거나, 과거 증상이 현재처럼 읽힐 위험 [가설].
- 선행연구: 불일치 측정 연구는 있으나, '환자 확인 기록 → 의사 설명 → 출처·시점 분리 표시'의 **추출 정확도 + 출처 귀속 정확도 + 시점 혼동률 + 의사 판독 시간**을 함께 평가한 연구가 있는지는 [미확인] (이번 검색 범위 밖. 디지털 사전 문진 도구 평가 연구는 다수 있을 가능성이 높음 → A가 확인해야 함).
- 연구 질문(알고리즘 주장 없음): 출처·시점·확인 상태를 보존하는 인계가 단순 요약 인계보다 (a) 출처 귀속 오류, (b) 시점 혼동 오류, (c) '언급 없음/미시행/대기/음성' 혼동 오류를 줄이는가, (d) 의사 판독 시간을 늘리는가.
- 평가 설계(초안): 같은 사례를 (i) 자유문 요약, (ii) MedMap 출처·시점 분리 화면으로 제시하는 대응 비교. 1차 지표 = 사례당 오류 수(출처·시점·결측 의미), 2차 = 판독 시간, SUS. 사례 단위·평가자 단위 혼합효과. 합성 사례만 사용하면 IRB 면제 가능성 [미확인: 학교 IRB 확인 필요].
- 공개 데이터·정답: [확인] 사전등록된 합성 12사례(`PREREGISTRATION.md`: CASE01~03, X01~X09, `cases.ts` SHA-256 고정, "같은 사람이 기대값과 구현을 모두 작성 → 독립 시험 아님"이라고 문서가 스스로 명시). → 독립 작성자가 만든 사례 추가(최소 수십 개)가 필요. 정답은 사례 작성 시 정의(구조적 정답이라 의학 판단 불필요) → **정답 확보가 8개 후보 중 가장 쉬움**.
- MedMap 활용 [확인]:
  - `~/medmap-team/MedMap/apps/web/src/clinicalHandoff.ts` — `source: "patient_confirmed_entry"`, 증상별 `source_text`, 인계 직렬화(MM 코드), 492줄.
  - `~/medmap-team/MedMap/apps/web/src/qrCrypto.ts` — 암호화 인계.
  - `~/medmap-team/MedMap/apps/web/src/research/doctorAB/encounterLink.ts` — `PatientEvent`(시간순 다중 관찰, `clinicallyVerified: false`), `NeedsCheck`, `stateAsOf`, `unknownsOf`.
  - `~/medmap-team/MedMap/apps/web/src/research/doctorAB/clinicianStatement.ts` — `TestStatus = not_done | pending | resulted | result_uncertain`, 의사 검토 상태.
  - `~/medmap-team/MedMap/apps/web/src/research/doctorAB/DoctorExplanationPanel.tsx`, `doctorAB.test.ts`.
- 실패 위험: (1) 신규성 = 실증 결과에 의존, 차이가 작으면 기여 약함. (2) 의사 평가자 모집. (3) 합성 사례 편향(작성자 = 구현자 문제는 이미 문서에 경고됨).
- 논문 기여: 의료정보학 사용성·평가 논문(JMIR Formative/Human Factors, AMIA 등) [가설]. 알고리즘 깊이를 요구하는 지도교수 기준에는 미달할 수 있음 → K1을 보조로 두는 이유.

### K8. JNP + MDQ (현행, 공정 비교 기준)

- E의 독자 판단: 참고 문서가 이미 ROR·Boutilier 2006·IJCAI 2005로 결합 신규성을 약화시켰다고 기술. E는 해당 원문을 이번에 확인하지 않았으므로 [미확인]으로 둔다. B·C 서브에이전트 실험 결과가 '기존 강건 최적화 반복 실행으로 동일 답이 나오는지'를 보여주면 판정 가능.
- 데이터 병목: 동일 환자의 임상 기록 + 선호 + 전문가 정답 공개자료 없음(참고 문서 기술, D가 확인 담당).
- MedMap 재사용: 선호·치료 선택지 코드 없음([확인] main-ai·MedMap grep에서 관련 모듈 미발견). 신규 구현 필요.
- 판정(조건부): B·C 결과 전까지 **유지 근거도 폐기 근거도 E 단독으로는 확정 불가**.

## 6. 최종 선택: **C. 다른 후보 선택 (조건부)**

**선택 내용**
1. 주 경로: **K7** — 출처·시점·확인 상태를 보존하는 인계의 정확성·사용성 평가 연구. K4(충돌 유형), K3(정정 후 오래된 판단), 18개 문제 중 1번(결측 의미 혼동)을 평가 지표로 포함.
2. 보조 연구 질문: **K1** — 환자별 근거 적용 범위(범위 안 / 지식 부족 / 정보 부족). A(선행연구)가 동일 과제를 찾지 못하는 경우에만 진행.

**근거**
- 8개 후보 모두 새 계산 방법 신규성을 확인하지 못했다(4절). 이 상황에서 알고리즘 신규성을 전제로 하는 A(JNP+MDQ 유지)를 E 단독으로 지지할 근거가 없다.
- B(문제 정의 수정)도 가능하지만, JNP의 강건 판단 기계를 그대로 쓰는 수정은 ROR·Boutilier 계열 중복 문제를 그대로 안고 간다. K1은 선호를 빼고 '근거 범위'로 축을 바꾸므로 중복 축이 다르다 → 별도 후보(C)로 분류.
- D(확정 근거 없음)를 고르지 않은 이유: K7은 신규성 판단과 무관하게 실행 가능하고 정답을 구조적으로 정의할 수 있어 '확정 근거 없음' 상태에서도 진행 가능한 유일한 경로다.

**이 선택을 뒤집는 조건**
- B·C가 JNP/MDQ에서 기존 방법(ROR 반복, 히팅셋)이 실패하는 반례를 재현 가능하게 보이면 → A 재검토.
- A가 '환자 단위 근거 적용성 자동 판정' 선행연구를 찾으면 → K1 폐기, K7 단독.
- 지도교수가 '알고리즘 깊이'를 필수 조건으로 고정하면 → K7 단독은 부족. 이때 K1 또는 K8 중 반례가 있는 쪽만 남김.

**다음 행동 1개**: A 서브에이전트 결과에서 'per-patient applicability / GRADE indirectness automation / trial generalizability to individual patient' 선행연구 유무를 대조한다(K1 게이트).
