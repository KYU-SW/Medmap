# 임시 외부 모바일 시험

학교 등 집 네트워크 밖에서 합성 시험 문장으로 기능을 확인할 때만 사용한다.
Cloudflare Quick Tunnel 주소는 임시 공개 주소이며 인증 기능이 없다. 실제 환자정보,
개인정보, 실제 진료 음성을 입력하지 않는다.

## 실행 조건

1. 집 컴퓨터가 켜져 있어야 한다.
2. API 서버와 웹 서버가 실행 중이어야 한다.
3. `scripts/run_temporary_tunnel.ps1`을 실행한다.
4. 출력된 `https://...trycloudflare.com` 주소를 휴대폰에서 연다.

터널 프로세스를 종료하면 외부 주소도 닫힌다. 주소는 실행할 때마다 바뀔 수 있으며
가용성이 보장되지 않는다. 정식 배포 수단으로 사용하지 않는다.

실행 파일은 `local-cache/tools/cloudflared.exe`에 있으며 Git에서 제외된다. 프로젝트 정리
시 `local-cache/`와 함께 삭제한다.
