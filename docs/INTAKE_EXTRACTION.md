# 의료정보 구조화 v1

## 목적

STT 문장에서 증상, 있음·없음, 발생 시점, 정도, 복용약, 알레르기를 찾아 사용자가
확인할 수 있는 형태로 보여준다. 이 단계는 질환을 진단하지 않는다.

## 현재 지원하는 증상

- 두통
- 발열
- 기침
- 호흡곤란
- 가슴 답답함
- 복통
- 구토

`없음`과 `확인되지 않음`을 구분하고, 각 결과에 원문 근거를 남긴다. 결과는 사용자가
수정하고 확인할 수 있으며, 확인 버튼을 눌러도 아직 서버나 PatientState에 저장하지 않는다.

## 검증된 예

입력: `어제부터 머리가 아프고 열은 없어요.`

- 두통: 있음, 시작 시점 `어제부터`, 원문 근거 `머리가 아프`
- 발열: 없음, 원문 근거 `열은 없`

현재 구현은 작은 규칙 기반 1차 버전이다. 지원하지 않는 표현을 임의로 추측하지 않으며,
향후 테스트 문장과 오류 사례를 모아 어휘와 시간 연결 규칙을 확장한다.
